# SANS · 심판의 회랑

샌즈하고만 싸우는 독립된 보스전 게임입니다. 기존 언더테일 팬 게임 안의 샌즈 전투와는 별개이며, 그 게임의 코드와 세이브를 건드리지 않습니다.

- 실행: 루트에서 `npx next dev` 후 `/play/sans` 접속.
- 이 게임만 바로 보기: `node games/sans/dev-server.mjs` 후 http://127.0.0.1:3030/play/sans/ 접속. (캐시 없이 `public/`을 그대로 내보냅니다)

## 조작

- 방향키 / WASD: 이동, 메뉴 선택. 파란 영혼일 때는 바닥 반대쪽 키가 점프이며 길게 누를수록 높이 뜁니다.
- Z / Enter / Space: 확인, 대사 넘기기, 공격 타이밍
- X: 취소, 대사 한 번에 보기. 누르고 있으면 천천히 이동
- Shift: 천천히 이동
- Esc / P: 잠깐 쉬기 · M: 소리 켜고 끄기
- 모바일: 화면 아래 방향 패드와 X · Z 버튼. 대사와 타이틀은 화면을 눌러도 넘어갑니다. 가로로 돌리면 버튼이 화면 오른쪽에 놓여 게임과 조작부가 한 화면에 들어옵니다. 여러 손가락이나 키보드·터치를 함께 써도 누르고 있는 방향을 유지합니다.

## 전투

- 샌즈는 HP 1, 공격 1, 방어 1. 그런데 공격은 전부 빗나갑니다. 그래도 **공격해야 이야기와 공격 순서가 나아갑니다.** 행동·아이템·자비로 차례를 넘기면 짧은 공격만 옵니다.
- 맞으면 한 번에 HP 1이지만 무적 시간이 거의 없어서, 스치면 조금 닳고 머무르면 금방 닳습니다. 맞을 때마다 **업보(KR)** 가 보라색으로 쌓여 HP를 천천히 갉아먹습니다. 업보만으로는 죽지 않습니다.
- 빨간 영혼은 자유 이동, 파란 영혼은 중력이 있습니다. 샌즈가 영혼을 벽으로 내리꽂으면 그 벽이 바닥이 되고, 곧 그 벽에서 뼈 가시가 솟습니다(빨간 경고). 중력이 향하는 벽에는 파란 선이 생기고, 화면 아래에는 정확한 점프 방향이 표시됩니다.
- 흰 뼈는 닿으면 다치고, 파란 뼈는 가만히 있으면 지나갑니다.
- 가스터 블래스터는 쏘기 전에 빔이 지나갈 자리를 흐리게 보여 줍니다.
- 뼈 바다 위에서는 초록 줄이 있는 발판을 갈아타며 버팁니다.
- **2막부터 암전 전환**: 모든 공격 시작 전에 잠깐 검게 끊기고, 공격 도중에도 2~4번씩 다시 검게 끊깁니다. 암전이 끝날 때마다 **다른 공격 패턴으로 교체**되며, 이전 탄막과 발판은 사라집니다. 상자 크기·영혼 색·중력도 새 패턴에 맞춰 바뀝니다. 특별 공격은 아홉 구간을 이어 붙입니다. 검은 동안 영혼·탄막·업보가 멈추고, 화면이 돌아온 뒤 0.18초 동안은 피해를 받지 않습니다. 암전에는 충격음과 상승 전자음, 새 패턴이 나타날 때는 짧은 전자음이 납니다. 소리 OFF 설정은 그대로 적용됩니다.
- 2막의 메뉴에서는 뼈가 버튼 줄을 가로지릅니다. 고르고 있는 버튼 위로 지나가기 전에 옆 버튼으로 옮기세요. (연습 난이도에는 없습니다)

## 흐름

1. 대사가 끝나면 플레이어 차례 없이 첫 공격(내리꽂기 → 물결 통로 → 블래스터 네 번)이 날아옵니다.
2. **1막** 여섯 공격: 뼈 뛰어넘기, 틈 뚫린 뼈 기둥, 흰 뼈와 파란 뼈, 블래스터 격자, 발판, 네 벽 내리꽂기.
3. **제안**: 샌즈가 그만하자고 합니다. 기다려 주는 동안에는 공격이 없습니다. 자비를 고르면… 속습니다. 공격하면 2막이 시작됩니다.
4. **2막** 여섯 차례의 복합 공격: 각 차례가 3~5개 구간으로 나뉘며, 암전마다 블래스터·뼈 통로·파란 뼈·중력·발판 공격으로 바뀝니다. 새 공격은 세로 뼈 통로, 멈추면 피하는 파란 십자가, 네 모서리 블래스터, 천장에서 뛰어넘는 뼈입니다.
5. **특별 공격**: 좁은 상자의 빠른 4방향 내리꽂기 → 양쪽에서 겨누는 연속 블래스터 → 좁고 촘촘한 뼈 통로 → 발판 → 파란 십자가 → 소용돌이 → 천장 점프 → 내리꽂기 → 가속 회전과 바닥 뼈. 마지막 구간에는 회전 블래스터 34개와 직각 추가 빔 8개가 나옵니다. 보통 이상에서는 특별 공격의 탄막 시간이 추가로 1.18배, 연습에서는 1.08배 흐릅니다.
6. **아무것도 하지 않는 차례**: 샌즈가 차례를 끝내지 않고 서 있다가 잠듭니다. 잠든 뒤에는 벽을 밀어 상자를 옮길 수 있습니다. 공격 버튼 쪽으로 밀어 Z를 누르면 싸움이 끝나고, 자비 버튼 쪽으로 밀어 Z를 누르면 다른 결말로 갑니다.

샌즈는 몇 번 졌는지 기억하고, 다시 만날 때마다 다른 말을 합니다. 끝까지 가면 그 셈은 처음으로 돌아갑니다.

## 난이도

- **연습**: 탄막이 0.8배로 흐릅니다. 2막과 특별 공격 앞에 이어하기 지점이 있고, 이어서 도전할 때 아이템이 다시 채워집니다. 메뉴 뼈가 없고 샌즈가 빨리 잠듭니다.
- **보통**: 최초 버전보다 탄막이 1.18배 빠릅니다. 쓰러지면 2막부터 이어서 도전할 수 있습니다(2막에 들어설 때의 가방 그대로).
- **최악의 시간**: 최초 버전보다 1.36배 빠르고 업보가 두 배로 쌓입니다. 쓰러지면 처음부터.
- **하드모드**: 처음에는 잠겨 있습니다. **보통 또는 최악의 시간을 어느 결말로든 클리어하면 열리며**, 기존 클리어 기록도 인정합니다. 연습 클리어로는 열리지 않습니다. 속도와 규칙은 보통과 같지만 **HP 1로 시작**합니다(최대 HP는 92 그대로). **아이템이 없어서 회복할 수 없고 한 번만 스쳐도 끝납니다.** 2막부터 이어서 도전할 때도 HP 1과 빈 가방으로 시작하며, 예전 버전의 이어하기 가방도 비웁니다. 처음 만나면 샌즈가 HP 1과 빈 가방을 알아봅니다.

영혼의 움직임은 난이도와 상관없이 같은 빠르기입니다. 느려지고 빨라지는 것은 탄막 쪽입니다.

## 히든 하트

타이틀의 샌즈를 세 번 누르거나 X를 세 번 누르면 민트색 히든 하트를 발견합니다. 타이틀에서 잠시 기다리면 단서가 나타납니다. 일반 세 난이도는 현재·최대 HP가 180, HP 1 하드모드는 현재·최대 HP가 3이 됩니다. 하드모드의 가방은 계속 비어 있습니다. 발견 기록은 같은 기기·브라우저에 저장되며 재도전·이어하기·새로고침에도 적용됩니다.

## 저장

`sans-judgement-hall` 키에 샌즈가 기억하는 횟수, 본 결말, 난이도별 최고 기록(쓰러진 횟수가 적은 쪽, 같으면 스친 횟수가 적은 쪽), 고른 난이도, 히든 하트 발견 여부, 소리 설정을 남깁니다. 다른 게임의 저장 데이터는 읽거나 쓰지 않습니다.

## 파일

- `public/play/sans/core.mjs` — 전투 로직. 상태가 함수 없는 순수 데이터라 통째로 복제할 수 있습니다.
- `public/play/sans/patterns.mjs` — 탄막 패턴과 공격 순서. `sequence`는 한 차례 안에서 암전으로 바뀌는 `[패턴 시각, 이름]` 목록입니다. 차례 전체의 시각과 각 구간의 시각·메모를 따로 보관해 이전 패턴의 탄막이나 중력이 새 구간에 섞이지 않습니다.
- `public/play/sans/lines.mjs` — 대사와 문구, 아이템.
- `public/play/sans/art.mjs` — 샌즈와 블래스터 픽셀 그림(표정·팔·땀을 인자로 바꿔 그립니다).
- `public/play/sans/render.mjs`, `audio.mjs`, `game.mjs` — 화면, 합성 음악과 효과음, 브라우저 연결부.

## 검증

- `npm run test:sans` — 전투 흐름과 규칙(`core.test.mjs`), 그리고 공정함 검사(`fairness.test.mjs`). 공정함 검사는 몇 수 앞을 내다보는 봇(`bot.mjs`)이 모든 공격을 거의 스치지 않고 넘길 수 있는지 확인합니다. 피할 길이 있다는 뜻이지, 사람에게 쉽다는 뜻은 아닙니다. 30초쯤 걸려서 전체 `npm test`에는 `core.test.mjs`만 들어 있습니다.
- `node games/sans/browser-check.mjs [스크린샷 폴더]` — 실제 브라우저에서 타이틀부터 두 결말까지 돌려 보고, 폴더를 주면 장면별 스크린샷을 남깁니다. `SANS_URL=https://seonn.dev/play/sans/index.html`로 배포된 페이지도 같은 검사를 할 수 있습니다. 새 효과음은 OfflineAudioContext에서 실제로 소리가 생성되고 음소거가 유지되는지도 검사합니다.
- `node games/sans/art-preview.mjs <out.png>` — 샌즈의 표정·팔 모양과 블래스터를 한 장의 PNG로 뽑습니다.
- `window.render_game_to_text()` 는 현재 상태(차례 이름·실제 패턴 이름·암전 남은 시간 포함)를 JSON으로 돌려주고, `window.advanceTime(ms)` 는 시간을 그만큼 흘려보냅니다.

## 크레딧

샌즈와 언더테일의 원작은 Toby Fox입니다. 이 게임은 팬이 만든 비공식 작품이며, 대사·픽셀 그림·음악은 모두 새로 만들었습니다. 원작의 이미지, 음원, 멜로디, 대사를 쓰지 않았습니다. 글꼴은 기존 언더테일 팬 게임에 들어 있는 Galmuri11을 함께 씁니다.

- `node games/sans/input-check.mjs`: 실제 게임 페이지처럼 iframe을 감싼 상태에서 클릭 전 최초 방향키, 새로고침, 모바일 행동 메뉴와 첫 전투 이동을 확인합니다. `GAME_SITE=https://seonn.dev`로 실제 공개 페이지를 검사합니다.

시작 음악 확인: `node games/sans/audio-check.mjs` (자동 재생 허용/차단과 첫 입력, 실제 오디오 신호, 음소거 저장). 배포 확인은 앞에 `GAME_SITE=https://seonn.dev`를 붙입니다.

배리하드: 하드모드(하드코어)의 클리어 기록으로 해금됩니다. 최악의 시간과 같은 탄막/속도, HP 1(히든 발견 시 최대 HP 3), 아이템 없음, 체크포인트 없이 처음부터 재도전합니다. 기존 클리어 기록도 인정합니다.
