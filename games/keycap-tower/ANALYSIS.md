# 키캡타워 분석과 키캡 타워 설계

조사 기준: 2026-10-04. "키캡타워"는 로블록스의 키보드 타워류 게임(+1 Speed Keyboard Escape, 키보드 타워)으로 보고 공개된 위키·공략 글을 읽어 정리했습니다. 원작의 내부 수치를 모두 확인한 것은 아니고, 아래 "키캡 타워 적용" 수치는 이 게임을 위해 새로 정한 값입니다.

## 원작의 핵심 흐름

**키캡을 밟는다 → 스피드 +1 → 레벨이 오른다 → 스테이지 문이 열린다 → 노란 버튼으로 윈을 받는다 → 윈으로 더 빨라진다 → 다음 월드.**

## 원작에서 확인한 시스템

- **스피드와 레벨**
  - 키보드 키를 한 번 밟을 때마다 스피드가 오르고, 누적 스피드가 레벨이 된다.
  - 뒤쪽 스테이지는 레벨 조건이 있다 (1월드 끝 100~120, 2월드 140~200+).
- **윈(트로피)**
  - 스테이지 끝 안전지대의 큰 노란 버튼을 밟으면 받는다. 1스테이지 +1부터 뒤로 갈수록 크게 늘어난다.
  - 가끔 나타나는 황금 키캡도 윈을 준다.
- **러닝머신**
  - 올라서 있으면 스피드가 자동으로 오른다. 초콜릿 ×1(무료), 골드 ×3, 다이아 ×9, 캔디 ×25, 어드민 ×100.
  - 원작은 대부분 로벅스로 산다.
- **월드**
  - 1월드 캔디·초콜릿 테마, 2월드 레벨 120, 3월드 레벨 400.
- **환생**
  - 레벨이 0으로 돌아가는 대신 영구 배수를 얻는다.
- **트레일·오라**
  - 얻는 스피드에 배수가 붙는 꾸미기 아이템.
- **장애물**
  - 좁은 다리, 움직이는 발판, 사라지는 발판, 회전 발판, 쫓아오는 추격자.

## 키캡 타워 적용

- **3D 나선 타워**: 가운데 키보드 기둥을 감고 올라가는 길. 스테이지마다 안전지대와 노란 버튼, 레벨 문이 있다.
- **월드 4개**: 1월드 캔디 타워(레벨 0, 8스테이지), 2월드 네온 타워(120), 3월드 용암 타워(400), 4월드 은하 타워(1000). 2~4월드는 6스테이지씩. 4월드는 새로 만든 월드다.
- **러닝머신 12대**: 월드마다 3대. 첫 대는 무료, 나머지는 로벅스 대신 윈으로 산다 (×1·×3·×9 → ×25·×60·×150 → ×1,000·×2,500·×6,000 → ×5만·×12만·×30만).
- **스탯 5가지** (윈으로 올림): 발걸음 힘, 윈 배수, 러닝머신 효율, 달리기, 점프력.
- **환생**: 레벨 50, 100, 150…마다 가능. 한 번에 스피드 ×2, 최대 30번.
- **트레일 5가지**: ×1.5 ~ ×20.
- **장애물**: 움직이는 키(↔), 오르내리는 키(↕), 사라지는 ? 키, 빨간 DEL 키, 빨간 회전 막대, 쫓아오는 ESC 괴물, 황금 키캡(★).
- **뺀 것**: 로벅스 결제, 멀티플레이, 펫·아이템 합성, 오라, 관리자 이벤트.
