# 원작 분석과 ECHO의 구현 범위

2026-10-13. 요청의 핵심은 기존 시작 화면의 수정이 아니라 **새로운 플레이 경험**이며, 원작의 모든 것을 포함해 달라는 넓은 요구다. 한 번의 구현으로 원작의 모든 콘텐츠를 재현했다고 주장하지 않는다. 기존 작품은 유지하고 별도 경로·별도 저장으로 새 캠페인을 만든다.

## 조사 근거

- Toby Fox의 공식 소개: https://undertale.com/about/ — 비폭력 해결, 적의 성격에 따른 행동, 실시간 회피 전투.
- Toby Fox의 개발자 인터뷰: https://www.gamedeveloper.com/design/game-design-deep-dive-i-undertale-i-s-action-based-rpg-battles — 공격 패턴과 캐릭터의 성격, 대화와 실시간 전투를 엮는 설계.
- 저장소 `games/undertale/ANALYSIS.md` 및 전투·패턴·영혼·세계·아스리엘 소스. 기존 로컬 분석은 구현 참고자료이며 공식 원작 전체를 독립적으로 검증한 자료로 취급하지 않는다.

## 설계 원칙

1. 공격을 줄이는 것과 적을 이해하는 것을 구분한다. ACT는 적마다 고유하며 자비는 실제 조건을 만족해야 한다.
2. 공격 시간과 방어 시간을 분리한다. 공격은 타이밍, 방어는 이동·중력·방패라는 다른 기술을 요구한다.
3. 선택을 숫자 외의 장면으로 돌려준다. 비어 있는 자리, 이어지는 노래, 새벽 열차가 관계의 결과를 드러낸다.
4. 보스의 기믹을 대사로 먼저 가르친다. 파피루스는 점프, 언다인은 방향 방패, 알피스는 색상 탄막을 설명한다.
5. 스위치와 세이브, 되돌아가는 길이 실제로 접근 가능한지 검사한다. 지도 장식으로 진행을 막지 않는다.
6. 명시적으로 다른 작품을 만든다. 장소를 재명명하는 데 그치지 않고 새 연결 구조, 이벤트, 목표, 결말을 만든다.

## 포함하지 않은 원작 콘텐츠

원작의 모든 대사·음원·아트·방·랜덤 대화, 전체 데이트/요리 이벤트, 머펫·매드 더미 등 모든 보스의 별도 전투, 진실의 연구소와 모든 아말가메이트, 보라색 줄 이동·노란색 슈팅 영혼, 전체 FUN 값 이벤트, 원작과 동일한 전화·배송·엔딩 변형·RESET 대사는 포함하지 않았다. 따라서 **원작 전체 재현 또는 완전 분석 완료**로 표현해서는 안 된다.

## 검증 범위

맵의 20×15 규격, 출구 연결, 잠금 해제 후 통행, 스위치 접근, 세이브와 기억 접근, 유령 재방문, 물 건네기, 신호 게이트, 세 가지 결말 분기를 자동 검사한다. 기존 전투의 실제 상태 변화 및 아스리엘의 모든 막·구원까지 별도 단위 검사한다. 실제 브라우저 자동화는 UI와 엔진 연결 및 렌더를 확인하며, 모든 보스를 플레이어 입력으로 완주한 수동 QA를 대신하지 않는다.
