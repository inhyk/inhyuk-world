# UNDERTALE: ECHO · 잊힌 별의 역

기존 「세 갈래의 결말」과 별도로 만든 새로운 비공식 팬게임. 멈춘 지하 열차의 다섯 신호를 되살리는 다섯 장의 모험입니다. 원작 캐릭터는 Toby Fox의 작품이며 공식 속편이나 원작 전체의 복제본이 아닙니다.

## 실행

- 사이트: `/play/undertale-echo`
- 독립 실행: `python3 -m http.server 5193 --directory public` 후 `http://localhost:5193/play/undertale-echo/index.html`
- 방향키/WASD 이동, Z/Enter 확인, X 취소·문장 표시, C 아이템·장비·수첩, Shift 정밀 이동, M 소리.
- 모바일 방향 패드와 Z/X/C. 소리는 상단 스피커 버튼으로 켭니다.

## 구성

새 시작 화면, 5개 지역·20개 방, 4개 스위치 퍼즐, 조사 가능한 기억 20개, 상점 3개, 회복·장비, 이름 짓기, 별에서 저장, 자동 복원, 합성 음악, 개별 몬스터 행동, 복수 몬스터 전투, 빨강·파랑·초록 영혼, 색상 탄막, 세 가지 결말.

정원 → 승강장 → 저수지 → 방송국 → 종착역을 탐험합니다. 신호의 문 스위치는 왼쪽 아래, 상자는 위쪽에 있습니다. 반짝이는 별 앞에서 Z를 누르면 회복·저장합니다. 첫 방에서 사탕 2개·파이·35G를 받습니다. 공격 외에 행동과 자비로 모든 전투를 진행할 수 있습니다.

타이틀 **보스 연습**에서 토리엘, 파피루스, 언다인, 불사의 언다인, 메타톤 EX, NEO, 아스고어, 플라위, 샌즈, 아스리엘의 10개 전투를 고릅니다. 연습은 HP 99·회복 아이템 4개로 시작하며 이야기 세이브에 영향을 주지 않습니다. 죽은 뒤 확인하면 연습 메뉴로 돌아갑니다.

## 결말 조건 (스포일러)

- **모두의 아침**: 아무도 죽이지 않음, 파피루스를 살림, 음악실에서 유령의 노래를 끝까지 들음, 언다인에게 물을 줌, 마지막에 모두의 기억을 잇기. 아스리엘의 세 막과 잃어버린 영혼 구하기를 거칩니다.
- **빈 옆자리**: 혼자 떠나거나 인연이 부족한 상태로 기억을 잇기. 후자는 플라위 전투를 거칩니다.
- **종착역 없음**: 12명 이상과 토리엘·파피루스·언다인·메타톤을 처치한 상태로 심판의 회랑을 지나 샌즈와 싸움. 마지막 신호에 응답할 목소리가 사라집니다.

기억 수첩의 20개 조사는 수집 요소이며 불살 결말의 필수 조건은 아닙니다. 유령에게 처음 거절해도 다시 찾아가 들을 수 있습니다. 종착역에서 신호가 모자라면 돌아가야 합니다.

## 저장과 검증

`undertale-echo-save-v1`, `undertale-echo-meta-v1`을 사용합니다. 이전 게임의 저장 키를 읽거나 지우지 않습니다. 브라우저 저장 기능을 막은 환경에서는 저장 실패를 표시합니다.

- `npm run test:undertale-echo`: 전투와 아스리엘 상태 기계, 맵 접근성, 퍼즐, 저장, 세 결말 분기 40개 검사.
- `npm run test:undertale-echo:browser`: 실제 Chrome 자동화로 이름·도입·이동·스위치·저장/이어하기·ACT/회피/MERCY·모든 방 렌더·중립 결말·연습 메뉴·모바일 터치 확인. 테스트 전투에서만 무적을 부여하며 전 캠페인을 수동으로 완주한 검사는 아닙니다.
- 스크린샷은 `artifacts/undertale-echo/`에 남습니다.

원작 시스템 조사와 구현 범위는 [ANALYSIS.md](ANALYSIS.md)에 정리했습니다. 전투·스프라이트·합성 음악 기반은 이 저장소의 기존 비공식 팬게임에서 가져왔으며, ECHO의 이야기·맵·시작 화면·역 연출·결말·연습 메뉴는 새로 작성했습니다. 원작 게임의 음원이나 이미지 파일은 포함하지 않습니다. Galmuri 폰트 라이선스는 fonts 폴더에 보존했습니다.
