# 사회적 게임

인혁이가 손으로 그린 계획(2026-11-02)으로 만든 1인칭 3D 사회생활 게임이다.
아파트(세온 아파트 101동 802호)에서 일어나 나갈 준비를 하고, 차를 타고 회사에 가서 일하고, 집에 와서 씻고 잔다.
어느 날엔 회식을 하고, 다른 회사로 출장을 가고, 주말엔 비행기를 타고 일본으로 여행을 간다.
마인크래프트처럼 돌아다니며 블럭을 깨고 놓을 수 있는데, 블럭은 네모난 상자가 아니라 둥근 돌, 통나무, 화분 같은 물건이다.

## 계획에서 가져온 것

- 1인칭 3D, 그림에 있는 3인칭 캐릭터 보기 (V 키로 바꾸기)
- 오른쪽 위의 둥근 "퀘스트" 칸 (그림의 "퀘스트 / 회사로 가세요")
- 왼쪽 위 체력 막대(물방울 아이콘)와 배고픔 막대(고기 아이콘), 4칸 눈금
- 블럭 깨기와 놓기, 블럭은 네모나지 않게
- 차 타고 회사 가기
- 퀄리티: 크랩크래프트처럼 높게, 물건 하나하나 자세하게

## 이야기 고르기 (인혁이 계획 3, 2026-11-03)

- 👔 직장인 이야기: 돈이 별로 없어서 회사 일을 시작한다. 일당 150,000원, 비행기표는 1,000,000원. 표를 살 돈을 모으기 전 주말은 쉬는 날, 모으면 토요일에 일본 여행
- 🎒 어린이 이야기(남자 / 여자): 1학년. 엄마 아빠와 아파트에 산다. 학교(수업 퀴즈, 급식) 끝나고 쉬기 → 태권도(발차기 타이밍) → 바로 피아노(학교종) → 1시간 쉬기 → 영어(퀴즈) → 집에서 엄마 아빠랑 저녁. 둘째 날 체육 시간에 다리를 다쳐 천천히만 걷고, 셋째 날 엄마 차로 면허시험장에 가서 면허를 따고 차 타고 학교에 간다
- 운전면허: 면허가 없으면 차를 못 탄다. 운전면허시험장 코스에서 파란 고리를 차례로 지나 "도착" 칸에 멈추면 끝. 콘 하나에 5점, 2분 넘으면 1초에 1점 감점, 70점 합격
- 내비게이션: 차 안에서 화면 위에 "80m 후 ↱ 우회전"처럼 다음 길을 알려 준다
- 맵: 남쪽에 학교길(두 번째 큰길)과 이어지는 길 2개. 세온 초등학교, 세온 학원 빌딩(1층 쑥쑥 수학과 도레미 피아노, 2층 반짝 태권도와 헬로 영어, 오른쪽 건물 입구에 엘리베이터), 운전면허시험장, 빵집, 카페, 서점, 약국, 장난감 가게, 병원, 아파트 106~107동, 주택 6채

## 직업 고르기 (인혁이 계획 5, 2026-11-06: "직업을 더 만들어줘. 다양하게 경찰, 소방관 같은 것도 넣어.")

시작 화면에서 👔 직장인, 🎒 어린이 옆의 "💼 다른 직업도 해 볼까?" 에서 고른다. 직업마다 아침은 집에서 똑같이 하고, 차 타고 일터로 출근해서 그 직업의 일을 하고, 오후 6시에 사물함(옷걸이)에서 옷을 갈아입고 퇴근하면 일당 150,000원을 받는다. 수요일, 목요일도 출근하는 날이고, 주말과 ✈️ 비행기표 모으기는 직장인과 같다. 일하는 옷(제복)은 사람 모델의 옷으로 만들었다.

- 👮 경찰관 (세온 경찰서): 반장님께 출근 체크 → 사무실 안쪽 파란 사물함에서 제복(모자, 배지) 입기 → 경찰서 앞 순찰차를 타고 파란 고리 순찰 지점 3곳(마트 앞, 학교 앞 어린이 보호구역은 30km/h보다 천천히, 병원 앞) → 무전: 장난감 가게 앞에서 우는 아이와 이야기하기 → 졸졸 따라오는 아이(차를 타면 같이 탐)를 마트 앞 엄마에게 데려다주기 → 큰길 사거리 단상에서 호루라기 교통 정리(✋ 멈춰요 / 👉 가세요) → 내 자리 컴퓨터로 보고서 쓰기
- 🚒 소방관 (세온 소방서): 사물함 앞에서 소방복을 순서대로 빨리 입기(바지 → 안전화 → 상의 → 공기통 → 헬멧 → 장갑, 초 재기) → 출동 대기 → 출동 벨(🚨 화면이 빨갛게 번쩍) → 차고의 소방차를 몰고 연기가 나는 학교길 주택으로 출동(사이렌) → 소화전에 호스를 연결하고 마우스로 겨눠 왼쪽 클릭 꾹, 물줄기로 창문과 지붕의 불 5개 끄기(꺼지면 그을음이 남음) → 소방서로 돌아가기(소방차는 차고로) → 장비 점검(고장 난 공기통, 호스, 무전기 고치기)
- 🧑‍⚕️ 의사 (병원): 하얀 가운 입기 → 진료실 의사 자리에서 환자 3명 진료(청진기, 체온계, 상처 보기 → 알맞은 약) → 엑스레이에서 금 간 정강이뼈 찾기 → 어린이에게 예방 주사(타이밍)
- 🧑‍🍳 요리사 (피자 하우스): 요리사 옷 입기 → 주문서대로 피자 2판(반죽 → 소스 → 치즈 → 토핑, 화덕에서 노릇할 때 꺼내기, 타면 다시) → 창가 손님에게 갖다 주기
- 🛒 마트 직원 (세온 마트): 초록 조끼 입기 → 물건을 알맞은 진열대에 채우기 → 3번 계산대에서 손님 3명 계산(삑 찍고 거스름돈 고르기) → 주차장 카트 4대 모으기
- 📮 우체부 (우체국): 우체부 옷 입기 → 편지를 주소대로 나누기 → 빨간 깃발 우편함 3곳(학교, 106동, 101동)에 배달하기
- 순찰차와 소방차는 그 날만 내 차 대신 운전하는 차다(`src/jobs.js` 의 `board()`). 내 차는 일터에 세워 둔 그대로 기다리고, 일이 끝나 일터로 돌아오면 순찰차와 소방차는 제자리로 돌아간다.

## 시간 (인혁이 계획 5)

- 시계는 진짜 2초마다 게임 1분씩 간다(2026-11-07 "1분을 2초로 바꿔", 그 전엔 0.5초). 게임 1시간은 2분, 하루(아침 7시~밤 9시)는 진짜 28분쯤.
- 할 일을 끝내도 시간이 건너뛰지 않는다("할일 끝나고 다음 일 해야 하는 시간이 바로 되는 게 아니고 기다리고 다음 일을 하게"). 다음 일에 정해진 시간이 있으면 퀘스트 칸에 "⏳ 오전 9:00에 해요 · 1시간 58분 남았어요 (진짜 59초)" 가 나오고, 그동안 마음대로 돌아다닐 수 있다. 너무 일찍 쓰면 "아직이에요!" 라고 한다. 늦었으면 바로 할 수 있다.
- 예: 출근 9:00, 팀 회의 11:00, 점심 12:00, 오후 일 13:00, 퇴근 18:00, 잠 21:00. 어린이: 수업 9:00, 체육 10:30, 급식 12:00, 쉬기 30분, 1시간 쉬기 60분, 저녁 18:00. 여행: 비행기 10:00, 라멘 12:00, 료칸 20:00. 직업: 일 시작 9:00(요리사 10:00), 퇴근 18:00.
- 시간은 `core.mjs` 의 각 퀘스트 `at`(시각)과 `rest`(쉬는 분)로 정한다(`stepStart`, `stepReady`). 밤 11시 59분에서 멈추고 자면 다음 날이 된다.
- 분수 공연: 금요일(`show-days.mjs` 의 `isShowDay`) 저녁 7시에 "분수 공연 보기" 퀘스트가 생긴다. 분수 광장(`plaza`)이 동네에 있을 때만 나온다.

## 영화관에서 진짜 영화 (2026-11-06, 인혁이 계획 2: "진짜 영화를 볼 수 있게 해줘")

## 분수 광장과 공연 (인혁이 계획 7, 2026-11-06)

"어느날엔 공연도 하게 해줘. 그리고 분수를 만들고 분수에서 공연을 하게 해줘."

- 세온 분수 광장: 큰길 남쪽, 세온 컴퍼니 앞 횡단보도 건너편(갤러리 오른쪽). 걸어서도 차로도 큰길에서 바로 간다.
- 분수: 조각한 돌 테두리와 조개 무늬, 두 층 그릇에서 흘러내리는 물 커튼, 테두리에서 안으로 휘는 물줄기 12개, 꼭대기 물줄기, 공연 물줄기 16개, 물결과 물보라. 밤에는 물속 조명 색이 천천히 바뀐다.
- 분수 앞 무대(LED 띠, 스피커, 트러스 조명 탑과 무빙 라이트), 벤치, 꽃밭과 나무, 랜턴 가로등과 전구 줄, 공연 포스터가 붙은 광고탑, 이름 돌.
- 공연: 금요일 저녁 7시~9시(`show-days.mjs` 의 `isShowDay`, `SHOW_HOUR`). 6시 45분부터 동네 사람들이 모이고, 7시에 가수, 기타, 키보드, 드럼, 댄서 2명이 노래하고 분수가 음악에 맞춰 춤춘다. 한 곡은 약 100초이고 조금 쉬었다가 다시 한다.
- 무대 앞 가운데 벤치에서 E: 앉아서 처음부터 끝까지 본다(가사 자막, E로 그만 보기). 공연이 없을 때는 언제 하는지 알려 준다. 공연 날 아침에 "오늘 저녁 7시 분수 광장에서 공연이 있어요!" 알림이 뜬다.
- 분수 왼쪽 테두리에서 E: 100원 동전을 던지고 소원 빌기. 동전은 분수 바닥에 쌓인다.
- 노래는 코드로 새로 만든 곡이다(120 BPM, 소리 파일 없음). 공연은 내 화면에서만 열린다(같이 사는 동네에서도).

## 하루

- 평일: 일어나기, 세수, 아침, 옷 입기, 운전해서 회사, 사원증 찍고 출근, 모닝 커피, 일하기(컴퓨터 업무 2개), 팀 회의, 점심, 일하기, 보고서 출력, 부장님 결재, 사원증 찍고 퇴근, 집에 가기, 씻기, 자기
- 우리 집은 세온 아파트 101동 802호(인혁이 요청으로 집을 아파트로 바꿈). 1층 로비 엘리베이터로 8층에 올라간다. 동네에 102~105동과 길 건너 주택 7채가 더 있다.
- 회사 엘리베이터: 1층 로비 뒤쪽에서 E로 부르고 안에서 E로 층 고르기. 옥상 정원(벤치, 나무, 동네 경치)으로 간다
- 수요일: 퇴근 후 고깃집 회식 (익은 고기를 클릭해서 먹기)
- 목요일: 별빛테크로 출장, 회의실에서 발표
- 토요일: 차 타고 세온 국제공항, 비행기 타고 일본(사쿠라 공항), 신사 도리이 앞에서 사진(P), 라멘, 기념품, 료칸에서 자기
- 일요일: 료칸에서 일어나 온천, 비행기 타고 집으로, 공항 주차장에서 차 타고 집, 씻고 자기
- 여행은 인혁이가 해외 여행(일본)으로 정했다. 서쪽 바다와 바다 펜션은 그대로 있어서 자유롭게 놀러 갈 수 있다.
- 시계는 진짜 2초마다 게임 1분씩 간다(인혁이 요청, 10초 → 0.5초 → 2초). 일을 끝내도 시간이 건너뛰지 않고, 다음 일은 그 시간이 될 때까지 기다린다(위 "시간").

## 같이 사는 동네 (멀티플레이, 2026-11-05)

인혁이가 고른 방식: 모두 나가도 동네가 그대로 남는다. 공용 서버의 같이 쓰는 세계(`packages/net/world.mjs` 의 `World`, game `social-game`)를 쓴다.

- 들어가기: 시작 화면 "🏘️ 친구랑 같이 하기" 또는 게임 안 "🏘️ 같이 하기" → 동네 1~4 (`town-1` ~ `town-4`, 한 동네 12명까지). 로그인해야 하고, 안 했으면 로그인 창이 열린다. 새 게임이면 이야기를 먼저 고르고 들어간다.
- 같이 쓰는 것: 놓은 블럭, 부순 나무, 덤불, 꽃, 바위, 조개(10분 뒤 다시 자람), 다른 사람의 모습과 이름표, 채팅.
- 나만 쓰는 것(예전처럼 클라우드 저장): 이야기, 시계, 퀘스트, 가방(블럭 개수), 돈. 동네에 블럭을 놓으면 내 가방에서 빠지고, 내 블럭을 부수면 돌아온다.
- 혼자 할 때 놓은 블럭은 동네에 있는 동안 화면에서만 빠지고 저장에는 그대로 남는다(`online.mjs` 의 `SoloBlocks`). 나가거나 연결이 끊기면 그대로 돌아온다.
- 다른 사람이 놓은 블럭은 부술 수 없다("○○ 님의 블럭이에요"). 블럭은 한 사람이 한 동네에 400개까지.
- 비밀 지키기: 우리 집(101동 건물 안 전체: 로비, 엘리베이터, 8층, 802호), 바다 펜션, 료칸 안에 있으면 다른 사람에게 내 위치를 보내지 않는다(숨김 신호만 감). 비행기 안도 숨긴다.
- 채팅: `T` 또는 `Enter`. 서버가 욕, 전화번호, 링크를 가리고, 이름은 서버가 준 닉네임만 쓴다. 말마다, 사람 목록의 사람마다 🚫 차단과 🚨 신고 버튼이 있다(`Esc` 로 마우스를 풀고 누른다). 진짜 이름, 나이, 학교, 전화번호는 묻지도 말하지도 않는다.
- 연결이 끊기면 혼자 하기로 돌아오고 "🔄 다시 들어가기" 버튼이 나온다. 서버가 아직 같이 쓰는 세계를 모르면(배포 전) "같이 사는 동네는 아직 준비 중이에요" 라고 하고 혼자 계속한다.
- 같이 타기 (2026-11-07, 인혁: "차를 같이 탈 수 있게 해줘"): 친구가 운전하는 차 옆(4.5m 안, 차가 거의 멈췄을 때)에서 `E 같이 타기 (○○ 님 차)`. 앞자리, 뒷자리 왼쪽, 뒷자리 오른쪽 3명까지 탄다. 타면 내 자리에서 마우스로 둘러보고(V 는 차 뒤에서 보기), 운전은 친구가 한다(WASD 안 됨). 차가 멈추면 `E` 로 내 자리 쪽 문 옆에 내린다. 내 차는 세워 둔 곳에 그대로 있다.
  - 자리는 운전하는 사람 컴퓨터가 정한다(먼저 온 사람 먼저). 타려는 사람은 위치 신호에 "○○ 차에 탈래요"를 싣고, 운전하는 사람은 위치 신호에 자리 3개를 싣는다. 내 번호가 그 자리 목록에 보여야 앉으므로 두 사람이 한 자리에 앉지 않는다. 따로 보내는 메시지는 없다(`online.mjs` 의 `packPose` 7, 8번째 칸, `assignSeats`, `rideStep`).
  - 운전한 사람이 내리거나, 동네를 나가거나, 비밀 장소로 가거나, 서로 차단하면(4초 동안 소식이 없어도) 탄 사람은 차 옆에 내린다. 탄 사람이 나가면 자리가 빈다. 차단한 사람은 태우지도 타지도 못한다.
  - 다른 사람 차는 위치 신호에 실린 보낸 시각으로 조금 늦게(0.15초) 두 신호 사이를 이어 그려서 덜컹거리지 않는다(`PoseTrack`). 운전하는 친구도 운전석에 앉아 보이고, 탄 사람 이름표는 차 위에 차례로 쌓인다.
  - 시험: `node games/social-game/ride-check.mjs http://127.0.0.1:5276/ <사진 폴더> http://127.0.0.1:8787` (로컬 서버만)
- 칸 이름: 블럭 `b|x|y|z`(값 `{i: 블럭, r: 돌림}`), 부순 것 `p|<종류>.<번호>`(ttl 600초). 나무 번호는 모든 컴퓨터에서 같다(`deco.js` 가 정해진 씨앗으로 심는다).

## 최적화 (인혁이 계획: "게임을 최적화 해줘", 2026-11-06)

모습은 그대로 두고 덜 그리고 덜 계산하게 했다. `perf-check.mjs` 로 재고, 전과 후 화면 사진을 같은 자리에서 비교했다.

- 해 그림자 맵은 한 프레임에 한 번만 그린다 (실내 AO 패스가 한 번 더 그리고 있었다). 실내 AO 는 절반 해상도로, 가까운 건물만 넣어서 계산한다
- 안개에 완전히 가려지는 먼 곳(동네에서 본 일본, 일본에서 본 동네)은 그리지 않는다 (`places.cullFar`)
- 나무, 덤불, 풀은 하나씩 거리로 자세한 모양과 먼 모양을 고르고, 가까운 것만 그림자를 만든다 (`scatter.js`)
- 켜진 등이 없으면(낮에 밖) 점광원을 장면에서 뺀다. 두 경우 셰이더를 처음에 다 만들어 둔다 (`lights.js`)
- 셰이더는 진짜 그리는 후처리 버퍼용으로 미리 만들고, 로딩 화면 뒤에서 동네 전체를 GPU 에 한 번 올린다 (`engine.warmUp`). 새 실내는 셰이더와 텍스처가 준비된 뒤에 보인다
- 움직이지 않는 건물, 땅, 나무는 행렬을 한 번만 계산한다 (`places.freeze`, 움직이는 것은 `userData.dynamic`)
- 동네 사람은 가까이 갈 때 한 프레임에 한 명씩 만들고, 먼 사람은 장면에서 뺀다. 머리, 손, 머리카락처럼 같은 모양은 한 번만 만든다
- 코드로 그리는 텍스처는 웹 워커 여러 개가 동시에 만든다 (`texgen.js`, `texworker.js`)

- `src/town.js` 같이 사는 동네(연결, 다른 사람, 채팅, 차단, 신고), `online.mjs` 그 규칙(칸 이름, 위치, 숨김, 혼자 블럭 지키기), `online.test.mjs`
- `src/wildlife.js` 숲의 반달가슴곰(숲 칸, 날마다 일정, 행동), `src/props/bear.js` 곰 모델과 움직임, `bear-check.mjs` 곰 검사
- `kid-check.mjs` 어린이 이야기 자동 검사, `job-check.mjs` 직업 6개의 하루 자동 검사, `login-check.mjs` 로그인 검사(로컬 net 서버), `online-check.mjs` 같이 사는 동네 검사(로컬 net 서버, 두 컴퓨터)
- `src/props/*.js` 자동차, 사람, 나무와 꽃, 가로등과 벤치, 블럭
- `src/world.js` 땅, 도로, 바다와 건물 자리, `src/deco.js` 나무와 거리 소품 배치
- `src/sites/plaza.js` 분수 광장, `src/fountain.js` 분수 물(물줄기, 물방울, 물결, 물속 조명), `src/show.js` 금요일 공연(사람, 조명, 분수 춤, 동전 소원), `src/show-music.js` 공연 노래
- `src/player.js`, `src/vehicle.js`, `src/build.js`, `src/quests.js`, `src/life.js` 걷기, 운전, 블럭, 하루와 미니게임, 동네 사람과 차
- `viewer.html` 모델 하나만 보는 개발용 화면 (빌드에는 안 들어감), `tools/shot.mjs` 화면 사진
- `src/perf.js` 다 짓고 나서 하는 최적화(고정, 안개 컬링, AO 에서 뺄 것), `src/texgen.js` 텍스처 픽셀, `src/texworker.js` 그걸 다른 코어에서
- `perf-check.mjs` 속도 재기: 시작 시간, 자리별 프레임 시간, 그리기 호출, 삼각형, 메모리, 큰길을 달릴 때 끊김

## 시험

```bash
npm run test:social-game
npm run social-game:dev            # 다른 터미널
node games/social-game/browser-check.mjs http://127.0.0.1:5173/ /tmp/social-shots
node games/social-game/kid-check.mjs http://127.0.0.1:5173/ /tmp/social-kid
node games/social-game/show-check.mjs http://127.0.0.1:5173/ /tmp/social-show   # 분수 광장과 공연 (약 3분)
node games/social-game/bear-check.mjs http://127.0.0.1:5173/ /tmp/social-bear
node games/social-game/bug-check.mjs http://127.0.0.1:5173/ /tmp/social-bugs            # 곤충 채집과 도감 (약 4분)
node games/social-game/job-check.mjs http://127.0.0.1:5173/ /tmp/social-jobs            # 직업 하나만: 끝에 police,fire
# 로그인과 같이 사는 동네는 로컬 net 서버가 있어야 한다 (저장소 AGENTS.md "시험해 보기" 1번). 계정을 2~3개 만든다.
node games/social-game/login-check.mjs http://127.0.0.1:5173/ /tmp/social-login
node games/social-game/online-check.mjs http://127.0.0.1:5173/ /tmp/social-online
# 속도 재기: 빌드(npm run social-game:build) 후 public/ 에서 정적 서버를 띄우고
node games/social-game/perf-check.mjs http://127.0.0.1:5275/play/social-game/ /tmp/social-perf
```

playwright 가 `tools/node_modules` 에 없으면 `PLAYWRIGHT_MJS=<playwright 의 index.mjs 경로>` 를 붙인다.
검사는 기다리는 시간을 `window.__game.day.timeScale` 로 빨리 감는다(검사 전용, 주소 뒤 `?fast=60` 도 같음).

그림, 모델, 소리는 모두 코드로 새로 만들었다. 저장은 브라우저(localStorage)에만 한다.
