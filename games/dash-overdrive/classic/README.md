# DASH / OVERDRIVE · CLASSIC

`/play/dash-overdrive`(처음 열면 CLASSIC이 나옵니다. 예전 HARD EDITION은 왼쪽 위 "← HARD EDITION"), `/play/dash-overdrive/classic` (Next.js) 또는 `/play/dash-overdrive/classic/index.html`에서 실행합니다.

## 게임

- 시작 화면은 인혁이가 손으로 그린 설계대로 SKINS, PLAY, CREATE 세 버튼이고, 뒤에서 모든 스킨의 큐브가 지나갑니다.
- 1~15단계는 모두 새로 만든 맵입니다. 큐브 점프, 점프 패드, 점프 링, 비행선, 중력 뒤집기가 나오고 뒤로 갈수록 어려워집니다. 노래가 신나지는 부분에서 비행선이, 조용해지는 부분에서 중력 뒤집기가 나옵니다.
- 단계마다 코인이 3개 있고, 단계를 끝까지 깨야 저장됩니다. 코인을 10개, 20개, 30개, 40개, 50개 모으면 비밀 단계 16 Golden Key, 17 Secret Core, 18 Last Dash, 19 Volt Rush, 20 Endless Dash가 하나씩 열립니다.
- 인혁이 손그림 계획 2번("지메에 있는 모든 블럭, 더블점프, 포탈 등을 다 만들어줘")으로 모드와 물건을 더 만들었습니다. 그림, 숫자, 맵은 모두 이 게임에서 새로 정한 것입니다.
  - 공 (빨강 포털): 바닥이나 천장을 굴러가고, 바닥이나 천장에 닿아 있을 때 누르면 중력이 뒤집혀 반대쪽으로 갑니다. 공중에서는 링으로만 바꿀 수 있습니다. 조금 일찍 눌러서 꾹 누르고 있으면 닿는 순간 뒤집힙니다. 중력 2.2, 뒤집을 때 처음 속도 12, 가장 빠른 속도 44 (1/60초 기준, 큐브는 중력 3.456).
  - UFO (노랑 포털): 누를 때마다 위로 톡 뜨고(공중에서도), 중력이 다시 끌어내립니다. 블록 위에는 서고, 블록 옆에 부딪히면 비행선처럼 죽습니다. 뜨는 힘 30, 중력 2.3, 떨어지는 속도는 30까지.
  - 웨이브 (청록 포털): 누르고 있으면 45도로 위로, 떼면 45도로 아래로 갑니다. 몸통 판정은 가운데 작은 칸(1/3 크기)뿐이라 좁은 길도 지나가고, 바닥, 천장, 블록 윗면과 아랫면을 미끄러져 가고, 블록 옆이나 가시에 닿으면 죽습니다. 뒤에 스킨 색 꼬리가 짧게 남았다가 사라집니다.
  - 공, UFO, 웨이브 포털은 비행선 포털처럼 바닥과 천장을 만들고, 큐브 포털과 비행선 포털은 어느 모드에서나 됩니다. 모든 모드가 중력 뒤집기(노랑, 파랑 포털, 파랑 링, 파랑 패드)를 따릅니다.
  - 속도 문 (화살표 1~4개): 느림 0.8배, 보통 1배, 빠름 1.25배, 아주 빠름 1.5배. 배경도 같이 빨라지거나 느려지고, 처음부터 다시 하면 보통 속도로 돌아갑니다.
  - 분홍 링: 노랑 링보다 작게 뜁니다(32, 노랑은 44.72). 파랑 링: 누르면 중력이 뒤집히면서 새 방향으로 살짝 밀립니다(12).
  - 분홍 패드: 작게 튑니다(42, 노랑 패드는 64). 파랑 패드: 닿으면 중력이 뒤집히면서 살짝 밀립니다(16). 패드마다 한 번만 뒤집습니다.
  - 웨이브는 노랑, 분홍 링과 패드를 그냥 지나가고, 파랑 링과 파랑 패드로는 중력이 뒤집힙니다.
  - 큐브가 파랑 링이나 파랑 패드로 거꾸로 되면 노랑 포털처럼 천장이 생깁니다.
  - 연습 모드 체크포인트는 모드, 속도, 중력을 같이 저장합니다.
  - 공과 UFO는 고른 스킨을 공의 둥근 창과 UFO의 유리 컵 안에 보여 주고, 웨이브는 스킨 색으로 물듭니다. 죽으면 어느 모드에서나 스킨 색 가루가 떨어집니다.
- 웨이브는 1단계부터 나옵니다(인혁이 부탁: "웨이브 1단계부터 나오게 해줘"). 1~18단계마다 노래의 한 부분(대부분 신나기 시작하는 build 부분)에 웨이브 구간이 하나씩 있고, 그 부분이 시작할 때 웨이브 포털이 나옵니다. 모두 보통 속도이고, 비행선과 중력 뒤집기 구간은 그대로입니다.
  - 1단계: 포털 뒤에 장애물 없는 긴 길(16칸)이 먼저 있어서 누르면 올라가고 떼면 내려가는 것을 익힙니다. 문은 6칸이나 열려 있고 가시가 없습니다.
  - 2~4단계: 문이 5칸 열려 있고, 문 높이가 조금씩 바뀝니다. 4단계부터 문 끝에 가시가 가끔 있습니다.
  - 5~12단계: 문이 4칸 열려 있고, 오르막과 내리막이 생기고 가시가 몇 개 있습니다.
  - 13~18단계: 문이 3칸 열려 있고, 바닥과 천장에 작은 가시가 깔립니다. 그래도 큐브 구간에서 가장 좁은 박자 창보다 좁지 않게, 손이 2~4프레임 늦어도 지나가는지 로봇으로 확인했습니다.
- 19단계 Volt Rush와 20단계 Endless Dash에서 새 모드와 물건을 만납니다. 노래의 부분(시작, 신나는 부분, 조용한 부분)마다 정해 둔 모드가 나오고, 그 부분이 시작할 때 속도 문이 있습니다.
  - 19단계: 분홍 링과 분홍 패드, 빠른 공, 파랑 패드로 천장에 올라갔다가 파랑 링으로 내려오기, 비행선, 느린 UFO, 빠른 웨이브.
  - 20단계: 빠른 공, 비행선, 느린 UFO, 파랑 패드와 파랑 링, 빠른 웨이브, 느린 공, 아주 빠른 웨이브. 화살표 4개짜리 속도 문은 여기서 나옵니다.
- 21단계 DASH AND RUN (인혁이가 지은 이름): 처음부터 열려 있고, 어려움은 "더 어려움"(Harder)입니다. 큐브로 달리다가 노래 부분마다 비행선, 공, 웨이브, UFO로 바뀌고, 신나는 부분에서는 한 부분 안에서 모드 두 개를 이어서 지나갑니다. 모드 사이에는 짧은 큐브 길이 있습니다. 신나는 부분은 빠른 속도, 조용한 부분은 느린 속도로 파랑 패드와 파랑 링을 지나고, 마지막 신나는 부분은 아주 빠른 속도로 공과 웨이브를 합니다. 맵과 노래(D 단조, 155.79 BPM, 108초)는 이 게임에서 새로 만들었습니다. 처음 깨면 25번째 스킨(하늘색 머리띠를 맨 주황색 달리기 큐브)이 열립니다. 같이 하기에서도 고를 수 있습니다(모두에게 열려 있는 단계라서).
- 비행선에서 큐브로 돌아가는 포털은 위아래가 블록으로 막혀 있고, 큐브는 포털 높이의 블록 발판에 내립니다. 비행선과 중력 구간이 끝나면 천장이 위로 밀려 올라갑니다.
- 스킨 31가지 중 하나를 고르면 이 브라우저에 저장됩니다. 4가지는 처음부터 있고, 21가지는 1~21단계를 처음 깰 때마다 하나씩 열리고, 6가지(크리스탈, 판다, 우주인, 수박, 번개, 쿠키)는 다이아몬드로 삽니다. 스킨 고르는 화면은 한 줄에 11칸이고, 짧은 마지막 줄은 가운데에 놓입니다. 상점 스킨의 잠긴 칸에는 다이아몬드와 값(10)이 나옵니다.
- 인혁이 손그림 계획 3("지오매트리 대쉬")으로 단계를 100개로 늘리고, 나의 레벨과 다이아몬드와 스킨 상점을 만들었습니다.
  - 22~100단계(79개)는 코인으로 여는 게 아니라 처음부터 열려 있습니다("이 레벨은 코인으로 여는 게 아니야"). 단계마다 1~21단계 노래 중 하나를 쓰고, 그 노래의 부분(시작, 신나는 부분, 조용한 부분)에 맞춰 모드가 바뀝니다. 22~31단계 쉬움과 보통, 32~46 어려움, 47~61 더 어려움, 62~79 아주 어려움, 80~100 데몬이고, 빠른 단계일수록 신나는 부분에 빠른 속도 문이 있습니다. 모든 단계에 웨이브가 나옵니다. 이름(예 Lunar Tower), 색, 맵은 모두 이 게임에서 새로 만들었습니다.
  - 나의 레벨("나의 레벨 8레벨" 그림): 단계를 처음 깨면 어려움에 따라 경험치를 받고(쉬움 20, 보통 30, 어려움 40, 더 어려움 50, 아주 어려움 60, 데몬과 비밀 80), 코인 하나마다 10을 더 받습니다. 경험치 100이면 레벨이 하나 오릅니다. 저장된 기록(최고 기록 100%와 코인)으로 그때그때 계산해서, 기록과 어긋나지 않습니다. 위쪽 막대에 작게, 단계 선택 화면 왼쪽에 크게 나옵니다.
  - 다이아몬드: 나의 레벨이 5, 10, 15, 20…이 될 때마다 10개씩 받습니다. 레벨이 오르면 "레벨 업!"과 받은 다이아몬드가 알림으로 나옵니다.
  - 스킨 상점(💎 단추): 다이아몬드 10개로 스킨을 하나씩 삽니다. 산 스킨은 바로 쓰고, SKINS 화면에서도 고를 수 있습니다. 산 스킨은 `dash-classic:2`(한 칸에 한 비트)에 저장되고, 엔진은 `classic_refresh_skins`, `classic_select_skin`으로 다시 읽고 고릅니다.
  - 22~100단계 기록은 `dash-classic:<1000|2000|3000 + 단계 번호 - 1>`에 저장됩니다(1~21단계와 맵 만들기는 예전 칸 그대로).
  - 같이 하기에서 비밀 단계 16~20을 뺀 모든 단계를 고를 수 있습니다. 맵 만들기 칸은 101번째(엔진 번호 100)입니다.
- CREATE(맵 만들기)에서 블록, 반 블록, 가시, 작은 가시, 점프 패드, 분홍 패드, 파랑 패드, 점프 링, 분홍 링, 파랑 링, 비행선, 큐브, 공, UFO, 웨이브 포털, 중력 포털, 속도 문 4가지(느린 속도, 보통 속도, 빠른 속도, 아주 빠른 속도), 코인을 놓고 노래와 색을 고른 뒤 바로 해 볼 수 있습니다. 만든 맵은 이 브라우저에 저장되고, 맵 코드(DOC1.)로 친구에게 보낼 수 있습니다.
- 👥 같이 하기: 방 만들기를 누르면 방 코드 6글자가 나오고, 친구가 그 코드로 들어옵니다(나까지 4명). 방장이 1~15단계 중 하나를 골라 같이 시작하면 모두 같은 단계를 동시에 달리고, 친구들은 반투명하게 보이고(큐브, 비행선, 공, UFO, 웨이브 모양 그대로) 왼쪽에 각자 몇 %까지 갔는지 나옵니다. 위치 메시지에 모드(`m`, 0 큐브 1 비행선 2 공 3 UFO 4 웨이브)와 속도 문(`v`, 0~3)을 같이 보냅니다. 공용 서버 `@inhyuk/net`의 `Room`(게임 이름 `dash-classic`)을 쓰고, 방 코드 방에는 로그인, 채팅, 이름이 없습니다. 비밀 단계는 혼자 할 때만 열립니다.
- 👤 로그인 (인혁이 기획 1번, 10번): 닉네임과 비밀번호로 로그인하거나 새 계정을 만듭니다. seonn.dev의 모든 게임이 같은 계정(`@inhyuk/net`의 `Account`)을 쓰고, 로그인은 젤리 타워처럼 이 브라우저(`inhyuk-net-session`)에 남습니다. `?net=` 시험 서버의 로그인은 다른 이름으로 저장해서 진짜 서버로 가지 않습니다.
- 친구: 닉네임으로 찾아 친구 요청을 보내고, 받은 요청은 수락하거나 거절합니다. 친구 목록에 접속 중인지 나옵니다.
- 친구 채팅: 접속 중인 친구의 "💬 채팅"을 누르면 친구 화면에 "같이 놀재!"가 뜨고, 친구가 "좋아!"를 누르면 두 사람만 들어오는 방(`social.invite`, `social.acceptInvite`)에서 이야기합니다. 사람이 쓴 글은 `room.chat`으로만 보내서 서버가 욕, 전화번호, 주소를 가리고, 상대 이름은 서버가 준 닉네임만 씁니다. 한 번에 4줄, 그다음 1초에 1줄까지 보냅니다(서버는 5줄, 1초에 1줄). 채팅 화면에 🚫 차단과 🚨 신고 단추가 있습니다.
- 🏁 같이 달리기: 채팅 화면이나 친구 목록에서 누르면 같이 하기 방을 만들고, 방 코드를 글자 대신 숫자로 친구에게 보냅니다. 친구가 "들어가기"를 누르면 같은 방에 들어가고, 그다음은 같이 하기와 같습니다.
- 키보드로 1 3 5 7 0을 차례로 누르면 제작자 모드가 켜지고, 다시 누르면 꺼집니다. 제작자 모드에서는 비밀 단계가 모두 열리고, 가시나 블록에 닿아도 죽지 않고, 히트박스가 색 칸으로 보입니다. 이때 깬 기록과 코인은 저장하지 않습니다.
- Space / 클릭 / 터치로 점프하고, 비행선은 누르고 있으면 올라갑니다. 공은 눌러서 뒤집고, UFO는 누를 때마다 뜨고, 웨이브는 누르고 있으면 올라갑니다. Esc로 일시정지하고, 연습 모드에서는 Z로 체크포인트를 놓고 X로 지웁니다.

## 폴더

- `engine/`: 게임 엔진(C++, SDL2). Vincent Li의 [Bad-GD-Clone](https://github.com/VinkentLi/Bad-GD-Clone)(MIT)을 고쳐서 씁니다. 충돌 판정, 비행선과 중력 구간의 바닥과 천장, 시작 화면, 스킨 화면, 노래 내려받기, 기록 저장, 맵 검사용 함수를 바꾸거나 더했습니다.
- `res/`: 엔진에 들어가는 그림(`gfx`), 효과음(`sfx`), 맵(`leveldata`), 글꼴(`fonts`). 모두 아래 스크립트로 만듭니다.
- `art/art.mjs`: 그림을 SVG로 그려서 PNG로 만듭니다.
- `music/music.mjs`: 노래와 효과음을 코드로 합성합니다. 단계 노래는 `public/play/dash-overdrive/classic/music/`에 저장되고, 단계를 시작할 때 내려받습니다.
- `levels/generate.mjs`: 100단계 맵(비밀 단계 5개 포함)과 코인 자리를 만듭니다. 22~100단계의 이름, 노래, 어려움, 색, 계획도 여기서 정합니다(`EXTRA_TIERS`). 19~100단계는 노래 부분마다 모드와 속도를 적은 계획(`plan`)을 따르고, 속도 문을 지나면 박자가 떨어지는 칸도 다시 계산해서 노래와 맞춥니다. 공, UFO, 웨이브 구간도 늦게 반응하거나 조금 빗나가게 조종하는 로봇이 통과해야 남고, 60, 120, 144Hz가 모두 같은 높이, 모드, 속도로 끝나는 조각만 남깁니다. `node levels/generate.mjs 19 20 21`처럼 단계를 골라 만들 수 있고, 1~18단계 파일은 그대로 둡니다. 21단계는 계획에 `tune`(어려움 번호, 9는 10단계 Lava Lift와 같은 조율), `seed`(맵을 고르는 씨앗 수), `modes`(한 노래 부분 안에서 차례로 지나갈 모드와 칸 수)를 씁니다. 씨앗 수는 `verify.mjs`가 144Hz와 90Hz에서도 통과하는 것으로 골랐습니다. `levels/physics.mjs`는 엔진의 움직임과 충돌 코드를 그대로 옮긴 것이라, 맵을 만들 때 모든 점프 시점을 실제로 해 보고 충분히 여유가 있는 장애물만 남깁니다. 비행선 구간은 늦게 반응하거나 조금 빗나가게 조종해도 통과해야 남습니다.
- `levels/add-wave.mjs`: 1~18단계에 웨이브 구간을 하나씩 넣습니다. 맵을 새로 만들지 않고, 웨이브를 넣기 전 맵(커밋 `a45c1ee`의 파일)에서 노래 한 부분의 칸 몇십 개만 잘라 내고 그 자리에 웨이브를 만듭니다. 자르는 처음과 끝은 큐브가 아무것도 누르지 않고 땅 위에 서 있는 곳이라, 잘라 낸 곳 밖의 블록, 가시, 코인, 색 바뀜은 하나도 바뀌지 않고 노래 박자도 그대로입니다. 잘라 낸 곳 안에 있던 코인은 웨이브가 지나가는 길로 옮깁니다. 녹화한 입력도 잘라 낸 곳 앞과 뒤는 그대로 쓰고, 웨이브 구간만 새로 확인한 입력으로 바꿉니다.
- `levels/extra.mjs`: 22~100단계를 만들고, 단계마다 `verify.mjs`가 모든 화면 속도에서 끝까지 깨는 첫 씨앗 수를 골라 `levels/extra-seeds.json`에 적습니다. 그다음부터 `generate.mjs`는 같은 맵을 만듭니다.
- `levels/level-list.mjs`: 단계 이름, 어려움, 노래 번호를 엔진(`engine/include/LevelList.h`)과 페이지(`public/play/dash-overdrive/classic/level-list.js`)에 씁니다. `integrity.test.mjs`가 둘이 맞는지 확인합니다.
- `levels/verify.mjs`: 만든 맵을 처음부터 끝까지 60, 90, 120, 144Hz 화면 시간으로 다시 깨 보고, 코인 3개를 모두 먹는지 확인합니다. `--engine`을 붙이면 빌드한 WebAssembly 엔진에서도 확인합니다.
- `build.sh`: emsdk로 엔진을 빌드해 `public/play/dash-overdrive/classic/engine/`에 넣습니다.
- `sync-net.mjs`: 공용 방 클라이언트(`packages/net`)를 `public/play/dash-overdrive/classic/net-client/`에 그대로 복사합니다. `integrity.test.mjs`가 둘이 같은지 확인합니다.
- `online-check.mjs`: 내 컴퓨터의 방 서버(`services/net`, 8787)로 두 사람이 같은 방에서 같이 달리는지 확인합니다.
- `social-check.mjs`: 내 컴퓨터의 방 서버(빈 DB로 새로 띄운 것)에 계정 두 개를 만들어 친구 요청, 수락, 채팅, 보내는 속도 제한, 전화번호 가리기, 차단과 신고, 같이 달리기, 다시 열어도 남는 로그인, 로그아웃을 확인합니다. 계정을 만드는 시험이라 진짜 서버로는 돌리지 않습니다. `BASE_URL=http://127.0.0.1:<public 폴더 서버 포트> node games/dash-overdrive/classic/social-check.mjs`
- 페이지 쪽 파일은 `public/play/dash-overdrive/classic/`의 `social-ui.mjs`(로그인, 친구, 채팅 화면)와 `net.mjs`(같이 하기와 같이 쓰는 서버 주소, 게임 이름)입니다.

## 다시 만드는 순서

```bash
node games/dash-overdrive/classic/art/art.mjs
node games/dash-overdrive/classic/music/music.mjs
node games/dash-overdrive/classic/levels/generate.mjs 19 20 21
node games/dash-overdrive/classic/levels/extra.mjs
node games/dash-overdrive/classic/levels/level-list.mjs
node games/dash-overdrive/classic/levels/add-wave.mjs
games/dash-overdrive/classic/build.sh
node games/dash-overdrive/classic/levels/verify.mjs --engine
```

- 1~18단계는 `generate.mjs`로 다시 만들지 않습니다. 저장소의 1~18단계 파일은 조금 예전 만들기 코드로 만든 것이라, 번호 없이 `generate.mjs`를 돌리면 그중 몇 개가 달라지고 웨이브도 없어집니다. 1~18단계는 `add-wave.mjs`가 `a45c1ee`의 파일에서 다시 만들고, 몇 번을 돌려도 같은 파일이 나옵니다.
