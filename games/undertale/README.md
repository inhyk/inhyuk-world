# UNDERTALE · 세 갈래의 결말

언더테일의 세계를 폐허에서 왕좌의 방까지 압축한 비공식 팬 게임. 캐릭터 원작은 Toby Fox이며, 대사, 픽셀 스프라이트, 맵, 실시간 합성 음악은 모두 이 게임을 위해 새로 만들었습니다. 외부 이미지, 폰트, 음악 다운로드 없이 실행됩니다.

루트에서 `npm run dev` 후 **http://localhost:3000/play/undertale** 에서 플레이합니다. 독립 실행 파일은 `public/play/undertale/`에 있으며 정적 서버에서도 실행할 수 있습니다. 원작 시스템을 어떻게 분석하고 옮겼는지는 [ANALYSIS.md](ANALYSIS.md)에 정리했습니다.

## 조작

- 방향키 / WASD: 이동, 메뉴 선택, 전투 중 영혼 이동
- Z / Enter / Space: 확인, 대화, 공격 타이밍
- X / Esc: 취소, 대화 빨리 넘기기, 전투 중 일시정지(Esc)
- C: 오버월드 메뉴(아이템 사용·장비 교체·스탯 확인)
- Shift: 정밀 이동(오버월드 느리게 걷기, 전투 중 느린 영혼)
- M: 음소거
- 모바일: 터치 방향 패드와 C / X / Z 버튼

## 전투

- **공격**: 움직이는 바가 중앙에 왔을 때 Z. 중앙에 가까울수록 배율이 높고, 놓치면 MISS.
- **행동**: 몬스터마다 다른 대화 행동. 알맞은 행동을 하면 이름이 노랗게 변하고 살려보낼 수 있습니다.
- **아이템**: 회복 아이템을 먹거나 무기·방어구를 바꿉니다. 가방은 8칸.
- **자비**: 노란 이름이면 살려주기. 일반 몬스터는 도망치기도 가능합니다.
- 빨간 영혼은 자유 이동, 파란 영혼은 중력이 있어 ↑로 점프, 초록 영혼은 방향키로 방패를 돌려 화살을 막습니다.
- 파란 탄막은 멈추면 안 맞고, 주황 탄막은 움직이면 안 맞습니다. 초록 탄막은 HP를 회복합니다.
- 몬스터가 둘 나오면 두 마리가 같은 턴에 각자의 탄막을 동시에 씁니다. 한 마리를 먼저 살려보내거나 쓰러뜨리면 남은 한 마리만 공격합니다.
- 걷는 중에 `-` 키를 누르면 모든 방으로 바로 이동할 수 있습니다.
- 걷는 중에 숫자 `12345678901015`를 차례로 치면 샌즈·아스리엘·플라위 보스전을 골라 바로 싸울 수 있습니다.
- 걷는 중에 숫자 `13570`을 치면 LV를 +1 / +10 / +100 중에서 골라 올릴 수 있고 HP가 가득 찹니다. 상한 없이 반복할 수 있습니다.

## 루트와 결말

- **불살**: 아무도 죽이지 않고 왕좌의 방까지 가면 토리엘이 난입하고 아스리엘과의 마지막 싸움 뒤 결계가 무너집니다.
- **몰살**: 폐허·설원·폭포·열지대에서 각각 6명을 죽여 "아무도 오지 않았다"를 띄우고 보스를 모두 처치하면 심판의 회랑에서 샌즈와 싸웁니다. 몰살 뒤에는 세이브가 지워지고 세계가 사라지며, 다시 실행하면 영혼을 넘기는 계약으로만 돌아올 수 있습니다. 파피루스를 살려주면 몰살 루트가 즉시 깨집니다.
- **중립**: 그 외 모든 경우. 아스고어와 플라위를 상대한 뒤 누가 살아남았는지에 따라 샌즈의 전화 내용이 달라집니다.
- 영혼을 넘긴 뒤의 불살 결말은 마지막 문장이 달라집니다.

## 세이브

- 반짝이는 별에서 Z를 누르면 HP가 회복되고 로컬 저장소 `undertale-fan-save`에 저장됩니다.
- 죽으면 마지막 세이브로 돌아갑니다. 세이브가 없으면 이름만 유지한 채 처음부터 시작합니다.
- 결말 달성 기록, 세계 소멸 상태, 영혼 계약, 소리 설정은 `undertale-fan-meta`에 남습니다.
- 타이틀의 "새로 시작"은 기존 세이브를 지우기 전에 한 번 더 묻습니다.

## 검증

`npm run test:undertale`로 전투 상태 기계와 루트 판정, 오버월드 이동·이벤트를 검증합니다. `node games/undertale/browser-check.mjs`는 실제 브라우저에서 타이틀·이름 짓기·플라위 도입부·전투를 돌려 보고 화면 사진을 찍습니다. `window.render_game_to_text()`는 브라우저에서 현재 모드, 플레이어, 방, 전투 상태를 JSON으로 읽는 자동화용 인터페이스입니다.

## 크레딧

언더테일과 등장 캐릭터의 원작은 Toby Fox입니다. 이 게임은 팬이 만든 비공식 작품이며 원작의 이미지, 음악, 대사를 사용하지 않았습니다.
