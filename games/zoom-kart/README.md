# 씽씽 카트 · 드리프트 레이싱

직접 만든 3D 카트 레이싱 게임. 선수, 카트, 트랙, 아이템, 소리 모두 이 게임만의 것이고 코드로 그렸다. 개발 작업 트리: `zoom-kart-20261115`.

- ← → (A D): 운전. ↑ (W): 달리기. ↓ (S): 멈추기, 뒤로. Shift (Space): 드리프트. Ctrl (Z, X, E): 아이템이나 부스터 쓰기. R: 트랙 가운데로 돌아오기. Esc (P): 잠깐 멈춤.
- 휴대폰: 화면 버튼(◀ ▶, 드리프트, 아이템, 멈춤). 달리기는 자동.
- 경기 방식 (`MODES`)
  - 아이템전: 상자를 먹으면 아이템 6가지(로켓 부스터, 미끌 젤리, 따라가 꿀벌, 눈덩이, 방울 방패, 먹구름) 중 하나. 뒤에 있을수록 좋은 것이 잘 나온다 (`rollItem`).
  - 스피드전: 드리프트로 게이지를 채우면 부스터가 생긴다 (두 개까지).
  - 혼자 기록 재기: 혼자 달리며 한 바퀴, 완주 최고 기록에 도전.
- 드리프트를 0.7초 넘게 하고 놓으면 순간 부스터(파랑, 주황, 보라 3단계). 출발 직전에 달리기를 누르면 출발 부스터.
- 트랙 6개 (`TRACKS`): 말랑 숲 서킷, 반짝 모래 해변, 눈꽃 고개, 네온 시티, 부글부글 화산, 무지개 구름길. 앞 트랙에서 3등 안에 들면 다음 트랙이 열린다.
- 선수 8명, 카트 5대(코인으로 산다). 컴퓨터 난이도 3단계. 1등이 들어오고 15초 안에 못 들어오면 시간 초과.
- 규칙 계산은 `core.mjs` (화면 없이 테스트 가능), 화면은 `main.js`, 풍경은 `src/scene.js`, 카트 모양은 `src/models.js`, 소리는 `src/audio.js`.
- 같이 하기: 공용 서버 방 코드(`Room`, game `zoom-kart`, 4명까지, 로그인 없음, `src/net.js`). 방장이 대기실에서 고른 트랙과 방식(아이템전, 스피드전)으로 출발하고 빈자리는 컴퓨터가 채운다.
  - 자기 카트는 자기가 계산하고, 컴퓨터 카트는 방장이 계산한다. 위치는 1초에 12번 묶어서 보낸다 (`snapOf`, `applySnap`). 아이템 쓰기, 맞음, 골인은 따로 한 번씩 보낸다.
  - 맞았는지는 맞는 카트의 주인이 정한다. 사람이 쓴 글은 보내지 않고 선수 번호, 카트 번호, 위치 같은 숫자만 보낸다.
  - 방장이 나가면 새 방장이 컴퓨터 카트를 이어받고(`setHost`), 연결이 끊기면 혼자 이어서 달린다. 같이 하기로는 코인만 받고 트랙은 열리지 않는다.
  - 로컬 서버 시험은 주소 뒤에 `?net=http://127.0.0.1:8787`. 확인: `node games/zoom-kart/online-check.mjs`.
- 진행은 localStorage `zoom-kart-save-v1` 에 저장.
- `?debug=1` 일 때만 브라우저 시험용 `window.__kart` 를 공개.

저장소 루트에서 실행:

```sh
npm run zoom-kart:dev -- --port 5198
npm run test:zoom-kart
npm run zoom-kart:build
```

허브 경로는 `/play/zoom-kart`, 빌드 산출물은 `public/play/zoom-kart/` 이며 Git 에서 제외한다.

브라우저 확인은 `npm install --prefix tools` 후 개발 서버를 켜고 `node games/zoom-kart/browser-check.mjs` 로 실행한다. 대기실, 잠긴 트랙, 출발, 드리프트, 아이템, 멈춤, 트랙 6개 화면, 골인과 결과, 휴대폰 화면을 확인하고 사진을 `artifacts/zoom-kart/` 에 남긴다.
