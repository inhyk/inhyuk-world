# 젤리 타워 · JELLY TOWER

인혁이의 손글씨 기획서(12가지)와 두 번째 기획서 「업그레이드 2」(7가지)로 만든 연쇄 퍼즐 게임. 사이트에서는 `/play/puyo-puyo`에서 플레이하고, 아이폰 앱은 [apps/jelly-tower](../../apps/jelly-tower/README.md)에서 만듭니다.

처음 이름은 「뿌요뿌요 타워」였습니다. 앱스토어에 내려면 다른 회사(SEGA)의 게임 이름을 쓸 수 없어서 2026-10-04에 인혁이가 고른 **젤리 타워**로 바꾸고, 게임 안의 "뿌요"도 모두 "젤리"로 바꿨습니다. 저장 키(`puyo-tower-v1`)·온라인 방 이름·폴더 이름은 예전 기록과 웹·앱 사이 온라인 대전이 그대로 이어지도록 바꾸지 않았습니다. 예전 `PUYO1.` 기록 코드도 그대로 가져올 수 있습니다.

## 실행

- `npm run puyo-puyo:dev`: 게임 개발 서버 (http://127.0.0.1:5190)
- `npm run puyo-puyo:build`: 사이트용 파일을 `public/play/puyo-puyo`에 빌드
- `npm run test:puyo-puyo`: 규칙·AI·로그인·챌린지·상점·타워 테스트
- `node games/puyo-puyo/browser-check.mjs`: 실제 Chrome에서 로그인 → 타워 → 엔딩 → 모바일 버튼까지 확인 (`PUYO_URL`로 주소 변경)
- `node games/puyo-puyo/practice-browser-check.mjs`: 연습하기 3단계를 키보드와 휴대폰 버튼으로 끝까지
- `node games/puyo-puyo/reset-browser-check.mjs`: 제작자 모드에서 잊은 계정 비밀번호 다시 정하기 → 바로 들어가기
- `node games/puyo-puyo/offline-chat-browser-check.mjs`: 친구가 게임을 꺼 둔 동안 친구 신청·메시지·젤리 이모티콘·이모지 → 켜면 도착 (사이트 빌드 + `JELLY_MAIL_MEMORY=1 next start`에서)
- `node games/puyo-puyo/social-browser-check.mjs`: 두 사람(서로 다른 저장소)으로 방 채팅·친구 신청·친구 채팅·초대·차단을 PeerJS 연결 서버를 거쳐 끝까지
- `node games/puyo-puyo/rounds-browser-check.mjs`: AI 대전·2인 플레이·온라인 대전에서 10·25·30·40·50판까지 고르기 (온라인은 두 창을 실제로 연결)
- `node games/puyo-puyo/app-browser-check.mjs`: 가짜 Capacitor로 앱 전용 기능(시작 그림, 기기 저장소에 같이 저장·되살리기, 진동, 계정 지우기) 확인

## 기획서 12가지와 구현

1. **뿌요뿌요의 모든 걸 분석해서 만들기**
   - 뿌요뿌요 통 규칙을 그대로: 6×12 필드와 숨은 13번째 줄, 14번째 줄에 놓으면 사라짐, 3열 12단 X에 쌓이면 패배
   - 두 개 짝, 다음·다다음 표시, 256개 주머니로 섞는 젤리 순서(첫 두 짝은 3색), 두 사람이 같은 순서
   - 벽 차기, 바닥 차기, 좁은 틈 퀵턴, 흩어지는 젤리(ちぎり), 소프트드롭 1칸 1점
   - 점수 공식(연쇄·색·연결 보너스), 70점당 방해 젤리, 상쇄, 전소 보너스, 96초 뒤 마진 타임
   - 자세한 분석은 [ANALYSIS.md](ANALYSIS.md)
2. **2인 플레이와 온라인**
   - 한 키보드 2인 플레이 (1P WASD + Q·Space, 2P 방향키 + / · Enter), 태블릿은 양쪽 버튼
   - 온라인 대전: 방 만들기 → 6글자 코드 → 친구가 들어오기, 선취 1·2·3·5·10·25·30·40·50판, “한 번 더!”
3. **AI를 깨는 타워**
   - 한 번 이길 때마다 한 층씩, 순서는 방해 젤리 순서 그대로: 작은 젤리 → 큰 젤리 → 운석 → 별 → 달 → 왕관
   - 층마다 주인 캐릭터와 대사(꼬마 젤리, 왕방울, 운석 골렘 쿵쿵, 별빛 마법사 반짝이, 달토끼 루나, 젤리 대왕)
4. **올라갈수록 AI가 세지게**
   - 층이 높을수록 더 멀리 내다보고(1수 → 3수), 더 큰 연쇄를 참았다가 터뜨리고, 손이 빨라지고, 실수가 줄어듦
   - AI끼리 12판씩 붙여 보면 모든 층에서 위층이 이김 (9:3, 9:3, 11:1, 11:1, 10:2, 12:0)
   - 같은 층에서 지면 “도움” 단계가 올라가서 그 층 AI 손이 조금씩 느려짐 (최대 4단계)
5. **seonn.dev에 올리기**: 사이트 카드와 `/play/puyo-puyo` 페이지
6. **레벨**: 판마다 경험치, 레벨업하면 코인 보상, 상점 물건은 레벨이 되어야 살 수 있음
7. **챌린지 (미션)**
   - ★ 표시: 기획서 예시 “타워에서 5연쇄 하기”
   - 타워 연쇄 2·3·5·7·10연쇄, 전소, 상쇄, 운석·별 만들기, 층 깨기 등 처음 32가지에서 업그레이드 2로 151가지 + 날마다 바뀌는 오늘의 미션 3개
8. **로그인**
   - 닉네임 + 비밀번호로 계정 만들기 (이 기기에 저장, 비밀번호는 해시로 저장)
   - 계정마다 레벨·코인·스킨·타워·챌린지가 따로, “기록 코드”로 다른 기기에 옮기기, 손님으로도 가능
9. **상점**: 젤리 스킨 20종(모양·젤리·사탕·고양이·과일·보석·픽셀·행성·네온·유령·황금 왕관에 업그레이드 2의 토끼·곰돌이·로봇·도넛·꽃송이·꼬마 드래곤·우주인·오로라 갑옷)과 터질 때 효과 19종
10. **엔딩**: 왕관 층을 깨면 왕관 받기 → 탑 꼭대기 불꽃놀이 → 층 주인들의 축하 → 만든 사람 → THE END, 그리고 비밀의 혜성 층이 열림
11. **모바일**: 화면 버튼(◀ ▼ ▶ ⤓ ↺ ↻), 필드 쓸기(좌우로 끌기, 톡 치면 회전, 아래로 휙), 세로·가로 화면 모두 배치
12. **효과음**: 가로·세로로 돌릴 때 “뿅”, 터질 때 연쇄가 커질수록 높아지는 소리, 그 밖에 착지·방해 젤리·상쇄·전소·승리 소리와 배경음악 4곡

## 업그레이드 2 (두 번째 손글씨 기획서 7가지)

1. **혜성 엔딩을 더 길게**: 30초 → 7장 70초. 새 친구 → 은하수 여행 → 잠든 별 → 우정의 일곱 빛깔 연쇄 → 타워의 축하 → 별의 문 → 우주의 친구들. 마지막 장면이 다음 보스로 이어집니다.
2. **혜성 다음 보스**: 비밀의 「초신성 층」과 별의 수호자 노바 (AI 레벨 8). 혜성 층을 깨야 열리고, 처음 이기면 오로라 갑옷 스킨과 초신성 폭발 효과를 받습니다. AI 대전에서도 고를 수 있습니다.
3. **상점에 스킨과 터짐 효과 추가**
   - 스킨 8종: 토끼, 곰돌이, 로봇, 도넛, 꽃송이, 꼬마 드래곤, 우주인, 오로라 갑옷(노바 보상)
   - 터짐 효과 6종: 나비 정원, 축하 폭죽, 드래곤 불꽃, 별빛 오르골, 차원 문, 초신성 폭발(노바 보상)
4. **2인 플레이 맵 고르기, 맵마다 다른 특징** (`maps.mjs`)
   - 젤리 정원: 4색 · 같은 색 4개 · 기본 속도
   - 느긋한 빙하: 낙하 속도 55%
   - 불꽃 화산: 낙하 속도 160%
   - 무지개 섬: 5색
   - 별빛 우주: 3색 · 50점마다 방해 젤리 · 낙하 속도 80%
   - 쫀득 연구소: **같은 색 6개를 모아야 터짐** · 낙하 속도 75%
   - 두 사람에게 같은 젤리 순서와 같은 규칙이 적용되고, 고른 맵은 계정에 저장됩니다.
5. **챌린지를 엄청 많이**: 32개 → 151개. 연쇄·누적 터뜨리기·방해 젤리·전소·상쇄, 판 수·승리, 혼자 하기 점수, 레벨, 맵 탐험, 선물 받기, 스킨·효과 수집, 타워 승리. 챌린지 화면에서 종류별로 골라 볼 수 있습니다.
6. **seonn 광고**: 게임을 5번 끝낼 때마다 결과 화면에 「seonn을 플레이하세요! 40개의 게임을 무료로 플레이하실 수 있습니다!」 포스터가 나옵니다. 기획서 그림대로 오른쪽 위 단추가 「5초 뒤에 ✕」에서 1초씩 줄어들고, 다 세면 눌러서 닫습니다. 같은 판 수에서는 새로고침해도 다시 나오지 않습니다 (`promo.mjs`).
7. **스핀·일일 보상·시간 보상에 다른 보상 추가**: 코인·경험치에 더해 🎨 스킨 교환권, ✨ 효과 교환권, 🎟️ 추가 스핀권. 교환권은 상점에서 레벨·코인 없이 판매 상품 하나와 바꾸고(보스 보상은 제외), 추가 스핀권은 오늘의 무료 스핀을 쓴 뒤 한 번 더 돌립니다. 생일 10배는 코인에만 적용되고 교환권 수는 그대로입니다.

## 연습하기 (처음 하는 사람)

메뉴의 **🐣 연습하기**(처음에는 NEW 표시)나 하는 방법 화면의 단추로 시작합니다. 필드 위에 꼬마 젤리 말풍선이 뜨고, 필드는 말풍선 아래로 내려가서 가려지지 않습니다 (`tutorial.mjs`).

1. 옮기고 돌리기: 젤리 짝을 3번 내려놓기. 휴대폰이면 화면 버튼 모양(◀ ▶ ↻ ⤓), 키보드면 키 이름으로 알려 줍니다.
2. 같은 색 4개면 퐁: 바닥의 빨강 2개 옆이나 위에 빨강 짝을 붙이면 터집니다.
3. 연쇄 만들기: 빨강을 맨 왼쪽 줄에 놓으면 빨강이 터지고 떨어진 초록이 또 터지는 2연쇄.

두 번 놓치거나 1연쇄에서 멈추면 꼬마 젤리가 "다시 해 보자"라며 판을 되돌립니다. 처음 끝내면 🪙100과 경험치 50을 한 번만 주고, 바로 1층 꼬마 젤리에게 도전할 수 있습니다.

## 채팅과 친구

- **온라인 대전 채팅**: 로비의 💬 채팅, 게임 중에는 위쪽 💬 단추(오른쪽 위 작은 창). 빠른 말 8개(👋 안녕! 👍 잘한다! …)는 번호로만 보내고, 직접 쓴 말은 60글자까지. 게임 중에 온 말은 화면 위쪽 말풍선으로 잠깐 보인다. 이번 판 채팅 끄기가 있다.
- **친구**: 계정마다 6글자 친구 코드(0·O·1·I 없음). 친구 코드를 넣어 신청하고, 상대가 받으면 친구가 된다 (이미 나를 친구로 둔 사람이거나 서로 신청했으면 바로). 30명까지. 받은 신청과 보낸 신청은 계정에 저장된다.
- **친구 우체통 (게임을 꺼 두었어도 채팅)**: 메시지·젤리 이모티콘·친구 신청은 사이트의 `/api/jelly-mail`(서버: `src/lib/jelly-mail/mailbox.mjs`, 저장소: Vercel에 연결한 Upstash Redis)에 맡긴다. 친구가 게임을 켜면(친구 기능을 쓴 계정은 로그인할 때, 그 뒤 40초마다, 친구 화면·친구 채팅에서는 8초마다) 받아 가고, 받은 편지는 다음 요청에서 지운다. 안 받아 가도 7일 뒤 지운다. 둘 다 켜 두었으면 직접 연결로 "편지 왔어"(ring)를 보내서 바로 받는다.
  - 친구 코드마다 32글자 열쇠(기기에만 저장, 기록 코드에는 함께 담김)의 해시를 서버가 맡아서, 열쇠가 맞아야 보내거나 열 수 있다. 보낸 사람은 서버가 확인한 코드다. 계정을 지우면 열쇠와 우체통도 지운다.
  - 서버도 나쁜 말을 가리고 전화번호·이메일을 거절하고, 보내기는 1분 20통·하루 300통, 우체통은 100통까지.
  - 저장소가 없으면(개발 서버, 연결 전) `{ ok: false, error: "off" }`를 받고 예전처럼 둘 다 켜 두었을 때만 직접 연결로 보낸다.
- **친구 채팅·초대**: 친구 목록에서 💬 채팅, 둘 다 켜 두었으면 🎮 같이 하기(방을 만들고 코드를 보내면 친구 채팅에 [들어가기]가 뜬다). 대화는 이 기기에 친구마다 최근 50개만 남는다.
- **이모티콘**: 채팅 창의 😊 단추 → 젤리 이모티콘 12개(게임 캐릭터를 그려서 만든 그림, 번호로만 주고받아 나쁜 말이 섞일 수 없다)는 누르면 바로 보내지고, 이모지 40개는 글에 들어간다. 이모지만 1~3개면 크게 보인다. 글자 수는 이모지 하나를 한 글자로 센다. 온라인 대전 채팅에서도 된다.
- **안전**: 나쁜 말은 보내기 전과 받을 때 모두 ♡로 가린다 (띄어쓰기·점·초성으로 숨겨도). 전화번호·이메일은 보내지 않는다. 5초에 5개까지만 보내고, 받는 쪽도 넘치면 버린다. 🚫 차단(조용히 연결을 끊고 상대에게 알리지 않음), 🚩 신고(최근 대화 복사 + 문의 안내), 내 정보 → 설정의 채팅 끄기. 손님은 친구 기능을 쓸 수 없다.
- 보낸 사람은 메시지 내용이 아니라 연결 이름(`puyo-tower-v1-f-친구코드`)으로 알아내서 다른 사람인 척할 수 없다. 둘이 동시에 연결하면 작은 코드 쪽이 건 연결 하나만 남긴다 (`friendnet.mjs`).
- 규칙은 `chat.mjs`, 친구 연결은 `friendnet.mjs`, 우체통 쪽은 `mailbox.mjs`(게임)와 `src/lib/jelly-mail/mailbox.mjs`(서버).
- 검사: `node --test games/puyo-puyo/mailbox.test.mjs`(서버 규칙), `offline-chat-browser-check.mjs`(사이트를 빌드해서 `JELLY_MAIL_MEMORY=1 next start`로 띄운 뒤 두 사람이 번갈아 껐다 켜기).

## 아이폰 앱에서만 다른 것

`platform.mjs`가 앱(Capacitor) 안인지 알아보고, 웹에서는 아무 일도 하지 않습니다.

- 시작 그림: 첫 화면을 그린 다음에 걷습니다.
- 저장: localStorage에 저장하면서 기기 저장소(Preferences)에도 같이 적고, 아이폰이 웹 저장소를 비우면 앱을 켤 때 되살립니다.
- 진동: 터뜨리기(연쇄가 클수록 세게)·방해 젤리·전소·승패·레벨 업·챌린지 완료. 내 정보 → 설정에서 끌 수 있습니다.
- 계정 지우기: 내 정보 맨 아래 (앱스토어 규칙). 웹에서도 됩니다.
- 사이트로 가는 「← 인혁 월드」 링크는 숨기고, 다이내믹 아일랜드·홈 막대 자리를 비웁니다.
- 글꼴: Jua를 게임 안에 넣어서 인터넷 없이도 같은 모양으로 나옵니다. 본문은 기기 글꼴(애플 산돌고딕, 맑은 고딕)을 씁니다.

## 조작

## 파일

- `core.mjs`: 규칙 엔진 (필드, 짝, 회전, 연쇄, 점수, 방해 젤리)
- `ai.mjs`, `ai-worker.js`: AI (웹 워커에서 생각)
- `match.mjs`: 라운드·선취·방해 젤리 주고받기·온라인 판정
- `render.mjs`, `skins.mjs`, `effects.mjs`, `characters.mjs`: 화면
- `audio.mjs`: 효과음과 배경음악 (Web Audio로 직접 합성)
- `profile.mjs`, `missions.mjs`, `shop.mjs`, `tower.mjs`: 계정·레벨·챌린지·상점·타워
- `online.mjs`, `room.mjs`: PeerJS 온라인 대전
- `calendar.mjs`, `rewards.mjs`, `creator.mjs`: 한국 달력·날짜 배율·매일 선물·제작자 도구
- `maps.mjs`, `promo.mjs`: 2인 플레이 맵 규칙, 5판마다 나오는 seonn 광고
- `tutorial.mjs`: 연습하기 3단계와 성공·다시 판정
- `chat.mjs`, `friendnet.mjs`: 채팅 규칙(나쁜 말·개인정보·속도), 친구 코드와 친구끼리 직접 잇기
- `platform.mjs`: 아이폰 앱에서만 하는 일 (진동, 기기 저장소, 시작 그림)
- `ending.mjs`: 왕관·혜성 엔딩
- `main.js`, `index.html`, `style.css`: 화면 흐름

`window.render_game_to_text()`는 브라우저 검증용 상태를 돌려주고, 주소에 `?test`를 붙이면 `window.__puyo` 도우미가 생깁니다.

캐릭터, 그림, 음악은 모두 코드로 직접 그리고 만든 것입니다. 같은 색을 이어 터뜨리는 연쇄 퍼즐(SEGA의 뿌요뿌요 같은 게임)에서 영감을 받았지만, 이름·캐릭터·그림·소리는 모두 젤리 타워만의 것입니다.
