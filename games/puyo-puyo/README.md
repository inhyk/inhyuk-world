# 뿌요뿌요 타워 · PUYO PUYO TOWER

인혁이의 손글씨 기획서(12가지)와 두 번째 기획서 「업그레이드 2」(7가지)로 만든 뿌요뿌요 팬 게임. 사이트에서는 `/play/puyo-puyo`에서 플레이합니다.

## 실행

- `npm run puyo-puyo:dev`: 게임 개발 서버 (http://127.0.0.1:5190)
- `npm run puyo-puyo:build`: 사이트용 파일을 `public/play/puyo-puyo`에 빌드
- `npm run test:puyo-puyo`: 규칙·AI·로그인·챌린지·상점·타워 테스트
- `node games/puyo-puyo/browser-check.mjs`: 실제 Chrome에서 로그인 → 타워 → 엔딩 → 모바일 버튼까지 확인 (`PUYO_URL`로 주소 변경)

## 기획서 12가지와 구현

1. **뿌요뿌요의 모든 걸 분석해서 만들기**
   - 뿌요뿌요 통 규칙을 그대로: 6×12 필드와 숨은 13번째 줄, 14번째 줄에 놓으면 사라짐, 3열 12단 X에 쌓이면 패배
   - 두 개 짝, 다음·다다음 표시, 256개 주머니로 섞는 뿌요 순서(첫 두 짝은 3색), 두 사람이 같은 순서
   - 벽 차기, 바닥 차기, 좁은 틈 퀵턴, 흩어지는 뿌요(ちぎり), 소프트드롭 1칸 1점
   - 점수 공식(연쇄·색·연결 보너스), 70점당 방해뿌요, 상쇄, 전소 보너스, 96초 뒤 마진 타임
   - 자세한 분석은 [ANALYSIS.md](ANALYSIS.md)
2. **2인 플레이와 온라인**
   - 한 키보드 2인 플레이 (1P WASD + Q·Space, 2P 방향키 + / · Enter), 태블릿은 양쪽 버튼
   - 온라인 대전: 방 만들기 → 6글자 코드 → 친구가 들어오기, 선취 1·2·3·5판, “한 번 더!”
3. **AI를 깨는 타워**
   - 한 번 이길 때마다 한 층씩, 순서는 방해뿌요 순서 그대로: 작은 뿌요 → 큰 뿌요 → 운석 → 별 → 달 → 왕관
   - 층마다 주인 캐릭터와 대사(꼬마 뽀요, 왕방울, 운석 골렘 쿵쿵, 별빛 마법사 반짝이, 달토끼 루나, 뿌요 대왕)
4. **올라갈수록 AI가 세지게**
   - 층이 높을수록 더 멀리 내다보고(1수 → 3수), 더 큰 연쇄를 참았다가 터뜨리고, 손이 빨라지고, 실수가 줄어듦
   - AI끼리 12판씩 붙여 보면 모든 층에서 위층이 이김 (9:3, 9:3, 11:1, 11:1, 10:2, 12:0)
   - 같은 층에서 지면 “도움” 단계가 올라가서 그 층 AI 손이 조금씩 느려짐 (최대 4단계)
5. **seonn.dev에 올리기**: 사이트 카드와 `/play/puyo-puyo` 페이지
6. **레벨**: 판마다 경험치, 레벨업하면 코인 보상, 상점 물건은 레벨이 되어야 살 수 있음
7. **챌린지 (미션)**
   - ★ 표시: 기획서 예시 “타워에서 5연쇄 하기”
   - 타워 연쇄 2·3·5·7·10연쇄, 전소, 상쇄, 운석·별 만들기, 층 깨기 등 처음 32가지에서 업그레이드 2로 151가지 + 날마다 바뀌는 오늘의 미션 3개
8. **로그인**
   - 닉네임 + 비밀번호로 계정 만들기 (이 기기에 저장, 비밀번호는 해시로 저장)
   - 계정마다 레벨·코인·스킨·타워·챌린지가 따로, “기록 코드”로 다른 기기에 옮기기, 손님으로도 가능
9. **상점**: 뿌요 스킨 20종(모양·젤리·사탕·고양이·과일·보석·픽셀·행성·네온·유령·황금 왕관에 업그레이드 2의 토끼·곰돌이·로봇·도넛·꽃송이·꼬마 드래곤·우주인·오로라 갑옷)과 터질 때 효과 19종
10. **엔딩**: 왕관 층을 깨면 왕관 받기 → 탑 꼭대기 불꽃놀이 → 층 주인들의 축하 → 만든 사람 → THE END, 그리고 비밀의 혜성 층이 열림
11. **모바일**: 화면 버튼(◀ ▼ ▶ ⤓ ↺ ↻), 필드 쓸기(좌우로 끌기, 톡 치면 회전, 아래로 휙), 세로·가로 화면 모두 배치
12. **효과음**: 가로·세로로 돌릴 때 “뿅”, 터질 때 연쇄가 커질수록 높아지는 소리, 그 밖에 착지·방해뿌요·상쇄·전소·승리 소리와 배경음악 4곡

## 업그레이드 2 (두 번째 손글씨 기획서 7가지)

1. **혜성 엔딩을 더 길게**: 30초 → 7장 70초. 새 친구 → 은하수 여행 → 잠든 별 → 우정의 일곱 빛깔 연쇄 → 타워의 축하 → 별의 문 → 우주의 친구들. 마지막 장면이 다음 보스로 이어집니다.
2. **혜성 다음 보스**: 비밀의 「초신성 층」과 별의 수호자 노바 (AI 레벨 8). 혜성 층을 깨야 열리고, 처음 이기면 오로라 갑옷 스킨과 초신성 폭발 효과를 받습니다. AI 대전에서도 고를 수 있습니다.
3. **상점에 스킨과 터짐 효과 추가**
   - 스킨 8종: 토끼, 곰돌이, 로봇, 도넛, 꽃송이, 꼬마 드래곤, 우주인, 오로라 갑옷(노바 보상)
   - 터짐 효과 6종: 나비 정원, 축하 폭죽, 드래곤 불꽃, 별빛 오르골, 차원 문, 초신성 폭발(노바 보상)
4. **2인 플레이 맵 고르기, 맵마다 다른 특징** (`maps.mjs`)
   - 뿌요 정원: 4색 · 같은 색 4개 · 기본 속도
   - 느긋한 빙하: 낙하 속도 55%
   - 불꽃 화산: 낙하 속도 160%
   - 무지개 섬: 5색
   - 별빛 우주: 3색 · 50점마다 방해뿌요 · 낙하 속도 80%
   - 쫀득 연구소: **같은 색 6개를 모아야 터짐** · 낙하 속도 75%
   - 두 사람에게 같은 뿌요 순서와 같은 규칙이 적용되고, 고른 맵은 계정에 저장됩니다.
5. **챌린지를 엄청 많이**: 32개 → 151개. 연쇄·누적 터뜨리기·방해뿌요·전소·상쇄, 판 수·승리, 혼자 하기 점수, 레벨, 맵 탐험, 선물 받기, 스킨·효과 수집, 타워 승리. 챌린지 화면에서 종류별로 골라 볼 수 있습니다.
6. **seonn 광고**: 게임을 5번 끝낼 때마다 결과 화면에 「seonn을 플레이하세요! 40개의 게임을 무료로 플레이하실 수 있습니다!」 포스터가 나옵니다. 기획서 그림대로 오른쪽 위 단추가 「5초 뒤에 ✕」에서 1초씩 줄어들고, 다 세면 눌러서 닫습니다. 같은 판 수에서는 새로고침해도 다시 나오지 않습니다 (`promo.mjs`).
7. **스핀·일일 보상·시간 보상에 다른 보상 추가**: 코인·경험치에 더해 🎨 스킨 교환권, ✨ 효과 교환권, 🎟️ 추가 스핀권. 교환권은 상점에서 레벨·코인 없이 판매 상품 하나와 바꾸고(보스 보상은 제외), 추가 스핀권은 오늘의 무료 스핀을 쓴 뒤 한 번 더 돌립니다. 생일 10배는 코인에만 적용되고 교환권 수는 그대로입니다.

## 제작자 모드와 매일 선물

- 메뉴 → **제작자 모드** → 비밀번호 `7777777`. 왕관 층까지 타워 깨기(혜성 층 열기), 레벨 50으로 올리기, 모든 챌린지·오늘의 미션 완료, 모든 스킨·터짐 효과 해제. 이미 받은 챌린지 보상은 다시 받을 수 없고, 레벨 50 이상은 유지합니다. 제작자 잠금 해제는 저장하지 않아 새로고침·로그아웃하면 다시 인증합니다.
- 매년 **5월 12일** 인혁이 생일에는 획득 포인트(상점 코인) **10배**. 레벨업 코인, 경기·챌린지·출석·스핀·시간 보상에 적용됩니다.
- **한국 공휴일은 경험치 2배**. 양력 공휴일, 한국 음력 설날·부처님 오신 날·추석, 대체공휴일, 일요일과 등록된 임시공휴일·선거일을 포함합니다. 생일과 공휴일이 겹치면 코인 10배와 경험치 2배가 각각 적용됩니다. 경기의 연쇄 점수·방해뿌요 규칙은 그대로입니다.
- **무료 스핀**: 하루 1회. 여섯 칸의 확률은 각 1/6이며 당첨 결과는 애니메이션 전에 지급·저장하여 새로고침에도 보존됩니다.
- **일일 출석**: 100·150·200·250·300·400·700 코인과 경험치를 받는 7일 순환. 연속 출석을 쉬면 1일째부터 시작합니다.
- **시간 보상**: 하루 실제 플레이 5·15·30분에 각각 100·200·400 코인과 경험치. 메뉴·AI 시범·일시정지·대사·엔딩·결과·숨긴 탭은 제외합니다. 계정은 15초마다 진행 시간이 저장되며 창 숨김·종료 시에도 저장합니다.
- 모든 날짜는 **한국 시간 자정** 기준이고, 보상 기록은 계정 저장·기록 코드에 포함됩니다. 손님 기록은 기존처럼 브라우저 세션에서만 유지됩니다.
- **혜성 엔딩 「우주의 친구들」**: 혜성 층을 이기면 코멧과 우주를 날고 일곱 층 주인들의 축하를 받은 뒤 노바를 만나는 두 번째 엔딩(7장 70초)이 재생됩니다. 타워에서 왕관·혜성 엔딩을 각각 다시 볼 수 있습니다. 첫 혜성 승리의 꼬리 효과 보상은 한 번만 받습니다.

달력 기준은 [관공서의 공휴일에 관한 규정](https://www.law.go.kr/lsInfoP.do?lsId=002404) 및 [인사혁신처 공휴일 발표](https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?mode=list&searchCondition=title&searchKeyword=%EA%B3%B5%ED%9C%B4%EC%9D%BC) (2026-10 확인)입니다. 음력은 브라우저의 Dangi 달력을 이용하며 2026년부터 노동절·제헌절을 반영합니다. 새 임시공휴일·선거일은 `calendar.mjs`의 `EXTRA`에 추가합니다.

## 조작

- 혼자·AI·타워·온라인: ←→ 옮기기, ↓ 빨리 내리기, ↑·X 오른쪽 돌리기, Z 왼쪽 돌리기, Space 바로 떨어뜨리기, Esc 일시정지 (WASD·Q도 됨)
- 2인 플레이: 1P A·D·S, W 오른쪽 돌리기, Q 왼쪽 돌리기, Space 바로 떨어뜨리기 / 2P ←→↓, ↑ 오른쪽 돌리기, / 왼쪽 돌리기, Enter 바로 떨어뜨리기

## 파일

- `core.mjs`: 규칙 엔진 (필드, 짝, 회전, 연쇄, 점수, 방해뿌요)
- `ai.mjs`, `ai-worker.js`: AI (웹 워커에서 생각)
- `match.mjs`: 라운드·선취·방해뿌요 주고받기·온라인 판정
- `render.mjs`, `skins.mjs`, `effects.mjs`, `characters.mjs`: 화면
- `audio.mjs`: 효과음과 배경음악 (Web Audio로 직접 합성)
- `profile.mjs`, `missions.mjs`, `shop.mjs`, `tower.mjs`: 계정·레벨·챌린지·상점·타워
- `online.mjs`, `room.mjs`: PeerJS 온라인 대전
- `calendar.mjs`, `rewards.mjs`, `creator.mjs`: 한국 달력·날짜 배율·매일 선물·제작자 도구
- `maps.mjs`, `promo.mjs`: 2인 플레이 맵 규칙, 5판마다 나오는 seonn 광고
- `ending.mjs`: 왕관·혜성 엔딩
- `main.js`, `index.html`, `style.css`: 화면 흐름

`window.render_game_to_text()`는 브라우저 검증용 상태를 돌려주고, 주소에 `?test`를 붙이면 `window.__puyo` 도우미가 생깁니다.

캐릭터, 그림, 음악은 모두 코드로 직접 그리고 만든 것입니다. 뿌요뿌요는 SEGA의 게임이며, 이 게임은 인혁이가 좋아서 만든 비상업 팬 게임입니다.
