# 뿌요뿌요 타워 · PUYO PUYO TOWER

인혁이의 손글씨 기획서(12가지)와 그 뒤의 업그레이드 기획서들(업그레이드 2, 3, 4)로 만든 연쇄 퍼즐 게임. 사이트에서는 `/play/puyo-puyo`에서 플레이하고, 아이폰 앱은 [apps/jelly-tower](../../apps/jelly-tower/README.md)에서 만듭니다.

이름이 두 가지입니다. 사이트(seonn.dev)는 **뿌요뿌요 타워**, 아이폰·안드로이드 앱은 **젤리 타워**입니다.

처음 이름은 「뿌요뿌요 타워」였습니다. 앱스토어에 내려면 다른 회사(SEGA)의 게임 이름을 쓸 수 없어서(가이드라인 5.2) 2026-10-04에 인혁이가 고른 「젤리 타워」로 바꾸고 게임 안의 "뿌요"도 모두 "젤리"로 바꿨습니다. 그 뒤 2026-10-06에 인혁이가 사이트는 다시 「뿌요뿌요 타워」와 "뿌요"로 돌려 달라고 해서(업그레이드 3의 1번), 지금은 코드와 화면 글을 모두 "뿌요"로 적고 **앱에 넣는 빌드(vite mode `app`)에서만** 눈에 보이는 "뿌요"를 "젤리"로 바꿉니다 (`brand.mjs`). 저장 키(`puyo-tower-v1`)·폴더 이름은 예전 기록이 그대로 이어지도록 바꾸지 않았습니다. 예전 `PUYO1.` 기록 코드도 그대로 가져올 수 있습니다.

## 실행

- `npm run puyo-puyo:dev`: 게임 개발 서버 (http://127.0.0.1:5190)
- `npm run puyo-puyo:build`: 사이트용 파일을 `public/play/puyo-puyo`에 빌드
- `npm run test:puyo-puyo`: 규칙·AI·로그인·챌린지·상점·타워 테스트
- `node games/puyo-puyo/browser-check.mjs`: 실제 Chrome에서 로그인 → 타워 → 엔딩 → 모바일 버튼까지 확인 (`PUYO_URL`로 주소 변경)
- `node games/puyo-puyo/practice-browser-check.mjs`: 연습하기 3단계를 키보드와 휴대폰 버튼으로 끝까지
- `node games/puyo-puyo/reset-browser-check.mjs`: 제작자 모드에서 잊은 이 기기 계정 비밀번호 다시 정하기 → 바로 들어가기
- `node games/puyo-puyo/offline-chat-browser-check.mjs`: 이 기기 계정끼리 친구가 게임을 꺼 둔 동안 친구 신청·메시지·뿌요 이모티콘·이모지 → 켜면 도착 (사이트 빌드 + `JELLY_MAIL_MEMORY=1 next start`에서)
- `node games/puyo-puyo/social-browser-check.mjs`: 이 기기 계정 두 사람(서로 다른 저장소)으로 방 코드 채팅·친구 신청·친구 채팅·초대·차단을 PeerJS 연결 서버를 거쳐 끝까지
- `node games/puyo-puyo/chat-layout-browser-check.mjs`: 채팅 칸이 넘칠 만큼 긴 친구 채팅에서 뿌요 이모티콘·글이 겹치지 않고, 열 때와 이모티콘 판을 열 때 맨 아래 메시지가 보이는지 (컴퓨터·휴대폰 크기)
- `node games/puyo-puyo/rounds-browser-check.mjs`: AI 대전·2인 플레이·온라인 대전에서 10·25·30·40·50판까지 고르기 (온라인은 `PUYO_NET=http://127.0.0.1:8787` 처럼 로컬 net 서버가 있을 때만 두 창을 실제로 연결)
- `node games/puyo-puyo/online-browser-check.mjs`: 온라인 계정 전체 (아래 "온라인 계정, 친구, 채팅, 클라우드 저장")
- `node games/puyo-puyo/cloud-errors-browser-check.mjs`: 클라우드 저장이 실패할 때 (옮기기 중 충돌이 끝나지 않음 → 다시 해 보기, 기기 저장소 꽉 참, 413 too-big) 저장된 것처럼 보이지 않는지 (`PUYO_NET` 이 없으면 로컬 net 서버를 띄움)
- `node games/puyo-puyo/app-browser-check.mjs`: 가짜 Capacitor로 앱 전용 기능(시작 그림, 기기 저장소에 같이 저장·되살리기, 진동, 계정 지우기) 확인
- `node games/puyo-puyo/watch-ranking-browser-check.mjs`: 업그레이드 3. Chrome 세 창으로 게임 찾기 대전 → 세 번째 사람이 관전 목록에서 골라 관전(닉네임·레벨·점수) → 이기면 "🏆 트로피 +1" → 온라인 랭킹 3개와 내 순위 → 5등 안이라 챔피언 스킨 → 친구 목록의 「👀 관전」, 손님은 로그인 안내 (net 서버는 빈 로컬 D1 로 스스로 띄우고, 이미 띄운 서버는 `PUYO_NET`)
- `node games/puyo-puyo/upgrade4-browser-check.mjs`: 업그레이드 4. 펫 화면이 기획서 그림과 같은 자리·같은 글인지 → 뽑기 → 시간 선물 7개와 펫 뽑기권 → 2배 부스트 → AI 대전·혼자 하기 맵 → 배우기 초급~최상급 문제를 실제로 풀기 → Chrome 두 창으로 친구 배수, 친구 선물(접속 중, 꺼 둔 동안, 한 번만), 온라인 맵 투표 (net 서버는 빈 로컬 D1 로 스스로 띄우고, 이미 띄운 서버는 `PUYO_NET`)
- `node games/puyo-puyo/graduation-browser-check.mjs`: 배우기의 졸업 ~ 졸업10 (열 등급 776가지)을 실제 Chrome 에서 처음부터 끝까지. 발화점 찾기의 도움말, 쌓기 안내, 초대연쇄, 졸업장, 등급 선물까지 (서버 없이 손님으로. 등급 하나에 7~20분쯤이라 `PUYO_GRADES=grad6` 처럼 등급을 골라 여러 창에서 같이 돌리면 빠릅니다)
- `node games/puyo-puyo/upgrade5-browser-check.mjs`: 업그레이드 5. 효과음·배경음악 ON/OFF(메뉴, 내 정보, 일시정지, 저장) → 새 챌린지 묶음 → 처음 인사 「하이와 친구가 되어 주세요!」 → Chrome 네 창으로 온라인 상대 필드가 매 프레임 움직이는지 → 관전 응원(화이팅, 좋아요)·관전 채팅·친구 요청, 관전자 차단·신고, 예전 서버일 때 안내 (`PUYO_NET` 이 없으면 로컬 net 서버를 띄움, 3분쯤)
- `node games/puyo-puyo/upgrade6-browser-check.mjs`: 업그레이드 6. 새 노래(16마디) → 배경음악 단추 연속 5번 이스터에그로 예전 노래, 저장, 다시 5번에 새 노래 → 새 스킨 12가지를 사서 끼고 대전 → 광고 보고 코인 1000(10초, 하루 3번)과 펫 뽑기권 → 배우기 목록의 "N가지"와 목록 안 스크롤 (서버 없이 손님으로, 2분쯤)
- `node games/puyo-puyo/upgrade7-browser-check.mjs`: 업그레이드 7. 혜성을 처음 깬 엔딩이 1장부터 나오는지(그리기 시각이 앞설 때도) → 대전 화면의 하늘 아침·낮·저녁·밤과 맵·모드별 배경 → 방해 뿌요 힘겨루기 막대(컴퓨터, 휴대폰) → 새 스킨 12가지를 사서 끼고 한 판 → Chrome 두 창으로 온라인 로비에서 캐릭터 고르기, 대전 화면의 두 캐릭터, 온라인 힘겨루기 (`PUYO_NET` 이 없으면 로컬 net 서버를 띄움, 2분쯤)
- `npm run test:net`: net 서버(`services/net`)와 클라이언트 라이브러리(`packages/net`) 테스트. 랭킹·관전·온라인 승리 세기는 `services/net/test/stats.test.js`
- `node apps/jelly-tower/scripts/build-web.mjs`: 앱용 빌드(이름은 「젤리 타워」). 끝나고 `www` 를 훑어서 "뿌요"가 하나라도 남아 있으면 오류로 멈춥니다

## 기획서 12가지와 구현

1. **뿌요뿌요의 모든 걸 분석해서 만들기**
   - 뿌요뿌요 통 규칙을 그대로: 6×12 필드와 숨은 13번째 줄, 14번째 줄에 놓으면 사라짐, 3열 12단 X에 쌓이면 패배
   - 두 개 짝, 다음·다다음 표시, 256개 주머니로 섞는 뿌요 순서(첫 두 짝은 3색), 두 사람이 같은 순서
   - 벽 차기, 바닥 차기, 좁은 틈 퀵턴, 흩어지는 뿌요(ちぎり), 소프트드롭 1칸 1점
   - 점수 공식(연쇄·색·연결 보너스), 70점당 방해 뿌요, 상쇄, 전소 보너스, 96초 뒤 마진 타임
   - 자세한 분석은 [ANALYSIS.md](ANALYSIS.md)
2. **2인 플레이와 온라인**
   - 한 키보드 2인 플레이 (1P WASD + Q·Space, 2P 방향키 + / · Enter), 태블릿은 양쪽 버튼
   - 온라인 대전: 온라인 계정은 방 코드 없이 "게임 찾기"(먼저 기다린 사람과 바로)나 친구 초대, 이 기기 계정과 손님은 방 만들기 → 6글자 코드. 선취 1·2·3·5·10·25·30·40·50판, “한 번 더!”, 대전 채팅
3. **AI를 깨는 타워**
   - 한 번 이길 때마다 한 층씩, 순서는 방해 뿌요 순서 그대로: 작은 뿌요 → 큰 뿌요 → 운석 → 별 → 달 → 왕관
   - 층마다 주인 캐릭터와 대사(꼬마 뿌요, 왕방울, 운석 골렘 쿵쿵, 별빛 마법사 반짝이, 달토끼 루나, 뿌요 대왕)
4. **올라갈수록 AI가 세지게**
   - 층이 높을수록 더 멀리 내다보고(1수 → 3수), 더 큰 연쇄를 참았다가 터뜨리고, 손이 빨라지고, 실수가 줄어듦
   - AI끼리 12판씩 붙여 보면 모든 층에서 위층이 이김 (9:3, 9:3, 11:1, 11:1, 10:2, 12:0)
   - 같은 층에서 지면 “도움” 단계가 올라가서 그 층 AI 손이 조금씩 느려짐 (최대 4단계)
5. **seonn.dev에 올리기**: 사이트 카드와 `/play/puyo-puyo` 페이지
6. **레벨**: 판마다 경험치, 레벨업하면 코인 보상, 상점 물건은 레벨이 되어야 살 수 있음
7. **챌린지 (미션)**
   - ★ 표시: 기획서 예시 “타워에서 5연쇄 하기”
   - 타워 연쇄 2·3·5·7·10연쇄, 전소, 상쇄, 운석·별 만들기, 층 깨기 등 처음 32가지에서 업그레이드 2로 151가지, 업그레이드 5로 240가지 남짓 + 날마다 바뀌는 오늘의 미션 3개
8. **로그인**
   - 닉네임 + 비밀번호로 온라인 계정 만들기 (서버에 저장, 이메일 없음, 비밀번호를 잊으면 되찾을 수 없음). 손님으로도 가능
   - 계정마다 레벨·코인·스킨·타워·챌린지가 따로 저장되고 다른 기기에서 로그인하면 이어서
   - 예전에 이 기기에만 만든 계정은 그대로 들어가거나 온라인 계정으로 옮김 (“기록 코드”도 그대로 가져올 수 있음)
9. **상점**: 뿌요 스킨 20종(모양·젤리·사탕·고양이·과일·보석·픽셀·행성·네온·유령·황금 왕관에 업그레이드 2의 토끼·곰돌이·로봇·도넛·꽃송이·꼬마 드래곤·우주인·오로라 갑옷)과 터질 때 효과 19종 (업그레이드 3에서 스킨 33종, 효과 21종으로 늘었습니다)
10. **엔딩**: 왕관 층을 깨면 왕관 받기 → 탑 꼭대기 불꽃놀이 → 층 주인들의 축하 → 만든 사람 → THE END, 그리고 비밀의 혜성 층이 열림
11. **모바일**: 화면 버튼(◀ ▼ ▶ ⤓ ↺ ↻), 필드 쓸기(좌우로 끌기, 톡 치면 회전, 아래로 휙), 세로·가로 화면 모두 배치
12. **효과음**: 가로·세로로 돌릴 때 “뿅”, 터질 때 연쇄가 커질수록 높아지는 소리, 그 밖에 착지·방해 뿌요·상쇄·전소·승리 소리와 배경음악 4곡

## 업그레이드 2 (두 번째 손글씨 기획서 7가지)

1. **혜성 엔딩을 더 길게**: 30초 → 7장 70초. 새 친구 → 은하수 여행 → 잠든 별 → 우정의 일곱 빛깔 연쇄 → 타워의 축하 → 별의 문 → 우주의 친구들. 마지막 장면이 다음 보스로 이어집니다.
2. **혜성 다음 보스**: 비밀의 「초신성 층」과 별의 수호자 노바 (AI 레벨 8). 혜성 층을 깨야 열리고, 처음 이기면 오로라 갑옷 스킨과 초신성 폭발 효과를 받습니다. AI 대전에서도 고를 수 있습니다.
3. **상점에 스킨과 터짐 효과 추가**
   - 스킨 8종: 토끼, 곰돌이, 로봇, 도넛, 꽃송이, 꼬마 드래곤, 우주인, 오로라 갑옷(노바 보상)
   - 터짐 효과 6종: 나비 정원, 축하 폭죽, 드래곤 불꽃, 별빛 오르골, 차원 문, 초신성 폭발(노바 보상)
4. **2인 플레이 맵 고르기, 맵마다 다른 특징** (`maps.mjs`)
   - 뿌요 정원: 4색 · 같은 색 4개 · 기본 속도
   - 느긋한 빙하: 낙하 속도 55%
   - 불꽃 화산: 낙하 속도 160%
   - 무지개 섬: 5색
   - 별빛 우주: 3색 · 50점마다 방해 뿌요 · 낙하 속도 80%
   - 쫀득 연구소: **같은 색 6개를 모아야 터짐** · 낙하 속도 75%
   - 두 사람에게 같은 뿌요 순서와 같은 규칙이 적용되고, 고른 맵은 계정에 저장됩니다.
5. **챌린지를 엄청 많이**: 32개 → 151개. 연쇄·누적 터뜨리기·방해 뿌요·전소·상쇄, 판 수·승리, 혼자 하기 점수, 레벨, 맵 탐험, 선물 받기, 스킨·효과 수집, 타워 승리. 챌린지 화면에서 종류별로 골라 볼 수 있습니다.
6. **seonn 광고**: 게임을 5번 끝낼 때마다 결과 화면에 「seonn을 플레이하세요! 40개의 게임을 무료로 플레이하실 수 있습니다!」 포스터가 나옵니다. 기획서 그림대로 오른쪽 위 단추가 「5초 뒤에 ✕」에서 1초씩 줄어들고, 다 세면 눌러서 닫습니다. 같은 판 수에서는 새로고침해도 다시 나오지 않습니다 (`promo.mjs`).
7. **스핀·일일 보상·시간 보상에 다른 보상 추가**: 코인·경험치에 더해 🎨 스킨 교환권, ✨ 효과 교환권, 🎟️ 추가 스핀권. 교환권은 상점에서 레벨·코인 없이 판매 상품 하나와 바꾸고(보스 보상은 제외), 추가 스핀권은 오늘의 무료 스핀을 쓴 뒤 한 번 더 돌립니다. 생일 10배는 코인에만 적용되고 교환권 수는 그대로입니다.

## 업그레이드 3 (세 번째 손글씨 기획서 6가지)

기획서 원문과 인혁이와 질문으로 정한 것은 [requirements/puyo-tower-upgrade-ranking-spectate.md](../../requirements/puyo-tower-upgrade-ranking-spectate.md)입니다. 서버 쪽은 [services/net](../../services/net/README.md)의 "기록, 랭킹, 관전"입니다.

   - 코드와 화면 글에는 "뿌요"만 적습니다. 앱 빌드(vite mode `app`)가 만들어진 글(HTML, JS, CSS, AI 워커 파일)에서 "뿌요"를 "젤리"로 바꿉니다. 나중에 글을 더해도 앱에는 저절로 "젤리"로 나갑니다.

   - 저장 기록, 친구, 온라인 대전은 사이트와 앱이 그대로 같이 씁니다. 처음부터 젤리였던 스킨 이름(말랑 젤리, 투명 젤리, 동그란 젤리)은 사이트에서도 그대로입니다.
2. **새 스킨과 레벨 스킨**: 스킨이 20종에서 33종(업그레이드 6에서 45종, 업그레이드 7에서 57종), 터질 때 효과가 19종에서 21종이 됐습니다.
   - 코인으로 사는 새 스킨 6종: 병아리(3레벨), 펭귄(5), 쿠키(6), 닌자(8), 호박(10), 문어(12)
   - 고난이도 레벨 스킨 6종: 기사(30레벨), 마법사(40), 불사조(50), 은하(60), 번개(70), 전설의 뿌요(99). 그 레벨이 되어야 코인으로 살 수 있고, **교환권으로는 바꿀 수 없습니다** (`shop.mjs`의 `noTicket`).
   - 레벨 효과 2종: 유성우(30레벨), 무지개 폭풍(50). 이것도 교환권으로 바꿀 수 없습니다.
3. **트로피**: AI 대전과 온라인 대전(방 코드 대전 포함)에서 대전 하나를 이기면 1개. 2인 플레이(한 기기), 타워, 혼자 하기는 주지 않습니다. 이긴 결과 화면에 "🏆 트로피 +1 (모두 N개)", 내 정보에 트로피 수가 나오고, 계정 저장에 같이 들어가서 클라우드 저장으로도 이어집니다 (`main.js`의 `finishMatch`).
4. **관전** (`watch.mjs`): 온라인 화면의 「👀 관전하기」에서 지금 하는 대전 목록을 보고 고르거나, 친구 목록에서 게임 중인 친구 옆 「👀 관전」을 누릅니다.

5. **온라인 랭킹 3개**: 온라인 화면의 「🏆 온라인 랭킹」에서 탭으로 고릅니다. 🏆 트로피 많은 순, ⭐ 레벨 높은 순, 🌐 온라인 승리 많은 순.
   - 기획서 그림대로 맨 위에 "순위 · 닉네임 · 레벨" 칸이 있고, 줄마다 등수·닉네임·레벨·그 랭킹의 숫자를 보여 줍니다. 50등까지와 내 등수.
   - 온라인 계정(서버)만 나옵니다. 손님과 이 기기 계정은 로그인 안내.
   - 게임이 레벨·경험치·트로피를 서버에 올리고(`PUT /stats/:game`, 기록이 바뀌었을 때만 조용해진 뒤에, 랭킹 화면을 열 때는 먼저), **온라인 승리는 서버가 직접 셉니다** (두 사람이 보낸 결과가 같을 때만). 트로피와 레벨은 게임이 올리는 값이라 마음먹고 속이면 속일 수 있고, 레벨은 제작자 모드로 50까지 바로 올릴 수 있어서 레벨 랭킹은 덜 공평합니다. 인혁이가 세 가지를 다 원해서 그대로 만들었습니다.
6. **랭킹 5등 스킨 「챔피언 뿌요」** (`shop.mjs`의 `RANK_SKIN`): 세 랭킹 중 하나라도 5등 안에 들면 받는 전용 스킨입니다. 서버가 처음 5등 안에 든 때를 적어 두어서 한 번 받으면 5등 밖으로 밀려나도 계속 가집니다. 기록을 올린 뒤 게임이 내 순위를 받아서 5등 안이면 상점에 넣고 "🎖️ 온라인 랭킹 5등 안에 들어서 …" 알림을 띄웁니다. 코인, 교환권, 제작자 모드로는 받을 수 없습니다.
7. 기획서 맨 밑 "(책읽음)"은 게임과 상관없는 메모라서 만들지 않았습니다.

올리는 순서: ① `services/net` 에서 `npx wrangler d1 migrations apply net --remote` (`0004_stats.sql`) → ② net 서버 배포 → ③ 사이트와 앱. 순서가 거꾸로면 새 게임이 아직 없는 서버 주소(`/stats`, `/rankings`, `/matches`)를 불러서 랭킹·관전 화면에 오류가 보입니다. 확인은 `watch-ranking-browser-check.mjs`.

아래는 이 기기 계정의 친구 코드 친구입니다.

- **온라인 대전 채팅**: 로비의 💬 채팅, 게임 중에는 위쪽 💬 단추(오른쪽 위 작은 창). 빠른 말 8개(👋 안녕! 👍 잘한다! …)는 번호로만 보내고, 직접 쓴 말은 60글자까지. 게임 중에 온 말은 화면 위쪽 말풍선으로 잠깐 보인다. 이번 판 채팅 끄기가 있다.

## 아이폰 앱에서만 다른 것

`platform.mjs`가 앱(Capacitor) 안인지 알아보고, 웹에서는 아무 일도 하지 않습니다.

- 이름: 앱에는 「젤리 타워」와 "젤리" 말로 나옵니다 (앱 빌드가 "뿌요"를 "젤리"로 바꿉니다, `brand.mjs`). 사이트는 「뿌요뿌요 타워」.
- 시작 그림: 첫 화면을 그린 다음에 걷습니다.
- 저장: localStorage에 저장하면서 기기 저장소(Preferences)에도 같이 적고, 아이폰이 웹 저장소를 비우면 앱을 켤 때 되살립니다.
- 진동: 터뜨리기(연쇄가 클수록 세게)·방해 뿌요·전소·승패·레벨 업·챌린지 완료. 내 정보 → 설정에서 끌 수 있습니다.
- 계정 지우기: 내 정보 맨 아래 (앱스토어 규칙). 웹에서도 됩니다. 이 기기 계정은 이 기기에서 지우고, 온라인 계정은 비밀번호를 한 번 더 적으면 서버에서 지웁니다 (아래 "온라인 계정 지우기").
- 사이트로 가는 「← 인혁 월드」 링크는 숨기고, 다이내믹 아일랜드·홈 막대 자리를 비웁니다.
- 글꼴: Jua를 게임 안에 넣어서 인터넷 없이도 같은 모양으로 나옵니다. 본문은 기기 글꼴(애플 산돌고딕, 맑은 고딕)을 씁니다.

## 온라인 계정, 친구, 채팅, 클라우드 저장

공용 net 서버(`services/net`, 클라이언트 `packages/net`)를 씁니다. 결정 근거는 [requirements/matchmaking-chat-friends.md](../../requirements/matchmaking-chat-friends.md).

- **계정**: 새 계정과 로그인은 서버의 닉네임(전체에서 하나뿐) + 비밀번호입니다. 손님과 이 기기 계정은 인터넷 없이 혼자 하기, 타워, AI 대전을 그대로 합니다.
- **이 기기 계정 옮기기** (`migrate.mjs`): 로그인 화면에서 기기 계정을 누르고 비밀번호를 넣은 뒤 「☁️ 온라인 계정으로 옮기기」. 기기에는 비밀번호 해시만 있으므로 비밀번호로 먼저 확인하고 같은 닉네임으로 가입합니다. 그 닉네임이 서버에 이미 있으면 "내 계정이야, 로그인" 또는 새 닉네임을 고릅니다. 가입(또는 로그인)과 첫 저장 올리기가 모두 끝나야 기기 계정에 "옮김" 표시를 하고(지우지 않음) 목록에서 숨깁니다. 첫 저장은 `importId = jelly-<기기 계정 번호>` 로 한 번만 올라가서 다시 시도해도 두 번 쓰지 않습니다. 올리기 전에 앱이 꺼지면 다음에 켤 때 마저 올리고, 그래도 안 되면 서버에서 로그아웃하고 기기 계정으로 돌아갑니다.
- **클라우드 저장** (`cloud.mjs`): 로그인하면 서버 저장을 읽고, 기록이 바뀐 뒤 3초 조용하면 올립니다. 판이 끝날 때와 화면을 떠날 때(페이지 숨김)는 바로 올립니다. 올릴 때는 항상 `baseRevision` 을 붙입니다. 다른 기기가 먼저 써서 409 가 오면 **합치지 않고**(코인을 큰 쪽으로 고르지도 않음) "이 기기 / 서버(다른 기기)" 의 레벨, 코인, 마지막 저장 시각을 보여 주고 고르게 한 뒤 서버 revision 으로 다시 씁니다. 인터넷이 안 되면 기기에 적어 두고 20초마다(인터넷이 돌아오면 바로) 다시 올립니다. 고르고 다시 쓰기를 세 번 해도 계속 다른 기기가 먼저 쓰면 자동 저장은 "저장 중" 으로 두고 다음에 다시 올리지만, 기기 계정 옮기기에서는 실패로 끝내서 기기 계정을 숨기지 않고 「다시 해 보기」를 보입니다. 서버가 너무 크다고(413 `too-big`) 하면 저장됨으로 표시하지 않고 알린 뒤 기기에 남겨 두고 5분마다 다시 올립니다.
- **올리는 기록의 크기**: 올리는 것은 `cloudPayload(progress)` 로, 친구 코드 기록(`progress.social`: 우체통 열쇠, 친구 코드 친구와 대화)은 빼고 이 기기에만 둡니다. 가장 큰 기록(`save-size.fixture.mjs`: 스킨, 효과, 미션 전부와 큰 숫자, 업그레이드 4의 펫과 친구 100명에게 받은 선물 번호까지)은 11,888바이트로 서버 한도(32KB)의 3분의 1 조금 넘습니다. 친구 기록을 끝까지 채우면(친구 30명 x 대화 50줄 x 60글자 이모지) 2,335,063바이트라 서버에 올릴 수 없습니다.
- **친구 우체통 비우기** (`legacy.mjs`): 옮기기 전과 기존 친구 기록을 열 때 받은 편지는 묶음마다 기기에 저장(`persistStore`)된 뒤에만 다음 요청에서 우체통에서 지웁니다(ack). 저장이 안 되면(저장 공간이 꽉 참) 그 묶음을 되돌리고 지우지 않으며, 옮기기도 멈춥니다.
- **온라인 대전** (`online.mjs`): 「🎲 게임 찾기」는 `findMatch('jelly-tower')`, 친구 초대는 친구 화면의 「🎮 초대」(60초). 방 코드는 보이지도 입력하지도 않습니다. 판 메시지는 예전과 같고, 필드 모습만 글자열 대신 숫자 배열로 보냅니다(서버가 관계자 방의 글자열 속 숫자 8개 이상을 가리므로). 서버가 한 연결에서 1초에 30개까지만 전해서 필드 모습은 초당 20번 보내고(업그레이드 5 전에는 12번), 받는 쪽이 그 사이를 매 프레임 이어서 그립니다(`remote-smooth.mjs`). 상대 이름은 서버가 준 `opponent.nickname` 만 씁니다.
- **다시 접속**: 같은 계정이 다른 연결로 다시 들어오면(`rejoin`) 판을 맞추지 않고 그 대전을 끝내고 두 사람 모두 온라인 화면으로 돌아갑니다. 양쪽 뿌요 순서와 방해 뿌요를 다시 맞추는 것보다 간단하고 어긋나지 않습니다. 상대가 나가거나 내 연결이 끊기면 예전처럼 대전이 끝납니다(결과가 이미 나왔으면 결과 화면은 그대로).
- **채팅과 안전**: 대전 채팅은 이 기기 계정과 같은 채팅 창(로비의 💬 채팅, 게임 중 위쪽 💬 단추, 말풍선, 이번 판 채팅 끄기)입니다. 직접 쓴 말은 `room.chat`(60글자, 서버가 욕설·전화번호·링크를 가림), 빠른 말과 뿌요 이모티콘은 번호만 보냅니다. 친구와 1:1 대화는 서버에 남아서 다음에 접속해도 보이고, 빠른 말·뿌요 이모티콘·이모지 단추가 있습니다. 채팅 창, 1:1 대화, 결과 화면에 🚫 차단과 🚨 신고가 있고 둘 다 확인을 한 번 더 묻습니다.
- **친구**: 닉네임 검색 또는 게임 찾기 결과 화면의 「🤝 친구 요청」. 상대가 수락해야 친구가 되고, 친구 목록의 초록 점은 접속 중입니다.
- **서버 주소**: 기본은 `wss://net.seonn.workers.dev`. 개발과 테스트에서만 주소 뒤에 `?net=http://127.0.0.1:8787`(내 컴퓨터 주소만 받음)이나 빌드 환경 변수 `VITE_NET_SERVER` 로 바꿉니다. 화면에는 바꾸는 곳이 없습니다. 다른 서버의 로그인은 다른 이름으로 저장해서 섞이지 않습니다.
- **확인**: `npm run puyo-puyo:dev` 후 `PUYO_URL=http://127.0.0.1:5190/ node games/puyo-puyo/online-browser-check.mjs`. net 서버는 빈 로컬 D1 로 스스로 띄웁니다(이미 띄운 서버는 `PUYO_NET`). 가입 두 명 → 둘 다 게임 찾기 → 같은 판 → 대전 채팅(빠른 말, 뿌요 이모티콘, 이모지, 서버가 가린 번호) → 채팅 끄기 → 결과 화면 친구 요청과 수락 → 친구 초대 → 1:1 대화(빠른 말, 뿌요 이모티콘, 이모지) → 다른 기기에서 같은 레벨/코인 → 저장 충돌 고르기 → 신고, 차단 → 친구 코드 친구가 있는 기기 계정 옮기기 → 기존 친구 기록과 지난 대화 → 온라인 계정 창은 친구 우체통을 부르지 않음. 옮길 때 우체통 비우기까지 보려면 사이트를 빌드해 `JELLY_MAIL_MEMORY=1 next start` 한 주소를 `PUYO_URL` 로 준다(개발 서버에서는 그 부분만 건너뜀).
- **온라인 계정 지우기** (2026-10-07 인혁이 요청 "계정 지우기 버튼을 다시 만들어줘"): 내 정보 맨 아래 「🗑️ 계정 지우기」가 온라인 계정에도 나옵니다. 비밀번호를 한 번 더 적으면 서버(`POST /auth/delete`)가 계정과 친구, 친구 요청, 차단, 1:1 대화, 신고, 모든 게임의 저장과 랭킹 기록을 지웁니다. 되돌릴 수 없고 닉네임은 다시 쓸 수 있게 됩니다. 게임은 이 기기에 남은 저장과, 옮기기 전의 기기 계정(숨겨 둔 것)도 지우고 로그인 화면으로 갑니다.
  - 비밀번호가 틀리면 "비밀번호가 달라" (10분에 5번까지). 정지된 계정은 지울 수 없습니다.
  - **net 서버를 다시 배포해야 됩니다** (D1 을 고치는 것은 없음). 배포 전의 서버는 브라우저가 미리 물어보는 요청(preflight)에 404 로 답해서 게임에는 "연결하지 못함"으로 보입니다. 그래서 게임이 다른 길(`/me`)이 되는지 확인한 뒤 "아직 지울 수 없어. 게임 서버를 새로 배포해야 계정 지우기가 돼. 부모님께 말해 줘 (인터넷은 괜찮아!)" 라고 알립니다 (처음에는 "인터넷을 확인해 줘"로 잘못 나왔던 것을 고침). 계정은 그대로입니다.
- 아직 없는 것: 온라인 계정 비밀번호 바꾸기(서버 API 가 없음). 제작자 모드의 비밀번호 다시 정하기는 이 기기 계정에만 됩니다.

- 2인 플레이: 1P A·D·S, W 오른쪽 돌리기, Q 왼쪽 돌리기, Space 바로 떨어뜨리기 / 2P ←→↓, ↑ 오른쪽 돌리기, / 왼쪽 돌리기, Enter 바로 떨어뜨리기

## 파일

- `core.mjs`: 규칙 엔진 (필드, 짝, 회전, 연쇄, 점수, 방해 뿌요)
- `ai.mjs`, `ai-worker.js`: AI (웹 워커에서 생각)
- `match.mjs`: 라운드·선취·방해 뿌요 주고받기·온라인 판정
- `render.mjs`, `skins.mjs`, `effects.mjs`, `characters.mjs`: 화면
- `audio.mjs`: 효과음과 배경음악 (Web Audio로 직접 합성)
- `profile.mjs`, `missions.mjs`, `shop.mjs`, `tower.mjs`: 계정·레벨·챌린지·상점·타워
- `online.mjs`: 온라인 계정의 온라인 대전 (`@inhyuk/net` 방, 게임 찾기, 친구 초대, 채팅)
- `online-peer.mjs`, `room.mjs`: 이 기기 계정과 손님의 방 코드 온라인 대전 (PeerJS, 예전 버전 게임과 같은 메시지)
- `chat.mjs`, `friendnet.mjs`, `mailbox.mjs`, `legacy.mjs`: 채팅 규칙, 친구 코드 친구의 직접 연결, 친구 우체통, 옮긴 뒤의 친구 코드 기록
- `net.mjs`, `cloud.mjs`, `migrate.mjs`, `social-ui.mjs`: net 서버 주소, 클라우드 저장, 이 기기 계정 옮기기, 친구·대화·초대·차단·신고 화면
- `calendar.mjs`, `rewards.mjs`, `creator.mjs`: 한국 달력·날짜 배율·매일 선물·제작자 도구
- `maps.mjs`, `promo.mjs`: 맵 규칙과 온라인 맵 투표, 5판마다 나오는 seonn 광고
- `pets.mjs`, `pet-art.mjs`, `bonus.mjs`, `gifts.mjs`: 펫과 뽑기, 펫·알 그림, 판 보상 배수(펫·2배 부스트·친구), 친구 선물
- `watch.mjs`: 관전 (서버의 관전 자리로 들어가서 두 사람의 필드 모습을 받아 그림, 화면 그리기는 `render.mjs`의 watch 배치), 관전 채팅과 응원 보내기
- `remote-smooth.mjs`: 온라인 상대 필드를 받은 모습 사이에도 매 프레임 이어서 움직이기
- `brand.mjs`: 사이트 이름 「뿌요뿌요 타워」와 앱 이름 「젤리 타워」, 앱 빌드에서 "뿌요"를 "젤리"로 바꾸는 vite 플러그인
- 서버 쪽 (`services/net`): `src/stats.js`(기록, 랭킹 3개, 지금 하는 대전 목록), `src/index.js`(방의 관전 자리, 온라인 승리 세기), `migrations/0004_stats.sql`
- `tutorial.mjs`, `school-puzzles.mjs`, `school-puzzles2.mjs`, `school-puzzles3.mjs`: 뿌요뿌요 배우기 열일곱 등급(초급 = 연습하기, 중급, 상급, 최상급, 초초상급, 마지막, 찐 마지막, 졸업, 졸업2 ~ 졸업10)의 문제와 성공·다시 판정, 졸업 등급의 퍼즐 판
- `chat.mjs`, `friendnet.mjs`: 채팅 규칙(나쁜 말·개인정보·속도), 친구 코드와 친구끼리 직접 잇기
- `platform.mjs`: 아이폰 앱에서만 하는 일 (진동, 기기 저장소, 시작 그림)
- `ending.mjs`: 왕관·혜성 엔딩
- `sky.mjs`, `clash.mjs`, `fighters.mjs`: 대전 화면의 시각별 하늘, 방해 뿌요 힘겨루기 셈, 온라인 대전에서 고르는 캐릭터
- `main.js`, `index.html`, `style.css`: 화면 흐름

`window.render_game_to_text()`는 브라우저 검증용 상태를 돌려주고, 주소에 `?test`를 붙이면 `window.__puyo` 도우미가 생깁니다.

캐릭터, 그림, 음악은 모두 코드로 직접 그리고 만든 것입니다. 같은 색을 이어 터뜨리는 연쇄 퍼즐(SEGA의 뿌요뿌요 같은 게임)에서 영감을 받았지만, 이름·캐릭터·그림·소리는 모두 뿌요뿌요 타워만의 것입니다.
