# 브릭버스 · BRICKVERSE

아바타를 꾸미고 광장에서 빛나는 문을 골라 들어가 노는 3D 블록 놀이터입니다. three.js 로 그리고, 그림과 모델과 소리는 모두 코드로 새로 만들었습니다.

## 실행

- 단독 실행: 저장소 루트에서 `npm run brickverse:dev` → http://127.0.0.1:5173/ 같은 주소
- 사이트에서: `npm run brickverse:build` 후 `/play/brickverse`
- 시험: `npm run test:brickverse` (물리, 저장 정리, 타이쿤 경제, 점프 탑 30단계가 모두 점프로 이어지는지, 모두의 광장 규칙, 모두의 공터 칸 규칙과 자리(`commons.test.mjs`))
- 모두의 광장 서버 시험: `node games/brickverse/plaza-check.mjs` (빈 DB 로 내 컴퓨터 서버를 8787 에 띄우고, 계정 둘이 `brickverse:plaza-1` 에서 만나고 헤어지는지, 공터 블록을 놓고 받고 거절당하고, 둘 다 나갔다 와도 블록이 남는지 보고, 서버를 끕니다. 먼저 `npm --prefix services/net ci`)

## 조작

- WASD·방향키 이동, Space 점프, 마우스 끌기 시점, 휠 확대, T 말하기, 1~4 표현
- **머리카락**: 꾸미기 💇 머리 탭. 모양 12가지(`HAIRS`, 5개는 공짜)와 색 10가지(`HAIR_COLORS`). 모자를 쓰면 위로 솟는 머리는 숨깁니다. 옷 배열 끝에 붙여서 예전 게임과도 맞습니다.
- **쉬프트락**: Shift 키(휴대폰은 오른쪽 아래 🔒 버튼). 컴퓨터에서는 마우스를 화면에 붙잡아(Pointer Lock) 마우스만 움직여도 시점이 돌고, 가운데에 조준점이 생깁니다. 캐릭터는 늘 카메라가 보는 쪽을 보고(A/D 는 옆걸음), 카메라는 어깨 너머로 비켜섭니다. 하늘 타워에서는 조준점으로 블록을 놓습니다. Esc, 옷장, 메뉴를 열면 꺼집니다.

## 세계

- **브릭 광장** (`buildHub`): 분수, 옷가게, 통통 점프 공원, 전망대, 작은 점프길, 주민, 코인, 🧱 모두의 공터. 문 세 개로 게임에 들어갑니다.
- **🧱 모두의 공터** (`commonsLot`, `src/commons.js`, `COMMONS`): 광장 오른쪽 아래(통통 점프 공원 남쪽, 작은 점프길 동쪽, 가운데 x 60, z 20)의 12×12칸, 16층 바닥판(주황 테두리, 안내판). 로그인해서 모두의 광장에 들어가 있으면 누구나 블록 17종을 놓고, 모두 나가도 서버에 남습니다. 부수기는 내가 놓은 블록만 됩니다. 막대와 놓기는 공터 안이나 6 안쪽으로 가까이 있을 때만 켜지고(멀리서 화면을 눌러도 안 놓임), 클릭이나 톡으로 놓기, 오른쪽 클릭이나 부수기 모드로 부수기, Q E 로 블록 고르기, F 로 놓기/부수기를 바꿉니다(숫자 키는 광장의 표현이라 안 씀). 손 닿는 거리 20, 내 자리에는 못 놓음, 0.3초마다 한 번, 내 블록 400개까지. 무지개 카펫과 모두 치우기는 없습니다. 로그인하지 않았거나 방 코드 방에 있으면 공터는 비어 보이고 가까이 가면 한 줄로 알려 줍니다.
- **무지개 점프 탑** (`buildObby`): 30단계. 단계마다 오른쪽으로 꺾이며 올라갑니다. 체크포인트마다 코인, 꼭대기 100코인.
- **블록 공장 타이쿤** (`tycoonBase`, `tycoonItem`, `src/tycoon.js`): 떨어뜨리개 → 벨트 → 업그레이더 → 녹이는 기계 → 초록 발판에서 돈 받기 → 발판을 밟아 물건 45개 사기. 황금 트로피(+200 코인) 다음에는 뒷마당을 넓혀 차고, 트램펄린, 그네, 연못, 온실, 축구 골대, 3층 집, 로켓 발사대(+300 코인)를 짓고, 그다음 하늘 섬(윗면 높이 `SKY`, 노란 엘리베이터로 오름)에 풍차, 구름 정원, 구름 은행(돈 ×2), 열기구, 무지개 다리, 하늘 분수, 하늘 성, 별 공장(돈 ×3), UFO 착륙장(돈 ×2), 황금 왕관 탑(+500 코인)을 짓습니다. `boost` 는 녹이는 기계에서 모든 돈에 곱합니다. 모두 사는 데 약 1시간. 친구 방에서는 돈 칸의 💸 돈 주기로 친구에게 타이쿤 돈을 줄 수 있습니다(`{t:'gift', amt, n}` → 받은 쪽이 `gift-ok`, 6초 안에 답이 없으면 돌려받음, 같은 번호는 한 번만). 공장 밖에 있거나 게임을 꺼 둔 동안에도 돈이 원래의 0.001%로 쌓입니다(`tycoonAwayEarnings`, 7일까지, 1달러가 안 되는 돈은 `bank` 에 모음).
- **바닥이 사라져요** (`buildSurvival`, `src/survival.js`): 밟은 바닥은 0.45초 뒤 떨어집니다. 3층 아래 용암에 빠지면 탈락. 혼자면 봇 5명과, 친구가 있으면 방장이 판을 시작합니다.

- **하늘 타워 짓기** (`buildTower`, `src/tower.js`): 돌판(24×24칸, 100층) 6개(`TOWER_SLOTS`). 혼자면 가운데 0번이 내 땅, 친구 방에서는 p1 → 0번, p2 → 1번처럼 각자 다른 땅에 짓습니다. 블록 17종을 내 땅에만 놓고 부수고, 손이 닿는 거리(20)까지만 놓을 수 있습니다. 내 땅 앞의 🌈 무지개 카펫에 타면 조종합니다: WASD(조이스틱) 이동, Space(⬆) 위, C(⬇) 아래, X(🛬) 내리기, 🏗️ 꼭대기로(꼭대기 블록 옆면에 붙음), 🌈 부르기. 내 땅 위에서만 날고, 카펫과 탄 사람 자리가 블록에 닿으면 그쪽으로는 멈춥니다(`blocked`). 플레이어보다 먼저 움직여 태우고(`move`), 아무도 안 타고 60초가 지나면 집으로 돌아갑니다. 처음 올라간 층마다 1코인. 내 블록 500개까지 저장. 블록은 숫자로만 보냅니다.

- **블록 배틀 로얄** (`buildBattle`, `src/battle.js`): 섬 지름 약 500(마을 7, 창고 5, 저격 탑 8, 언덕, 나무 250). 블록이 많아 봇과 광선은 16칸 격자로 가까운 블록만 봅니다(`buildGrid`). 하늘 대기실(10초) → 낙하산으로 섬에 내려가기 → 블래스터 4종(`WEAPONS`)과 회복 주스, 방패 줍기 → 줄어드는 안전 구역(`zonePhases`, 밖에 있으면 체력이 줄어듦) → 마지막 1명이 우승. 장난감 블래스터라서 맞으면 체력이 줄고 0 이면 펑 사라져 탈락합니다. 혼자면 봇 11명, 친구 방이면 방장이 판과 봇을 맡고 각자 자기 체력을 맡습니다(`{t:'br', k:'tick'}` 0.1초마다: 체력, 총알 자국, 맞힘, 주운 아이템, 봇 위치. 모두 숫자). 봇은 처음 12초는 쏘지 않고 낙하산 탄 사람도 쏘지 않습니다. 좋은 블래스터와 회복, 방패를 챙기고, 숨은 적은 마지막으로 본 곳까지 쫓아가고, 싸울 때 좌우로 피합니다. 화면 가운데 조준점으로 쏘고, 컴퓨터는 화면을 누르면 마우스를 붙잡습니다(왼쪽 쏘기, 오른쪽 저격 확대, 1~4 무기). 휴대폰은 🔫 버튼과 🔭 버튼. 블래스터마다 탄창(`mag`)과 남은 총알(권총은 끝없음): R 이나 🔄 로 재장전, 비면 저절로, 재장전하는 동안은 못 쏨, 📦 총알 상자와 같은 블래스터를 주우면 총알이 늘어남. 봇도 탄창을 다 쓰면 재장전합니다. 오른쪽 위 미니맵(섬, 안전 구역, 다음 구역, 나). 방어구: 🪖 헬멧과 🦺 조끼 1~3단계(`GEAR`, 맞는 아픔을 헬멧 10/18/25%, 조끼 15/25/35% 줄임, 아바타에 보임, 더 높은 단계만 바꿔 입음, 봇도 입음). 탈락하면 남은 사람을 관전(`src/spectate.js`, ◀ ▶ 또는 Q/E, 바닥이 사라져요도 같음).
  - **팀전: 성 지키기** (`src/defense.js`, `CASTLE`, `DEFENSE`, `waveOf`): 대기실에서 다음 판을 🎯 개인전이나 🏰 팀전으로 고릅니다(방장만, 버튼이나 숫자 1, 2 키). 섬 가운데 성(성문 4개, 성벽 계단, 모퉁이 탑)의 💎 성의 보석을 친구, 동료 봇(4명이 되게 채움, 성벽 위에서 쏨)과 같이 지킵니다. 동서남북 길 끝 보라색 포털에서 슬라임, 고블린, 돌 골렘이 길을 따라 성으로 오고, 웨이브 5와 10에는 킹 슬라임이 나옵니다. 몬스터는 가까운 사람을 먼저 때리고 아니면 보석을 때립니다. 10웨이브를 막으면 승리, 보석이 부서지면 끝. 쓰러져도 탈락하지 않고 6초 뒤 성 안에서 다시 일어나고, 웨이브를 막을 때마다 총알과 체력이 찹니다. 처음부터 블래스터 4개를 다 들고 시작합니다. 몬스터는 방장이 움직이고 `df` 로 보내며, 손님이 맞히면 `-(10000+몬스터 번호)` 로 방장에게 알립니다. 코인은 처치 + 웨이브×5 + 승리 100.
- **술래잡기 마을** (`buildTag`, `src/tag.js`, 6번째 문): 가운데 "👹 술래 집"과 그 옆 "🏠 광장으로" 문, 집 4채(들어갈 수 있는 옷장, 침대), 덤불 20개, 키 큰 풀숲, 상자 더미, 굴, 짚더미, 놀이터. 대기실에서 🏃 술래잡기 / 🙈 숨바꼭질을 고릅니다(방장만, 버튼이나 숫자 1, 2). 술래잡기: 술래(발밑 빨간 고리, 👹 이름표)에게 닿으면 내가 술래, 새 술래는 3초 동안 세고, 90초가 끝날 때 술래면 짐(살면 🪙15, 술래 🪙3). 숨바꼭질: 술래가 20초 동안 눈을 감고 세는 동안 숨고(숨은 사람 이름표는 안 보임), 술래가 닿으면 찾았다! 그 사람도 술래 편. 100초 안에 다 찾으면 술래 편, 한 명이라도 남으면 숨은 편 승리(이긴 편 🪙25, 진 편 🪙5). 6명이 되게 봇을 채우고, 봇은 1칸 바둑판 길 찾기(A*)로 집 안 옷장, 상자 구석, 굴까지 가서 숨고, 술래 봇은 숨을 만한 곳을 차례로 살피며 덤불·풀숲·옷장 속은 가까이 와야 찾습니다. 친구 방이면 방장이 판, 봇, "닿았나"를 맡고 `{t:'tg'}` 로 자리 번호만 보냅니다.
- **펫과 알 판매** (`src/pets.js`, `PETS`, `hatchPet`): 광장의 🥚 알 판매에서 코인 100으로 알을 까면 강아지(1.5배), 고양이(2배), 판다(5배), 앵무새(10배)가 나와 데리고 다니는 동안 달리기가 빨라집니다(`stepPlayer` 의 `speed`). 적어 준 확률은 75+30+5+0.1 = 110% 라서 귀한 것은 그대로(앵무새 0.1%, 판다 5%, 고양이 30%), 강아지가 나머지 64.9%. 친구에게도 내 펫이 보입니다(`hi` 의 `pt`).
- **핸드폰** (`src/phone.js`, P 키 또는 📱): 가로 핸드폰, 위에 카메라, 앱 4개. seonn.dev(사이트 게임 목록을 빌드할 때 `src/data/games.json` 에서 가져와 핸드폰 안에서 바로 실행, ⛶ 크게, ↗ 새 창), 기록(세계마다 지금까지 한 것), 설정(효과음, 음악, 펫, 쉬프트락, 점프 탑 처음부터, 기록 지우기), 계정(별명, seonn 로그인, 친구 방).
- **달걀 도둑** (`buildEgg`, `src/egghunt.js`, 7번째 문): 인혁이 말한 로블록스 게임을 베끼지 않고 노는 방식만 같은 우리 게임입니다(이름, 동물, 경비, 지도는 새로 만듦). 남쪽에 기지 6개(친구마다 하나, 받침대 4→12개), 북쪽으로 🌾 풀밭(공짜) → 🌲 숲속($500) → 🌋 용암($8,000) → ☁️ 구름($120,000) 둥지 마당. 둥지의 알에 닿으면 들고(무거워서 펫 속도는 안 됨), 경비(거위, 곰, 용암 골렘, 번개 새)에게 닿으면 떨어뜨립니다. 내 기지에 들어오면 받침대에서 부화(5~40초)해 동물 12종(`CRITTERS`, 3% ✨ 황금은 3배)이 1초마다 돈을 법니다. 돈으로 👟 신발(빨라짐)과 🪺 받침대를 사고, 울타리 문에 닿으면 새 둥지 마당을 엽니다. 받침대가 꽉 차면 가장 못 버는 동물을 팔고 바꿉니다. 🦝 너구리 도둑이 가끔 가장 비싼 동물을 훔치러 오니 닿아서 잡고, 🔒 기지 잠그기(30초, 쉬는 시간 60초)로 막습니다. 친구 방에서는 친구 기지의 동물도 훔칠 수 있고(기지 주인이 맡음, `{t:'eg'}` 숫자만), 훔쳐 가는 친구에게 닿으면 돌려받습니다.
  - **AI 도둑**: 혼자 할 때 빈 기지 5곳에 AI가 삽니다. AI도 경비를 피해 알을 훔쳐(내가 연 마당까지만) 자기 기지에서 부화시키고, 번 돈으로 받침대, 신발, 새 마당을 삽니다. 경비는 알을 든 AI도 쫓습니다. 가끔 AI가 내 기지에 와서 가장 비싼 동물을 훔쳐 가니 닿아서 되찾고(🔒 잠그면 돌아감), 내가 AI 기지에서 훔치면 AI가 1.2초 뒤 알아차리고 쫓아옵니다(쫓는 빠르기 7.0, 신발 없이 동물 든 나 7.65). 친구 방에서는 친구가 상대라 AI가 없습니다.
  - **러닝머신**: 기지 앞 오른쪽에 3대(🏃 ×1 공짜, ⭐ ×2 $3,000, 🌈 ×5 $60,000, 올라서면 삽니다). 벨트는 나를 전혀 움직이지 않고(인혁: "안끌리게", "아직 끌려가는데"), 올라가서 가만히 서 있으면 저절로 계기판을 보고 제자리 달리기를 하며(키를 누르면 평소처럼 걸어 내려옴), 달리는 동안 🏃 달리기 레벨(최고 30, 레벨마다 3% 빨라짐, `trainRun`)이 오릅니다. 달걀 도둑 안에서 빠르기에 더해집니다.
- **모닥불 캠프** (`buildCamp`, `src/camp.js`, 8번째 문, 반지름 210의 넓은 섬: 호수, 바위 언덕 3곳, 버려진 오두막 4채, 동서남북 빛나는 길 버섯, 나무 640그루, 화면에 모닥불 쪽 화살표와 거리. 📦 파밍: 보물 상자 59개(나무 28 가까운 숲, 쇠 18 먼 숲·오두막, 황금 13 섬 끝·바위 언덕·굴 옆), E 로 열면 나무, 열매, 구운 고기, 코인과 가끔 ⛏️ 쇠/✨ 황금 도끼(늑대 40/60, 나무 2/3개씩), 🛡️ 가죽/쇠/황금 갑옷(15/30/45% 덜 아픔), 🏮 랜턴(밤에 내 둘레 5칸이 빛이라 늑대가 못 옴), 연 상자는 3일 뒤 다시 참, 장비는 처음부터 다시 해도 남음(`chestLoot`); 낮 60초): 인혁이 말한 로블록스 게임(99 Nights in the Forest)의 이야기와 괴물은 쓰지 않고, 노는 방식만 비슷한 우리 게임입니다. 둥근 숲 섬 가운데 모닥불이 있습니다. 낮(45초)에는 🪓 E 로 나무 베기(3번에 쓰러지고 90초 뒤 다시 자람)와 열매 따기를 하고, 모닥불 옆에 서면 나무가 저절로 들어갑니다(넣은 나무 수로 불 Lv1~5, 빛 반지름이 커짐). 밤(35초)에는 숲에서 👁️ 빨간 눈의 그림자 늑대가 오고(밤이 갈수록 많아짐, 10일마다 그림자 거인), 늑대는 모닥불과 🔦 횃불(F, 나무 5개, 밤 3번) 빛 안에 못 들어옵니다. 늑대를 쫓아내면 날고기가 나오고, 불 옆에서 구워 Q 로 먹습니다(🫐 열매도). 배고픔이 0이면 체력이 줄고, 목숨 3개를 다 쓰면 1일째부터 다시 합니다. 하루를 버틸 때마다 🪙2(10, 25, 50, 75, 99일에 더 많이), 99일을 버티면 성공입니다. 인혁이 "사슴 괴물이랑 아이들도 넣어" 했지만 그 게임의 캐릭터라 넣지 않고 우리 캐릭터로 바꿨습니다: 👁️ 그림자 사냥꾼(2일째 밤부터 한 마리, 키 크고 마른 그림자에 하얀 눈, 도끼로 3초 얼릴 수만 있고 쓰러지지 않음, 빛 안에는 못 들어오고 쫓을 사람이 없으면 🔦 횃불을 끔, 가까이 오면 화면 가장자리가 어두워지고 두근 소리)과 🐾 길 잃은 아기 동물 4마리(숲 끝 굴 4곳 `CAMP_DENS`, E 로 데려와 모닥불까지 오면 구조 🪙25, 🦊 아침마다 나무 5개, 🐻 늑대에게 30% 덜 아픔, 🐰 열매 2배, 🦉 불빛 +3, 쓰러지면 굴로 돌아감, 새로 시작하면 다시 길을 잃음). 혼자면 AI 캠프 친구 3명이 나무를 베어 불에 넣고, 밤에는 빛 가장자리에 온 늑대를 때립니다. 친구 방에서는 방장이 날짜, 불, 늑대를 맡고(`{t:'cp'}` 숫자만) 각자 자기 체력과 가방을 맡습니다.

## 파일

- `core.mjs`: 캐릭터 물리(상자 충돌, 계단, 사다리, 벨트, 점프대, 움직이는 발판), 저장 정리, 아바타 목록, 타이쿤 가격, 네트워크 묶기. three.js 를 쓰지 않아서 node 로 시험합니다.
- `worlds.mjs`: 세계 부품 목록(숫자만).
- `src/render.js`: 렌더러, 하늘, 그림자, 재질, 부품 합치기.
- `src/avatar.js`: 블록 아바타, 모자 16개, 얼굴 8개, 무늬 8개, 이름표, 말풍선, 움직임.
- `src/net.js`: 방 코드(`Room`, 게임 이름 `brickverse`, 6명까지).
- `src/plaza.js`: 모두의 광장(`World`, `plaza-1` ~ `plaza-4`). DOM 을 쓰지 않아서 node 로 시험합니다(`plaza.test.mjs`, `plaza-check.mjs`).
- `src/blocks.js`: 하늘 타워와 모두의 공터가 같이 쓰는 블록 그리기(InstancedMesh), 미리 보기 상자, 화면 위치에서 칸 고르기, 블록 막대.
- `src/commons.js`: 🧱 모두의 공터 (브릭 광장의 런타임). 칸 이름과 검사는 `core.mjs` 의 `commonsKey`, `parseCommonsKey`, `commonsBlock`, `countMine`.
- `src/cloud.js`: 로그인과 클라우드 저장.

## 같이 놀기와 로그인

- **모두의 광장** (`src/plaza.js`): 로그인하고 게임을 시작하면 방 코드 없이 저절로 같은 광장 세계에 들어갑니다. 세계는 공용 서버의 같이 쓰는 세계(`World`) `brickverse:plaza-1` ~ `plaza-4` 이고 한 곳에 12명까지입니다. 언제나 `plaza-1` 부터 들어가 보고 꽉 찼으면 다음 번호로 가며, 넷 다 차면 혼자 하다가 30초 뒤부터 다시 들어가 봅니다. 들어갈 때마다 `account.ticket()` 으로 표를 새로 받습니다.
  - 광장으로 보내는 것은 방과 같은 `hi`(별명 번호, 옷, 있는 세계, 펫. 타이쿤 물건 목록은 뺌), 위치(`world.pose`, 방의 `p` 와 같은 숫자 배열), `say`(정해 둔 말 번호)뿐입니다. 타이쿤 돈 주기, 타워 블록, `ty`, `br`, `sv`, `tg` 는 보내지 않고 받아도 버립니다(`acceptPlaza`). 사람이 쓴 글과 채팅은 없습니다. 보내는 모양이 서버 거르개(`cleanData`)를 지나도 그대로인지 `plaza.test.mjs` 가 봅니다.
  - 광장에서 만난 사람은 `game.plazaRemotes` 에 따로 두고, 나와 같은 세계이고 그 세계가 브릭 광장이나 무지개 점프 탑일 때만 보입니다. 다른 문 안(타이쿤, 바닥이 사라져요, 하늘 타워, 배틀 로얄, 술래잡기)에서는 안 보이고, 미니게임은 방(`game.net`, `game.remotes`)만 보므로 광장에만 있으면 혼자 하기와 똑같습니다. 친구와 미니게임을 같이 하려면 방 코드를 씁니다.
  - 이름은 꾸미기에서 고른 별명이고, 서버의 계정 닉네임은 보이지 않습니다. 사람 목록과 👥 화면에 광장 사람이 어디 있는지 나오고 🔇 로 나에게만 숨길 수 있습니다. 서로 차단한 계정 사이는 서버가 위치와 메시지를 전하지 않습니다.
  - 칸(`world.set`, `world.del`)은 🧱 모두의 공터 블록만 씁니다. 칸 이름은 `b|i|j|k`(정수 칸 좌표, i k 0~11, j 0~15), 값은 블록 번호 하나(0~16), ttl 없음. 서버가 진실이라 놓으면 `set` 을 보내고 서버가 돌려준 `cell` 만 그립니다. 들어올 때 받은 칸은 `opened` 뒤 `plaza.cells` 로 공터를 채우고, 광장에서 나오면 공터를 비웁니다. 공터 밖 좌표, 정수가 아닌 값, 모르는 블록 번호는 그리지 않습니다(`commonsBlock`). 서버 거절은 한 줄로 알립니다: `taken` 다른 친구가 먼저 놓았어, `not-owner` 다른 친구가 놓은 블록은 못 부숴, `limit` 400개, `world-full`, `rate` 너무 빨라, `limit-day` 오늘은 그만(`COMMONS_TEXT`, 같은 알림은 2.5초에 한 번). 남의 블록 부수기와 400개 넘기는 서버에 보내지 않고 바로 알립니다. 놓은 사람 이름표는 붙이지 않습니다(계정 닉네임이 보이지 않게).
  - 방을 만들거나 들어가면 광장에서 나오고, 방에서 나오면 다시 광장에 들어갑니다. 로그아웃하면 나옵니다. 탭이 5분 넘게 가려져 있으면 자리를 비워 주려고 나오고, 다시 보이면 들어갑니다.
  - 서버가 아직 광장을 모르면(`no-world`, `not-deployed`, 서버 배포 전) 조용히 혼자 하고 다시 들어가 보지 않습니다(새로 열거나 다시 로그인하면 다시 해 봄). 인터넷 오류나 끊김은 3초부터 두 배씩 2분까지 간격을 늘려 다시 들어갑니다(서버는 1분에 20번 넘게 들어오면 막음). 다른 기기에서 들어갔거나(`replaced`) 계정이 정지되면 다시 들어가지 않습니다.
- 방 코드는 로그인 없이 됩니다. 별명(꾸미는 말 + 동물), 옷, 정해 둔 말 12개, 감정 표현 4개는 모두 번호로만 보냅니다. 사람이 쓴 글은 보내지 않아서 채팅 거르기가 필요 없습니다. 친구 목록에서 🔇 로 그 친구를 나에게만 숨길 수 있습니다.
- 로그인은 모든 게임이 같이 쓰는 seonn 계정입니다. 코인, 산 꾸미기, 점프 탑, 타이쿤 기록을 저장합니다. 다른 기기가 먼저 저장했으면 합치지 않고 어느 기록을 쓸지 고르게 합니다.
- 내 컴퓨터 서버로 시험할 때는 주소 뒤에 `?net=http://127.0.0.1:8787` 을 붙입니다. 계정 만들기 시험은 진짜 서버에서 하지 않습니다.
