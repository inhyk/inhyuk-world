# 브릭버스 · BRICKVERSE

아바타를 꾸미고 광장에서 빛나는 문을 골라 들어가 노는 3D 블록 놀이터입니다. three.js 로 그리고, 그림과 모델과 소리는 모두 코드로 새로 만들었습니다.

## 실행

- 단독 실행: 저장소 루트에서 `npm run brickverse:dev` → http://127.0.0.1:5173/ 같은 주소
- 사이트에서: `npm run brickverse:build` 후 `/play/brickverse`
- 시험: `npm run test:brickverse` (물리, 저장 정리, 타이쿤 경제, 점프 탑 30단계가 모두 점프로 이어지는지)

## 조작

- WASD·방향키 이동, Space 점프, 마우스 끌기 시점, 휠 확대, T 말하기, 1~4 표현
- **머리카락**: 꾸미기 💇 머리 탭. 모양 12가지(`HAIRS`, 5개는 공짜)와 색 10가지(`HAIR_COLORS`). 모자를 쓰면 위로 솟는 머리는 숨깁니다. 옷 배열 끝에 붙여서 예전 게임과도 맞습니다.
- **쉬프트락**: Shift 키(휴대폰은 오른쪽 아래 🔒 버튼). 컴퓨터에서는 마우스를 화면에 붙잡아(Pointer Lock) 마우스만 움직여도 시점이 돌고, 가운데에 조준점이 생깁니다. 캐릭터는 늘 카메라가 보는 쪽을 보고(A/D 는 옆걸음), 카메라는 어깨 너머로 비켜섭니다. 하늘 타워에서는 조준점으로 블록을 놓습니다. Esc, 옷장, 메뉴를 열면 꺼집니다.

## 세계

- **브릭 광장** (`buildHub`): 분수, 옷가게, 통통 점프 공원, 전망대, 작은 점프길, 주민, 코인. 문 세 개로 게임에 들어갑니다.
- **무지개 점프 탑** (`buildObby`): 30단계. 단계마다 오른쪽으로 꺾이며 올라갑니다. 체크포인트마다 코인, 꼭대기 100코인.
- **블록 공장 타이쿤** (`tycoonBase`, `tycoonItem`, `src/tycoon.js`): 떨어뜨리개 → 벨트 → 업그레이더 → 녹이는 기계 → 초록 발판에서 돈 받기 → 발판을 밟아 물건 45개 사기. 황금 트로피(+200 코인) 다음에는 뒷마당을 넓혀 차고, 트램펄린, 그네, 연못, 온실, 축구 골대, 3층 집, 로켓 발사대(+300 코인)를 짓고, 그다음 하늘 섬(윗면 높이 `SKY`, 노란 엘리베이터로 오름)에 풍차, 구름 정원, 구름 은행(돈 ×2), 열기구, 무지개 다리, 하늘 분수, 하늘 성, 별 공장(돈 ×3), UFO 착륙장(돈 ×2), 황금 왕관 탑(+500 코인)을 짓습니다. `boost` 는 녹이는 기계에서 모든 돈에 곱합니다. 모두 사는 데 약 1시간. 친구 방에서는 돈 칸의 💸 돈 주기로 친구에게 타이쿤 돈을 줄 수 있습니다(`{t:'gift', amt, n}` → 받은 쪽이 `gift-ok`, 6초 안에 답이 없으면 돌려받음, 같은 번호는 한 번만). 공장 밖에 있거나 게임을 꺼 둔 동안에도 돈이 원래의 0.001%로 쌓입니다(`tycoonAwayEarnings`, 7일까지, 1달러가 안 되는 돈은 `bank` 에 모음).
- **바닥이 사라져요** (`buildSurvival`, `src/survival.js`): 밟은 바닥은 0.45초 뒤 떨어집니다. 3층 아래 용암에 빠지면 탈락. 혼자면 봇 5명과, 친구가 있으면 방장이 판을 시작합니다.

- **하늘 타워 짓기** (`buildTower`, `src/tower.js`): 돌판(24×24칸, 100층) 6개(`TOWER_SLOTS`). 혼자면 가운데 0번이 내 땅, 친구 방에서는 p1 → 0번, p2 → 1번처럼 각자 다른 땅에 짓습니다. 블록 17종을 내 땅에만 놓고 부수고, 손이 닿는 거리(20)까지만 놓을 수 있습니다. 내 땅 앞의 🌈 무지개 카펫에 타면 조종합니다: WASD(조이스틱) 이동, Space(⬆) 위, C(⬇) 아래, X(🛬) 내리기, 🏗️ 꼭대기로(꼭대기 블록 옆면에 붙음), 🌈 부르기. 내 땅 위에서만 날고, 카펫과 탄 사람 자리가 블록에 닿으면 그쪽으로는 멈춥니다(`blocked`). 플레이어보다 먼저 움직여 태우고(`move`), 아무도 안 타고 60초가 지나면 집으로 돌아갑니다. 처음 올라간 층마다 1코인. 내 블록 500개까지 저장. 블록은 숫자로만 보냅니다.

- **블록 배틀 로얄** (`buildBattle`, `src/battle.js`): 섬 지름 약 500(마을 7, 창고 5, 저격 탑 8, 언덕, 나무 250). 블록이 많아 봇과 광선은 16칸 격자로 가까운 블록만 봅니다(`buildGrid`). 하늘 대기실(10초) → 낙하산으로 섬에 내려가기 → 블래스터 4종(`WEAPONS`)과 회복 주스, 방패 줍기 → 줄어드는 안전 구역(`zonePhases`, 밖에 있으면 체력이 줄어듦) → 마지막 1명이 우승. 장난감 블래스터라서 맞으면 체력이 줄고 0 이면 펑 사라져 탈락합니다. 혼자면 봇 11명, 친구 방이면 방장이 판과 봇을 맡고 각자 자기 체력을 맡습니다(`{t:'br', k:'tick'}` 0.1초마다: 체력, 총알 자국, 맞힘, 주운 아이템, 봇 위치. 모두 숫자). 봇은 처음 12초는 쏘지 않고 낙하산 탄 사람도 쏘지 않습니다. 좋은 블래스터와 회복, 방패를 챙기고, 숨은 적은 마지막으로 본 곳까지 쫓아가고, 싸울 때 좌우로 피합니다. 화면 가운데 조준점으로 쏘고, 컴퓨터는 화면을 누르면 마우스를 붙잡습니다(왼쪽 쏘기, 오른쪽 저격 확대, 1~4 무기). 휴대폰은 🔫 버튼과 🔭 버튼.

## 파일

- `core.mjs`: 캐릭터 물리(상자 충돌, 계단, 사다리, 벨트, 점프대, 움직이는 발판), 저장 정리, 아바타 목록, 타이쿤 가격, 네트워크 묶기. three.js 를 쓰지 않아서 node 로 시험합니다.
- `worlds.mjs`: 세계 부품 목록(숫자만).
- `src/render.js`: 렌더러, 하늘, 그림자, 재질, 부품 합치기.
- `src/avatar.js`: 블록 아바타, 모자 16개, 얼굴 8개, 무늬 8개, 이름표, 말풍선, 움직임.
- `src/net.js`: 방 코드(`Room`, 게임 이름 `brickverse`, 6명까지).
- `src/cloud.js`: 로그인과 클라우드 저장.

## 같이 놀기와 로그인

- 방 코드는 로그인 없이 됩니다. 별명(꾸미는 말 + 동물), 옷, 정해 둔 말 12개, 감정 표현 4개는 모두 번호로만 보냅니다. 사람이 쓴 글은 보내지 않아서 채팅 거르기가 필요 없습니다. 친구 목록에서 🔇 로 그 친구를 나에게만 숨길 수 있습니다.
- 로그인은 모든 게임이 같이 쓰는 seonn 계정입니다. 코인, 산 꾸미기, 점프 탑, 타이쿤 기록을 저장합니다. 다른 기기가 먼저 저장했으면 합치지 않고 어느 기록을 쓸지 고르게 합니다.
- 내 컴퓨터 서버로 시험할 때는 주소 뒤에 `?net=http://127.0.0.1:8787` 을 붙입니다. 계정 만들기 시험은 진짜 서버에서 하지 않습니다.
