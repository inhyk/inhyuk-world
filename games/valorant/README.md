# VALORANT // PROTOCOL

발로란트에서 영감을 받은 1인칭 3D 전술 슈팅 팬 게임입니다. 직접 만든 항구 전장 HARBOR에서 AI 수비팀과 싸웁니다. Riot Games와 관계없는 비공식 팬 게임이며, 원작의 이미지·음성·모델은 사용하지 않습니다. 온라인 멀티플레이는 지원하지 않습니다.

루트에서 `npm install` 후 `npm run dev`로 사이트를 실행하고 **http://localhost:3000/play/valorant**에서 플레이하세요. 게임만 개발할 때는 `npm run valorant:dev`로 **http://127.0.0.1:5174**를 엽니다. `npm run valorant:build`는 게임을 `public/play/valorant/`로 빌드합니다. 사이트의 개발 시작과 배포 빌드에도 자동으로 연결되어 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| WASD / 방향키 | 이동 |
| 마우스 / 왼쪽 클릭 | 조준 / 사격 |
| 오른쪽 클릭 | 정밀 조준, 천천히 이동 |
| Shift / Space | 걷기 / 점프 |
| R | 재장전 |
| 1 / 2 | 선택한 소총 / 클래식 권총 |
| Q | 이동 방향으로 대시, 12초 재사용 |
| E | 전방에 연막, 8초 지속, 라운드당 2회 |
| C | 4초에 걸쳐 체력 최대 50 회복, 라운드당 1회 |
| F 또는 설치 버튼 | A 지점의 사각형 안에서 설치 시작, 2.5초간 정지하면 완료 |
| Esc | 일시정지 및 감도 조절 |

모바일은 왼쪽 스틱으로 이동하고 오른쪽 공간을 드래그해 조준합니다. 사격·재장전·점프·설치 및 스킬 버튼을 지원하며, 가로 화면을 권장합니다. 키보드와 마우스가 있는 데스크톱에서 가장 편하게 플레이할 수 있습니다.

## 규칙

- 3라운드를 먼저 이기면 승리합니다. 매 라운드 5초 준비 후 90초 작전을 진행합니다.
- 설치 중 이동·점프·사격하면 취소됩니다. A 지점까지 거리와 설치 가능한 위치를 HUD에 표시합니다.
- 적을 모두 처치하거나 스파이크를 설치한 뒤 25초 동안 지키면 승리합니다.
- 적은 시야가 가려지면 엄폐물을 돌아 접근합니다. 연막은 양쪽 시야를 막고, 적은 스파이크에 접근해 7초 동안 해체할 수 있습니다. 총알은 연막을 통과합니다.
- 연습 / 일반 / 도전 난이도에 따라 적 수, 반응 속도, 명중률과 피해가 달라집니다.
- 밴달은 25발, 팬텀은 30발, 권총은 12발입니다. 정지 사격이 더 정확하며 헤드샷은 추가 피해를 줍니다. 매 라운드 체력, 방어구, 탄약과 스킬이 복구됩니다.
- 창을 벗어나거나 마우스 잠금을 해제하면 일시정지합니다. 계속 플레이 버튼으로 돌아옵니다.
- 난이도별 최고 처치 수는 브라우저에 저장합니다. 저장소 및 오디오가 차단되어도 게임은 실행됩니다.

## 검증

`npm run test:valorant`로 충돌, 경로 탐색, 벽 뒤 피격 방지, 헤드샷, 무기, 연막, 스파이크, 라운드 및 일시정지 규칙을 검사합니다. `window.render_game_to_text()`는 전투 상태를 JSON으로, `window.advanceTime(ms)`는 테스트용 시간 진행을 제공합니다.

사이트 개발 서버를 실행한 상태에서 `node games/valorant/tests/browser.mjs`로 실제 Chrome의 전체 경기, 모바일 멀티터치와 iframe 실행을 검증합니다. `--plant` 옵션은 A 지점 모서리로 직접 이동한 뒤 F 키를 한 번 눌러 설치하는 회귀 테스트입니다. 브라우저 테스트에는 `tools` 폴더의 Playwright와 설치된 Chrome이 필요합니다.

Babylon.js와 Vite를 사용합니다. 3D 전장·캐릭터·총기는 코드로 생성하며 효과음은 Web Audio로 합성합니다. 외부 CDN과 별도 게임 서버 없이 같은 사이트에서 리소스를 로드합니다.
