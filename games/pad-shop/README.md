# 패드 작업실 · PAD ATELIER

인혁이의 손그림 기획으로 만든 3D 패드 제작·판매 게임. `/play/pad-shop`에서 플레이합니다.

## 실행

- `npm run pad-shop:dev`: 게임 개발 서버
- `npm run pad-shop:build`: 사이트에서 제공할 파일을 `public/play/pad-shop`에 빌드
- `npm run test:pad-shop`: 제작·경제·등급·저장 테스트
- `node games/pad-shop/browser-check.mjs`: 실제 Chrome 및 모바일 터치 검증. `PAD_SHOP_URL`로 사이트 주소 변경 가능 (기본 `http://127.0.0.1:3000`).

## 플레이

작업대, 제작 버튼 또는 Space를 꾹 눌러 패드를 완성합니다. 완성 후 판매 버튼 / Enter로 손님에게 판매합니다. B 또는 왼쪽 버튼으로 곡괭이 상점을 열고, 새 도구를 사거나 이미 산 도구를 다시 장착할 수 있습니다. 오른쪽 건너뛰기는 100원을 차감하고 새 손님을 받습니다. 이전 제작 진행은 사라집니다. 패드 도감에서 판매 기록과 확률을 확인하고, ? 버튼으로 튜토리얼을 다시 볼 수 있습니다. 처음부터 버튼은 확인 후 기록을 지웁니다.

돈, 구매한 곡괭이, 장착 도구, 손님과 제작 진행, 도감, 튜토리얼·소리 설정을 브라우저에 자동 저장합니다. 모바일 터치 지원. 창을 벗어나거나 대화상자를 열면 두드리기가 멈춥니다. 실제 3D WebGL 장면, 두 손·곡괭이 동작, 제작 단계별 패드 변화와 파티클, 합성 효과음을 사용합니다.

## 사진의 규칙과 해석

| 등급 | 기획 확률 | 판매가 | 곡괭이 가격 | 제작 힘 |
|---|---:|---:|---:|---:|
| 일반 | 50% | 1,000 | 0 | 12 |
| 고급 | 30% | 10,000 | 10,000 | 22 |
| 에픽 | 10% | 50,000 | 50,000 | 40 |
| 레전더리 | 1% | 1,000,000 | 500,000 | 75 |
| 매직 | 0.5% | 5,000,000 | 1,000,000 | 130 |
| 인피니티 | 0.1% | 10,000,000 | 1,000,000 | 230 |
| EX | 0.001% | 100,000,000 | 10,000,000 | 400 |

- 기획 확률 합계가 91.601%라서 상대 비율을 보존하여 현재 장착 곡괭이 이하의 등급에서 100%로 정규화합니다. 도감에 원래 확률과 현재 실제 확률을 모두 표시합니다. 최초 손님은 일반 등급입니다.
- 더 높은 곡괭이는 같은 등급 이하 패드를 제작하고, 한 번의 두드림에 더 많은 진행도를 쌓습니다. 주문을 받은 뒤 낮은 곡괭이를 장착하면 적합한 곡괭이로 돌아올 때까지 제작이 멈춥니다.
- 사진에서 지운 흔적이 있는 인피니티 곡괭이는 읽힌 값인 1,000,000원으로 적용했습니다.
- 제작 힘과 패드별 작업량은 플레이를 위해 추가한 값입니다. 모든 곡괭이의 두드림 간격은 0.22초입니다.
- EX와 오메가 곡괭이를 처음 구매하면 각자 축하 화면이 나타나며, 이후에도 제작·판매와 도감 수집을 계속할 수 있습니다.

코어는 `core.mjs`, 3D 장면은 `world.mjs`, 화면과 입력·저장은 `main.js`에 있습니다. `window.render_game_to_text()`는 읽기 전용 브라우저 검증용 상태를 제공합니다.

## 확장: 곡괭이 15종 · 패드 45종

원래 7등급의 기본 모델과 가격은 그대로 유지합니다. 여덟 등급을 추가하고 모든 등급에 기본·미니·프로 모델을 제공합니다. 미니는 기본 가격의 75%, 작업량의 80%, 프로는 가격의 160%, 작업량의 135%입니다. 크기가 다르고, 프로에는 드로잉 펜·스피커·화면 앱 도크가 추가됩니다. 등급별 배경색·수정·불꽃·별·궤도 화면과 고급 곡괭이의 보석·뿔·날개·회전 고리도 구현했습니다.

| 새 등급 | 곡괭이 가격 | 기본 패드 판매가 | 제작 힘 |
|---|---:|---:|---:|
| 크리스탈 | 2,500만 원 | 2억 원 | 650 |
| 루비 | 1억 원 | 5억 원 | 950 |
| 블리자드 | 3억 원 | 10억 원 | 1,400 |
| 드래곤 | 10억 원 | 25억 원 | 2,000 |
| 코스믹 | 30억 원 | 60억 원 | 3,000 |
| 셀레스티얼 | 100억 원 | 150억 원 | 4,200 |
| 네뷸라 | 300억 원 | 400억 원 | 6,000 |
| 오메가 | 1,000억 원 | 1,000억 원 | 9,000 |

일반 주문은 기존 일곱 등급의 상대 가중치를 유지하고 새 등급의 가중치를 추가해, 장착 곡괭이가 허용하는 등급 안에서 정규화합니다. 세 모델은 각각 1/3 확률입니다. 새 등급은 희귀하므로 **확장 곡괭이 첫 구매 시 기본·미니·프로 특별 주문을 하나씩 확정 지급**합니다. 제작 중인 패드는 유지하고, 판매하거나 100원을 내고 건너뛴 다음 특별 주문이 도착합니다. 낮은 도구로 바꾸면 제작할 수 없는 특별 주문은 큐에서 기다립니다. 재장착으로 주문을 중복 지급하지 않습니다. 특별 주문 이후에는 일반 무작위 주문으로 돌아갑니다.

상점의 전체/보유/새 곡괭이 필터와 도감의 등급·모델 필터를 지원합니다. 저장 키는 유지하고, 버전 1 기록을 버전 2로 읽습니다. 돈·장비·주문 진행·설정·등급별 판매 수는 보존하고 과거 판매 수를 기본 모델의 도감으로 옮깁니다. 특별 주문 큐, 모델별 도감과 오메가 달성도 자동 저장합니다.
