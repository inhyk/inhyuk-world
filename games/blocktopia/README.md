# BLOCKTOPIA · 블록토피아

로블록스에서 영감을 받은 싱글플레이 웹 게임. Babylon.js로 그린 파스텔 섬에서 자유롭게 탐험하고 건축합니다.

## 실행

저장소 루트에서 `npm run blocktopia:dev` 실행 후 표시된 주소를 엽니다.
전체 사이트에서는 `/play/blocktopia`로 플레이합니다. `npm run dev`와 `npm run build`에 게임 빌드가 포함됩니다.

## 기능

- 분수 물방울, 움직이는 관람차와 주민, 카페 테라스, 화단, 블록 조각상, 오리 연못
- 3인칭 이동, 점프, 달리기, 마우스 드래그 카메라, 터치 방향키
- 섬과 점프맵에 배치된 32개 코인, 미니맵, 3개 퀘스트와 탐험가 등급
- 12개 점프 발판, 3발판마다 저장 지점, 정상 보상 25코인
- 6색 의상 구매, 6색 블록으로 정원 건축 (최대 100개, 높이 8층)
- 낮/밤, 선택적 효과음, 일시정지, localStorage 자동 저장

## 조작

WASD / 방향키 이동 · Space 점프 · Shift 달리기 · E 상호작용
화면 드래그 시점 · 휠 확대 · 1 탐험 · 2 건축 · 3 의상 · 4 낮/밤 · R 광장 · Esc 일시정지
건축 모드에서는 초록 격자 클릭으로 쌓고, 우클릭 또는 길게 눌러 맨 위 블록을 삭제합니다.

## 검증

`npm run test:blocktopia` — 저장 데이터 정리, 점프/착지, 벽 충돌, 12발판 도달 가능성, 섬 밖 추락.
`node games/blocktopia/browser-check.mjs` — 5180 포트의 게임에서 실제 브라우저 조작 확인. `tools`의 Playwright 설치가 필요합니다.

정적 지형을 재질별로 합쳐 그리기 호출을 줄입니다. 외부 게임 이미지나 Roblox 계정/서버는 사용하지 않습니다. Google Fonts 로딩 실패 시 시스템 폰트를 사용합니다.

## 진행 상황 리셋

오른쪽 위 ☰ 메뉴 → **처음부터 다시 시작** → **모두 지우고 새로 시작**. 코인, 의상, 건축물, 체크포인트와 완료 기록을 초기화합니다. 취소하면 현재 진행 상황이 유지됩니다. 다른 게임의 저장 데이터는 건드리지 않습니다.

## 다섯 가지 추가 타워

하단 **타워** 버튼 또는 숫자 **5**로 선택합니다. 딸기 마카롱(12층/30코인), 초록 숲(16층/40코인), 얼음 결정(20층/50코인), 노을 구름(24층/60코인), 별빛 왕관(28층/75코인). 기존 스카이 점프맵과 함께 총 6코스/112발판입니다. 새 타워는 4층마다 각각 체크포인트를 저장하고 보상은 최초 완주에 한 번만 줍니다. R 또는 광장 버튼으로 돌아옵니다. 기존 저장 데이터는 그대로 유지되며 리셋 시 새 타워 기록도 초기화됩니다.
