# ORBIT BREAKER · 오비트 브레이커

총 10웨이브의 우주 슈팅게임입니다. 5웨이브에서 중간 보스 **센티넬**, 10웨이브에서 최종 보스 **이클립스**가 나타납니다. 중간 보스를 쓰러뜨리면 6웨이브로 계속 진행하고, 최종 보스를 격추하면 승리합니다. 외부 이미지·폰트·음악·게임 엔진 없이 Canvas 2D와 Web Audio로 실행됩니다.

`npm run dev` 후 **http://localhost:3000/play/orbit-breaker**에서 플레이합니다. 독립 실행 파일은 `public/play/orbit-breaker/`에 있어 정적 HTTP 서버에서도 실행할 수 있습니다.

| 조작 | 키 / 동작 |
| --- | --- |
| 이동 | WASD / 방향키 / 화면 드래그 |
| 발사 | 자동 발사 기본 ON, 끄면 Space를 누르고 있기 |
| 노바 필살기 | X / 노바 버튼 |
| 정밀 이동 | Shift |
| 일시정지 | Esc / P / 상단 일시정지 버튼 |
| 소리 | M / 상단 소리 버튼 (기본 OFF) |

시작 화면에서 **2인 협동**을 선택하면 한 컴퓨터의 같은 키보드로 함께 플레이합니다. 인터넷 연결이나 방 코드는 필요하지 않습니다.

| 조작 | 1P (초록) | 2P (파랑) |
| --- | --- | --- |
| 이동 | WASD | 방향키 |
| 발사 | 자동 발사 / Space | 자동 발사 / 슬래시(/) |
| 노바 | X / 1P 노바 버튼 | Enter / 2P 노바 버튼 |
| 정밀 이동 | 왼쪽 Shift | 오른쪽 Shift |
| 터치 | 화면 왼쪽에서 드래그 시작 | 화면 오른쪽에서 드래그 시작 |

두 사람의 체력·무기·노바는 독립적이며, 아이템은 가까운 살아 있는 기체가 받습니다. 아군의 총알은 서로를 해치지 않습니다. 한 명이 격추되어도 동료가 계속 싸울 수 있고, 다음 웨이브를 시작하면 격추된 기체가 체력 절반(올림)으로 돌아옵니다. 두 명 모두 격추되면 게임이 끝납니다. 2인 모드는 적의 수가 25%, 보스 체력이 65% 늘어납니다. 점수는 팀이 공유하며 1인·2인과 난이도별로 기록을 따로 저장합니다.

- **루키 / 파일럿 / 에이스:** 체력 7 / 5 / 3, 탄환 속도와 공격 주기, 보스 체력이 다릅니다.
- **P:** 무기 강화 (싱글 → 듀얼 → 트리플), **+:** 체력 +2와 3초 보호, **N:** 노바 +1 (최대 3).
- 6기 격추할 때마다 P → P → + → N 순서로 아이템이 나옵니다. 가까이 가면 끌어당깁니다.
- 노바는 사용한 플레이어의 충전량을 하나 소모하고, 적의 탄환과 레이저를 지우며 적 전체와 보스에 피해를 줍니다. 살아 있는 두 플레이어 모두 1.5초간 보호합니다.
- 구역 돌파 시 체력 +1, 연속 격추로 최대 4배 점수. 적이 화면을 벗어나도 다음 웨이브로 진행합니다.
- 보스 체력이 절반 이하가 되면 공격이 강화됩니다. 레이저는 1.5초간 예고한 뒤 발사합니다.
- 창을 전환하면 두 플레이어 모두 일시정지하며, 계속하기를 눌러 재개합니다. 최고 점수는 인원·난이도별로 브라우저에 저장됩니다. 10웨이브 기록은 이전 5웨이브 기록과 별도로 저장합니다. 저장소가 막혀도 게임은 실행됩니다.
- 모바일은 세로 전장을 사용합니다. 기체는 손가락을 움직인 거리만큼 이동하므로 손가락 바로 아래로 순간 이동하지 않습니다.

검증: `npm run test:orbit-breaker`. 브라우저 조작 검증: 개발 서버 실행 후 `node games/orbit-breaker/browser-check.mjs` (기존 `tools`의 Playwright와 Chrome 사용).

`window.render_game_to_text()`는 현재 상태를 JSON으로 반환하는 읽기 전용 인터페이스입니다. 전투 코어는 DOM과 독립적이며, 브라우저에 테스트 전용 치트는 제공하지 않습니다.
