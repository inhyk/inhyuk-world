# 미네랄 밸리 · MINERAL VALLEY

1000×1000m 3D 계곡에서 광물을 들고 판매하는 탐험 게임. Babylon.js로 만든 돌 껍질과 양쪽 틈의 작은 보석, 가격별 14등급, 무게에 비례하는 크기, 높은 등급의 매끄러운 표면을 구현했습니다.

- WASD / 방향키: 이동 · 드래그: 카메라 회전 · 휠: 거리 조절
- E: 줍기 · Q: 마지막 광석 내려놓기 · R: 캠프 귀환 · F: 판매 · B: 상점
- 휴대폰: 방향 버튼, 화면 드래그, 행동 버튼
- 최대 5개, 힘 ≥ 운반 광물 총무게일 때만 추가 운반. 상점에서 힘(30회, Lv.31)과 속도(10회) 구매. 운반 칸 클릭으로 선택한 광석을 내려놓고 F로 한꺼번에 판매.
- 기본 광물 1,600개 + 시작용 12개, 판매 시 보충, 45초마다 먼 광물 70개 재생성.
- 시작용 초록 원석과 파랑·보라·갈색 견본은 무작위 생성과 별개. 도감에 명시.
- 누적 플레이 10·20·30·40·50·60분에 2분간 희귀 광맥 이벤트. 매시간 반복하며 접속 종료나 숨겨진 탭에서는 시간이 멈춥니다.
- 이벤트 중 주변 특별 광물 240개 추가. 에픽 이상 11종이 등장하며 확률은 도감에서 확인할 수 있습니다.
- 이벤트 종료 시 특별 광물 제거. 운반 중인 광물은 유지하고 판매할 수 있습니다.
- 돈·강화·도감·이벤트 누적 시간은 로컬 저장. 운반 광물·위치·지도는 새로 접속하면 초기화.
- 상점 선물 코드 `135707531113570` 입력 시 `100000000000000000000000000000000`원 지급. 다시 입력해도 지급되며 큰 금액은 정수 연산과 문자열 저장으로 1원 단위까지 보존됩니다.
- 리셋 버튼은 확인창을 거쳐 현재 게임의 돈·강화·도감·이벤트 시간·운반 광물을 초기화합니다. 다른 게임의 저장에는 영향을 주지 않습니다.
- 갈색 판매는 확인창을 거쳐 잔액에서 100원을 차감하며 마이너스 잔액 허용.

## 실행 및 검증

```sh
npm run mineral-valley:dev -- --port 5186
npm run mineral-valley:build
npm run test:mineral-valley
node games/mineral-valley/browser-check.mjs
node games/mineral-valley/events-browser-check.mjs
node games/mineral-valley/cargo-browser-check.mjs
node games/mineral-valley/gift-browser-check.mjs
```

사이트 경로: `/play/mineral-valley`. 개발 서버의 `?test`에만 검증용 API가 활성화됩니다. 브라우저 검증은 실제 Chrome에서 이동·힘 제한·판매·강화·손해 확인·내려놓기·맵 경계·캠프 제한·저장·도감·모바일 터치를 확인하고 스크린샷을 생성합니다.
