# 미네랄 밸리 · MINERAL VALLEY

30,000×30,000m 3D 계곡에서 광물을 들고 판매하는 탐험 게임. Babylon.js로 산맥처럼 삐죽삐죽 솟은 광맥, 가격별 19등급, 무게에 비례하는 크기와 가격, 아침·낮·밤의 하루, 분할 화면 2인 플레이를 구현했습니다.

## 조작

- **1P**: `W A S D` / 방향키 이동 · 드래그 카메라 회전 · 휠 거리 조절
- **1P 행동**: `E` 줍기 · `Q` 내려놓기 · `R` 캠프 귀환 · `F` 판매 · `Z` 상점
- **2인 플레이**: `2` 키로 분할 화면 켜고 끄기 (헤더의 `2인` 버튼도 동일)
- **2P**: 방향키 이동 · `.` 줍기 · `,` 내려놓기 · `/` 판매 · `'` 캠프 귀환
- **휴대폰**: 방향 버튼, 화면 드래그, 행동 버튼

## 규칙

- 운반 칸은 **Lv.1에서 1개**로 시작해 상점에서 네 번 강화하면 **Lv.5에서 5개**가 됩니다.
- 칸이 남아도 **힘 ≥ 운반 광물 총무게**일 때만 추가로 들 수 있습니다. 힘은 Lv.45, 속도는 Lv.11까지.
- 운반 중에는 무게에 따라 조금 느려지고, 운반 칸을 클릭하면 선택한 광석만 내려놓습니다.
- **가격은 기본가 × 실제 무게 비율**입니다. 같은 광물이라도 크게 자란 쪽이 더 비쌉니다.
- **0.1% 확률로 초대형 광물(★)** 이 나옵니다. 무게 25배에 가격은 80배 프리미엄이 더 붙어 기본가의 약 2,000배가 됩니다. (손해 광석인 갈색 돌에는 프리미엄이 붙지 않습니다.)
- **캠프에서 1,000m 밖**으로 나가야 에픽 이상이 제대로 나옵니다. 그 안에서는 ×0.25, 밖에서는 거리에 따라 최대 ×18까지 잘 나옵니다. 미니맵의 점선 원이 1,000m 경계입니다.
- 기본 광물 1,600개가 항상 플레이어 주변 900m 안에 깔리고, 1,500m 밖으로 밀려난 광물은 회수해 앞쪽에 다시 심습니다. 시작용 12개는 무작위 분포와 별개입니다.
- 미니맵은 플레이어를 가운데 두고 함께 움직이며 1,400m 범위를 보여 줍니다. 캠프가 화면 밖이면 가장자리에 방향 표시가 뜹니다.

## 하루와 이벤트

- 하루는 **아침 10분 · 낮 10분 · 밤 10분**으로 30분이며 하늘·안개·햇빛이 함께 바뀝니다. 밤에는 광물 결정이 스스로 빛납니다.
- 누적 플레이 10·20·30·40·50·60분마다 **1분간** 희귀 광맥 이벤트가 열리고 매시간 반복됩니다.
- 이벤트 중 주변에 특별 광물 240개가 추가되고 새 광석은 에픽 이상만 나옵니다. 종료 시 특별 광물은 사라지지만 운반 중인 광물은 유지되어 판매할 수 있습니다.
- 하루와 이벤트 시간은 보이는 플레이 시간 기준입니다. 접속 종료나 숨겨진 탭에서는 멈춥니다.

## 2인 플레이

- `2`를 누르면 화면이 좌우로 나뉘고 2P가 캠프 옆에 나타납니다. 왼쪽이 1P, 오른쪽이 2P입니다.
- 2P 카메라는 달리는 방향을 부드럽게 따라가므로 마우스 없이 방향키만으로 탐험할 수 있습니다.
- **돈·힘·속도·운반 칸 강화·도감은 함께 쓰고**, 운반 칸은 각자 따로 채웁니다.
- 다시 `2`를 누르면 1인 플레이로 돌아오며 2P가 들고 있던 광물은 그 자리에 내려놓습니다.

## 저장과 기타

- 돈·강화·도감·누적 플레이 시간은 로컬 저장. 운반 광물·위치·지도는 새로 접속하면 다시 생성됩니다.
- 상점 선물 코드 `135707531113570` 입력 시 `100000000000000000000000000000000`원 지급. 다시 입력해도 지급되며 큰 금액은 정수 연산과 문자열 저장으로 1원 단위까지 보존됩니다.
- 리셋 버튼은 확인창을 거쳐 현재 게임의 돈·강화·도감·시간·운반 광물을 초기화합니다. 다른 게임의 저장에는 영향을 주지 않습니다.
- 갈색 돌 판매는 확인창을 거치며 마이너스 잔액을 허용합니다.

## 실행 및 검증

```sh
npm run mineral-valley:dev -- --port 5186
npm run mineral-valley:build
npm run test:mineral-valley
node games/mineral-valley/browser-check.mjs
node games/mineral-valley/events-browser-check.mjs
node games/mineral-valley/cargo-browser-check.mjs
node games/mineral-valley/coop-browser-check.mjs
node games/mineral-valley/gift-browser-check.mjs
```

사이트 경로: `/play/mineral-valley`. 개발 서버의 `?test`에만 검증용 API가 활성화됩니다. 브라우저 검증은 실제 Chrome에서 30,000m 맵 경계, 운반 칸 1→5 강화, 무게·초대형 가격, 1,000m 희귀도 경계, 아침·낮·밤, 플레이어를 따라가는 미니맵, 분할 화면 2인 플레이, 1분 이벤트, 저장, 도감, 모바일 터치를 확인하고 스크린샷을 생성합니다.
