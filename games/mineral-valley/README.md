# 미네랄 밸리 · MINERAL VALLEY

30,000×30,000m 3D 계곡에서 광물을 캐고 파는 탐험 게임. 산맥처럼 삐죽삐죽 솟은 광맥, 가격별 24등급, 무게에 비례하는 가격, 아침·낮·밤의 하루, 밤 몬스터, 분할 화면과 온라인 2인 플레이를 Babylon.js로 만들었습니다.

## 조작

- **1P 이동**: `W A S D` / 방향키 · 드래그 카메라 회전 · 휠 거리 조절
- **1P 행동**: `E` 줍기(풍선 터뜨리기) · `Q` 내려놓기 · `R` 캠프 귀환 · `F` 판매 · `B` 상점 · `T` 공격
- **분할 2인**: `2` 키로 좌우 분할 화면을 켜고 끕니다 (헤더의 `2인` 버튼도 동일)
- **2P**: 방향키 이동 · `L` `;` 시점 회전 · `.` 줍기 · `,` 내려놓기 · `/` 판매 · `'` 귀환 · `K` 공격
- **온라인 2인**: 헤더의 `온라인` 버튼 → 방 만들기 / 친구 코드로 들어가기. 온라인에서는 각자 자기 화면을 쓰고 두 사람 모두 1P 조작을 씁니다.
- **휴대폰**: 방향 버튼, 화면 드래그, 행동 버튼

## 규칙

- 운반 칸은 **Lv.1에서 1개**로 시작해 상점에서 아홉 번 강화하면 **Lv.10에서 10개**가 됩니다.
- 칸이 남아도 **힘 ≥ 운반 광물 총무게**일 때만 추가로 들 수 있습니다. 힘은 Lv.45, 속도는 Lv.11까지.
- **가격은 기본가 × 실제 무게 비율**입니다. 같은 광물이라도 크게 자란 쪽이 더 비쌉니다.
- **0.1% 확률로 초대형 광물(★)** 이 나옵니다. 무게 25배에 가격 80배 프리미엄이 더 붙어 기본가의 약 2,000배가 됩니다. (손해 광석인 갈색 돌에는 프리미엄이 붙지 않습니다.)
- **캠프에서 1,000m 밖**으로 나가야 에픽 이상이 제대로 나옵니다. 그 안에서는 ×0.25, 밖에서는 거리에 따라 최대 ×18까지. 미니맵의 점선 원이 1,000m 경계입니다.
- 기본 광물 1,600개가 항상 플레이어 주변 900m 안에 깔립니다. **두 명이 떨어져 있으면 밭을 절반씩 나눠** 각자 주변이 비지 않습니다.
- 미니맵은 플레이어를 가운데 두고 1,400m 범위를 보여 주며 **밤에도 하얀 지도** 그대로입니다.

## 하루 · 몬스터 · 풍선

- 하루는 **아침 10분 · 낮 10분 · 밤 10분**. 하늘·안개·햇빛이 함께 바뀌고 밤에는 광물이 스스로 빛납니다.
- **밤에만 몬스터**가 최대 14마리까지 나타나 가까운 탐험가를 쫓습니다. 부딪히면 들고 있던 광석을 하나 놓칩니다.
- 곡괭이를 **세 번** 맞히면 쓰러집니다. 보상은 캠프에서 멀수록 커집니다(최대 19배). 아침이 오면 모두 사라집니다.
- 계곡에는 **풍선이 언제나 딱 하나** 떠 있습니다. 미니맵의 분홍 표시와 방향·거리 안내를 따라가 줍기 키(또는 공격 키)로 터뜨리면 **무게와 상관없이** 좋은 광물 하나를 그대로 받습니다. 20초 뒤 다른 곳에 다시 뜹니다.
- 누적 플레이 10·20·30·40·50·60분마다 **1분간** 희귀 광맥 이벤트가 열리고 매시간 반복됩니다. 이벤트 중에는 주변에 특별 광물 240개가 추가되고 새 광석은 에픽 이상만 나옵니다.
- 5분마다 짧은 안내가 지나갑니다.

## 2인 플레이

### 분할 화면

- `2`를 누르면 화면이 좌우로 나뉘고 2P가 캠프 옆에 나타납니다. 왼쪽이 1P, 오른쪽이 2P입니다.
- 2P는 `L`·`;`로 직접 시점을 돌립니다.
- 돈·힘·속도·운반 칸 강화·도감은 함께 쓰고, 운반 칸은 각자 채웁니다.

### 온라인

- 방장 기기가 계곡 전체를 계산하고, 손님에게는 주변 340m의 광물·몬스터·풍선만 보내 줍니다.
- 손님의 조작은 방장에게 전달되어 실제로 처리되고, 화면은 곧바로 반응하도록 손님 쪽에서도 함께 계산합니다.
- 돈·강화·도감은 방장 것을 함께 쓰며, 방에서 나오면 손님은 **자기 저장과 자기 계곡으로 돌아옵니다.**
- 한 방에는 두 명까지만 들어갈 수 있습니다.

## 저장과 기타

- 돈·강화·도감·누적 플레이 시간은 로컬 저장. 운반 광물·위치·지도는 새로 접속하면 다시 생성됩니다.
- 상점 선물 코드 `1357013570` 입력 시 `100000000000000000000000000000000`원 지급. 다시 입력해도 지급되며 큰 금액은 정수 연산과 문자열 저장으로 1원 단위까지 보존됩니다.
- 리셋 버튼은 확인창을 거쳐 현재 게임의 돈·강화·도감·시간·운반 광물을 초기화합니다.
- 소리 버튼을 켜면 시간대에 따라 바뀌는 배경음악과 효과음이 함께 재생됩니다. 파일 없이 WebAudio로 직접 연주합니다.
- 갈색 돌 판매는 확인창을 거치며 마이너스 잔액을 허용합니다.

## 실행 및 검증

```sh
npm run mineral-valley:dev -- --port 5186
npm run mineral-valley:build
npm run test:mineral-valley
node games/mineral-valley/browser-check.mjs
node games/mineral-valley/events-browser-check.mjs
node games/mineral-valley/cargo-browser-check.mjs
node games/mineral-valley/coop-browser-check.mjs
node games/mineral-valley/online-browser-check.mjs
node games/mineral-valley/gift-browser-check.mjs
```

사이트 경로: `/play/mineral-valley`. 개발 서버의 `?test`에만 검증용 API가 활성화됩니다. 온라인 검증은 실제 WebRTC로 두 개의 브라우저를 연결해 방 만들기·참가·조작 전달·광물 스트리밍·공용 지갑·3번째 거절·퇴장 복구까지 확인합니다.
