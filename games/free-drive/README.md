# 자유도로 · FREE DRIVE

인혁이의 자동차 게임 손그림 기획으로 만든 3D 자유주행 게임.

- 사이트: `/play/free-drive`
- 개발: `npm run free-drive:dev`
- 사이트용 빌드: `npm run free-drive:build` (루트 dev/build에도 포함)
- 검증: `npm run test:free-drive`, 실행 중인 localhost:3000에서 `node games/free-drive/browser-check.mjs`

W / ↑ 가속, S / ↓ / Space 제동, A D / ← → 조향. 1·2·3·4로 D·N·P·R 기어를 선택합니다. 차가 멈춰 있어야 기어를 바꿀 수 있으며 R에서 가속하면 후진합니다. C는 추적·운전석·위에서 보기 시점을 순환하고 Esc는 차고로 돌아갑니다. 모바일은 화면 하단 핸들 방향·제동·가속 버튼을 사용합니다. 도로로 복귀 버튼으로 출발점으로 돌아갈 수 있습니다.

도시·숲·해변이 도로로 연결되어 있습니다. 코인은 하나당 5개, 45초 뒤 다시 나타납니다. 상점에서 선셋 쿠페(150 코인), 베리 밴(250 코인)을 사고, 숲 전망대·해변 부두·도시 건물 사이에서 숨겨진 차 3대를 발견할 수 있습니다. 미니맵의 ?를 찾아 가까이 가면 자동 획득합니다.

매일 현지 날짜 기준 100 코인, 실제 자유주행 화면 120초마다 60 코인을 차고 보상 메뉴에서 받습니다. 여러 회차의 시간 보상을 모아서 받을 수 있습니다. 차고·다른 탭에서는 플레이 시간이 늘어나지 않습니다. 코인, 자동차, 선택, 보상, 거리와 누적 플레이 시간은 이 브라우저의 localStorage에 저장됩니다. 계정 및 서버 저장은 없습니다.

## 교통 · 걷기 · 계속 이어지는 맵

도로를 달리는 30대의 차와 출발점 옆 주차 차량을 추가했습니다. **E** 또는 화면의 **내리기 / 타기** 버튼을 사용하세요. 운전 중에는 차를 멈춰야 내릴 수 있습니다. 내린 뒤에는 WASD / 방향키로 걷고, 휴대폰에서는 좌우·앞으로·뒤로 버튼을 사용합니다. 멈춘 차에서 5m 안쪽에 가면 탑승할 수 있습니다. 지나가는 차는 걸어가는 캐릭터 근처에서 멈추며, 탑승하면 직접 운전합니다. 갈아탄 차가 상점의 소유 차량으로 자동 등록되지는 않습니다. 차고에 들렀다 돌아오면 걷기·탑승 상태가 유지되고, 도로로 복귀하면 원래 출발점과 선택한 소유 차량으로 돌아옵니다.

초기 도시 바깥에 들판·숲·해안·도시가 절차적으로 계속 생성됩니다. 한 번에 주변 3×3 구역만 유지하며 멀어진 구역은 해제합니다. 지역 주소는 BigInt, 실제 렌더링은 가까운 좌표로 주기적으로 이동하는 방식이라 먼 곳에서도 부동소수점 좌표가 커지지 않습니다. 지도는 현재 위치를 따라가며 주변 차량을 보여줍니다. 새로운 경관은 같은 지역 주소에서 동일하게 생성됩니다. 위치와 빌린 차량은 새로고침 후 복원되지 않으며, 기존 코인·차고·보상 저장은 유지됩니다.

추가 검증: `npm run test:free-drive`에 교통·걷기·무한 지역 테스트가 포함됩니다. 로컬 사이트와 `npx vite --config games/free-drive/vite.config.js --host 127.0.0.1 --port 5183`을 실행한 뒤 `node games/free-drive/journey-browser-check.mjs`로 PC/모바일 갈아타기, 실제 통행 차량 인수, 이전 맵 경계 통과, 좌표 재배치와 복귀를 검증합니다. 이동용 테스트 훅은 `?test`가 있는 Vite 개발 서버에서만 제공되며 배포용 빌드에서는 제거됩니다.


## 자동차 확장 · 신호등 · 경찰

소유할 수 있는 자동차는 총 21대입니다. 기본 민트 러너를 포함한 상점 차량 14대, 히든 차량 9대입니다. 레드 블록 지프(220 코인)는 빨간 블록 차체와 돌기, 검은 지붕, 투명한 창문, 파란 좌석과 노란 원형 헤드라이트를 갖췄습니다. 택시·랠리카·캠핑카·전기차·레트로 카·탐험차도 상점에서 구매할 수 있습니다.

새 히든 차 6종은 초기 지역 바로 동쪽(코멧 스타), 서쪽(아이스 크리스털), 북쪽(드래곤 파이어), 남쪽(섀도 나이트), 북동쪽(캔디 드림), 남서쪽(사파리 킹)의 길가에서 찾을 수 있습니다. 이후 생성되는 먼 지역에도 반복해서 나타납니다. 미니맵 ?로 표시되며, 이미 발견한 종류는 사라집니다. 가까이 가면 무료로 소유하고 차고에서 선택할 수 있으며 기존 저장 기록은 그대로 호환됩니다.

교차로에는 실제 신호등이 있습니다. 남북 방향 8초 초록·2초 노랑, 동서 방향 8초 초록·2초 노랑이 번갈아 진행됩니다. 도로 차량도 같은 신호로 정차합니다. 자동차로 빨간불에 정지선을 넘으면 경찰차가 지나온 길을 따라 추격하고, 차에서 내리면 경찰관이 쫓아옵니다. 잡히면 감옥 화면에서 60초를 기다린 뒤 출발점으로 돌아갑니다. 수감 종료 시각과 추격 여부는 저장되어 새로고침으로 해제되지 않습니다. 수감 중에는 이동과 차량 변경을 할 수 없고, 추격 중에는 차고 차량 변경과 출발점 복귀를 사용할 수 없습니다. 수감 시간은 실제 경과 시간이며 다른 탭에 있어도 지나갑니다.

확장 브라우저 검증: 사이트 서버와 Vite 5183 서버를 실행한 뒤 `node games/free-drive/expansion-browser-check.mjs`. 지프 구매, 새 히든 6종 발견·저장, 초록불 통과·빨간불 위반·추격·체포, 새로고침 후 수감 유지와 60초 만료, 모바일 UI를 검증합니다.

## 차량 내구도

모든 차량은 내구도 100으로 시작합니다. 운전 중 건물이나 다른 자동차와 충돌하면 사고 한 번에 10씩 줄어들고, 자동차끼리 부딪히면 양쪽 차량이 손상됩니다. 장애물에 계속 붙어서 가속하는 상황은 같은 사고로 처리합니다. 차를 2m 이상 빼고 다시 부딪히면 새로운 사고입니다. 내구도가 0이 되면 가속·후진으로 움직일 수 없지만 E나 화면 버튼으로 내려 다른 차에 탈 수 있습니다. 내 차의 내구도는 차량 종류별로 저장되며 새로고침·차고 선택·출발점 복귀로 회복되지 않습니다. 빌린 도로 차량의 상태는 현재 플레이 세션에서 유지됩니다. 속도계 위에 현재 차량의 내구도가 표시됩니다.

`node games/free-drive/durability-browser-check.mjs`는 실제 벽 충돌 10회, 지속 접촉 중 중복 피해 방지, 내구도 0 정지, 새로고침 후 상태 보존, 고장 난 차에서 내리고 다른 차로 이동하기, 모바일 내구도 표시를 검증합니다.

감옥에서 키보드로 **13570**을 순서대로 누르거나, 휴대폰의 **출소 코드** 칸에 입력하면 즉시 출소합니다. 추격·수감 상태를 해제하고 출발점으로 돌아가며 해제 상태가 저장됩니다.


경찰 순찰차는 상점에서 **1,000코인**으로 구매합니다. 구매한 경찰차에 탑승해 앞쪽 14m 안의 다른 차를 향해 **H**를 누르거나 모바일 **수갑 채우기** 버튼을 누르면 해당 차량이 멈추고 수갑 표시가 나타납니다. 같은 차량을 향해 다시 H를 누르면 풀어주며, 원래 주행 중이던 차량은 다시 움직입니다. 수갑 사용에는 추가 코인이 들지 않습니다. 건물 너머·뒤쪽·먼 차량은 대상으로 선택되지 않고, 수갑이 채워진 차에는 탑승할 수 없습니다. 내구도가 0인 경찰차에서는 수갑을 사용할 수 없습니다. 일반 도로 차량으로는 경찰차가 무료 생성되지 않습니다. 경찰차에 탑승 중에는 신호 위반으로 추격되거나 다른 경찰에게 잡히지 않습니다. 진행 중인 추격도 경찰차에 타면 해제됩니다. 일반 차로 갈아타면 기존 신호 위반 규칙이 다시 적용됩니다.

검증: `node games/free-drive/handcuffs-browser-check.mjs` — 구매·저장·추가 과금 없음, H로 움직이는 차량 정지·해제, 모바일 수갑 버튼.

## 페라리 458 이탈리아

## 온라인 2인 플레이

첫 화면의 **친구와 2인 플레이 → 방 만들기**를 누르고 표시된 6글자 코드를 친구에게 알려 주세요. 친구는 각자 컴퓨터/휴대폰에서 같은 게임을 열고 **참가하기**를 누릅니다. 방 메뉴는 주행 중 오른쪽 위 코드 버튼으로 다시 열 수 있습니다. 최대 2명이며, 친구 차량 위에는 파란 표시가 나타납니다. 방장은 게임 화면을 열어 두어야 합니다.

모든 게임이 같이 쓰는 멀티플레이 서버(`services/net`, `wss://net.seonn.workers.dev`)와 클라이언트 `@inhyuk/net`(`packages/net/index.mjs`)의 코드 방을 사용합니다. 계정 없이 방 코드만으로 들어오며, 서버는 메시지를 전달만 하고 게임 내용을 저장하지 않습니다. 방장이 교통 차량·신호 시계·두 운전자의 이동과 차량 점유·충돌·경찰·수리·보상을 계산하고 참가 기기에 전송합니다. 참가자는 키보드/터치 입력을 보내며, 자기 소유 차량·잔액·내구도는 자신의 브라우저에 저장합니다. 다른 플레이어가 타고 있는 차와 상대 소유 차량에는 탑승할 수 없습니다. 주변 지형은 두 운전자 위치의 합집합(최대 18개 구역)으로 유지하며 좌표 재배치 시 둘을 함께 이동시킵니다.

서버 한도(한 사람이 1초에 30개, 메시지 하나 16KB)에 맞춰 위치는 1초에 15번만 보냅니다. 참가자는 `{type:'input',input,playing,actions}`, 방장은 `{type:'frame',...,notices}` 를 보내고, 수리·승하차·기어 같은 버튼(`actions`)과 코인·사고 안내(`notices`)는 다음 메시지에 모아 보내 버려지지 않습니다. 처음 들어올 때만 참가자가 `hello`(저장 정보), 방장이 `welcome` 을 한 번 보냅니다. 핑, 방 가득 참, 나가기는 서버가 맡습니다.

방이 가득 찼을 때, 없는 코드/연결 실패 시, 나가기/연결 끊김 시에 안내합니다. 참가자가 나가면 방장이 같은 코드로 다른 친구를 받을 수 있고, 방장이 나가면(서버가 참가자를 새 방장으로 정해도) 교통과 경찰은 방장 기기에만 있으므로 참가자는 혼자 플레이로 돌아갑니다. 소유 차량과 진행은 유지합니다. 인터넷 연결이 필요합니다.

검증: `node games/free-drive/online-browser-check.mjs`는 net 서버와 두 브라우저로 PC/모바일 접속, 수리 비용·동기화, 걷기·승하차·터치 운전, 방장 이동이 참가자에게 보이는지, 1초당 메시지 수(30 미만), 세 번째 참가 거부, 나가기·재참가·방장 종료를 확인합니다. 로컬 서버로 하려면 `cd services/net && npx wrangler d1 migrations apply net --local && npx wrangler dev --port 8787 --ip 127.0.0.1` 와 `npm run free-drive:dev` 를 띄우고 `DRIVE_URL=http://127.0.0.1:5173/ NET=http://127.0.0.1:8787 node games/free-drive/online-browser-check.mjs`. 게임 주소 뒤에 `?net=http://127.0.0.1:8787` 을 붙이면(내 컴퓨터 주소만 받음) 브라우저에서도 로컬 서버를 씁니다. 방 약속은 `room.test.mjs`, 순수 로직은 `online.test.mjs`에서 차량 점유, 공동 좌표 이동, 개인 복귀, 수갑, 지형 범위를 검증합니다.

net 서버는 `https://seonn.dev`, `http://localhost`, `http://127.0.0.1` 에서 연 게임만 받습니다(`services/net/wrangler.jsonc` 의 `ALLOWED_ORIGINS`). 그래서 컴퓨터의 LAN IP(예 `http://192.168.0.5:5184`)나 미리보기 배포 주소로 연 게임은 방에 들어가지 못합니다. 휴대폰과 함께 시험하려면 seonn.dev 에 배포된 게임을 씁니다.

## 장소 선택과 어린이 보호구역

차고에서 **자유주행 장소 고르기**를 눌러 도시·숲·해변·어린이 보호구역 중 출발 장소를 고릅니다. 선택한 소유 차량으로 이동하며 코인과 내구도는 유지됩니다. 추격·수감 중에는 장소 이동을 할 수 없습니다. 온라인에서도 각자 장소를 고를 수 있고 상대방은 제자리에 남습니다.

인혁초등학교 앞에는 붉은 도로, 횡단보도, 노란 안전 말뚝과 30 km/h 표지판이 있습니다. 보호구역에서 일반 차량으로 30 km/h를 0.5초 이상 초과하면 경찰이 추격합니다. 지나가는 차도 구역 안에서는 30 km/h 이하로 감속합니다. 경찰차 면제와 체포 후 60초 수감 규칙은 기존과 같습니다.

검증: `places.test.mjs`는 구역 좌표·공유 원점 이동·네 장소 이동·재산 유지·교통 속도·과속 단속을 검증합니다. `places-browser-check.mjs`는 PC/휴대폰 장소 선택과 안내를, `online-browser-check.mjs`는 참가자의 장소 이동 동기화를 확인합니다.

## 포르쉐와 람보르기니

상점에 포르쉐 911(700코인, 은색)과 람보르기니 아벤타도르(900코인, 라임색)를 추가했습니다. 외부 모델 파일을 사용하지 않고 게임의 장난감 스타일에 맞춰 차체를 직접 구성했습니다. 포르쉐는 둥근 지붕과 헤드라이트, 람보르기니는 낮은 각진 차체와 공기흡입구·뒷날개를 갖췄습니다. 기존 승하차, 내구도, 100코인 수리, 저장 및 온라인 동기화를 지원합니다. 도로의 일반 차량으로도 등장합니다.

검증: `node games/free-drive/supercars-browser-check.mjs`로 PC·모바일 구매/수리/승하차/운전/저장 복원을, `SUPERCARS=1 node games/free-drive/online-browser-check.mjs`로 두 차량의 온라인 플레이를 확인합니다.

온라인 입력 전송과 2P 주행 계산은 화면 렌더링과 분리된 20Hz 타이머로 실행됩니다. 방장 화면의 프레임이 낮거나 렌더링이 일시 중단되어도 참가자는 조작할 수 있습니다. 입력은 타이머가 키보드/터치 상태에서 직접 읽고, 차고·방 메뉴·숨겨진 탭에서는 조작을 중지합니다. `guest-movement-browser-check.mjs`는 실제 사이트 iframe에서 접속 직후 키보드 이동, 방장 렌더링 중단, 참가자 렌더링 중단 상태의 제동을 검증합니다. 기기 자체가 잠들거나 브라우저 프로세스가 중단되면 방장 연결을 유지할 수 없습니다.
