# 검 강화하기 · 불멸의 대장간

독립적인 오리지널 검 강화 게임. 원본은 `public/play/sword-forge/`, 별도 게임 빌드 없이 Next.js `/play/sword-forge`에서 실행합니다.

- +0부터 +30까지 31종 검, 6개 등급의 검 외형·색상·장식 변화와 수집 도감
- 처음 3번 강화는 100%, +4부터 단계 하락, +7부터 파괴. 표시 확률과 실제 확률을 같은 함수로 계산
- 실패마다 +8%p (최대 +80%p), 보호·축복 주문서, 상점 영구 강화, 7개 일회성 여정 보상
- 판매와 새 철검 지급, 전투에서 패배 시 재화 손실 없음, 파괴 시 무료 철검·보호 주문서 지급
- 6개 사냥터, 턴제 전투·3회마다 필살기·전투당 무료 회복 물약. 사냥 3회마다 축복 지급
- 합성 효과음, 불씨 파티클, 강화 연출, 자동 저장 및 손상 저장 정규화, 반응형·키보드·모션 감소 지원

실행: `python3 -m http.server 5198 --bind 127.0.0.1 --directory public` → `http://127.0.0.1:5198/play/sword-forge/`

검증: `node --test games/sword-forge/core.test.mjs`. 브라우저 확인: `node games/sword-forge/browser-check.mjs` (서버 실행 후).
