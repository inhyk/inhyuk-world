# 뚱뚱해지기 · 먹방 타이쿤

공책 아이디어로 만든 싱글플레이 3D 게임. 개발 작업 트리: `fat-tycoon-20261111`.

- WASD / 방향키: 이동. 스페이스: 점프. 클릭: 먹기. E: 음식 받기, 업그레이드, 저울, 문.
- 화면을 끌어서 시점 회전, 휠로 확대. 모바일은 조이스틱과 냠!, E 버튼.
- 음식 50가지, 월드 5개(우리 동네 먹자골목, 별빛 야시장, 눈꽃 얼음 나라, 우주 정거장, 황금 구름 궁전), 업그레이드 6가지, 스킨 8가지, 일일·시간 보상.
- 발전과제 42가지: 이루면 오른쪽 위에 알림이 뜨고 코인을 받는다. 규칙은 `core.mjs` 의 `ADVANCEMENTS`.
- 같이 하기: 공용 서버 방 코드(`Room`, game `fat-tycoon`, 4명까지, 로그인 없음). 위치, 몸무게, 옷 번호 같은 숫자만 1초에 10번 보내고 사람이 쓴 글은 보내지 않는다. 친구와 연결돼 있으면 먹을 때 코인 +20%. 진행은 각자 따로 저장한다. 로컬 서버 시험은 주소 뒤에 `&net=http://127.0.0.1:8787`.
- 월드 문(포탈) 안으로 걸어 들어가면 월드를 고르는 창이 뜬다. 앞 월드를 끝까지 깨야 다음 월드가 열린다.
- 로그인: seonn 공용 계정(`Account`, 닉네임 + 비밀번호)으로 로그인하면 `account.putSave('fat-tycoon', ...)` 로 서버에도 저장한다(`src/cloud.js`, 15초에 한 번까지). 다른 기기가 먼저 저장했으면 합치지 않고 어느 기록을 쓸지 사람이 고른다. 계정 만들기와 저장 시험은 로컬 서버(`&net=http://127.0.0.1:8787`)에서만 한다.
- 계획 2 (공책 두 번째 장):
  - 스페이스 점프. 점프력은 기본 1.0, 트램폴린에서 튈 때마다 +0.02 (최대 5.0). 뚱뚱할수록 조금 낮게 뛴다.
  - 날씨(맑음, 구름, 비, 눈, 안개, 무지개)가 실제 시각 기준 1시간마다 바뀐다. 모두 같은 날씨를 본다 (`weatherAt`).
  - 점프맵: 월드 문에서 들어간다. 5구간, 구간 끝 깃발에 처음 닿으면 코인. 떨어지면 마지막 깃발에서 다시.
  - 먹는 건 돈을 낸다 (`platePrice`). 마쮸는 공짜, 돈이 모자라면 시식 5개 (막히지 않게).
  - 우리 집(`src/places.js`): 부엌에서 토마토, 고기, 양파, 초콜렛으로 요리(`recipe`, `cook`), 카메라로 먹방 동영상 20초(`videoPay`), 러닝머신으로 살 빼기(`exercise`).
  - 처음 시작할 때 여자/남자를 고른다. 스킨 창에서 바꿀 수 있다.
- 리셋: 메인화면 오른쪽 아래 🔄 버튼. 두 번 확인한 뒤 전부 지우고 처음부터 시작한다 (소리 설정만 남김). 로그인 중이면 서버 기록도 새 기록으로 덮어쓴다.
- 진행은 localStorage `fat-tycoon-save-v1`에 자동 저장. 로그인은 안 해도 된다.
- `?debug=1`일 때만 브라우저 시험용 `window.__fat`을 공개.

저장소 루트에서 실행:

```sh
npm run fat-tycoon:dev -- --port 5197
npm run test:fat-tycoon
npm run fat-tycoon:build
```

허브 경로는 `/play/fat-tycoon`, 빌드 산출물은 `public/play/fat-tycoon/`이며 Git에서 제외한다.

브라우저 확인은 `npm install --prefix tools` 후 개발 서버를 켜고 `node games/fat-tycoon/browser-check.mjs`로 실행한다. 시작 이야기, 보상 중복 방지, 음식 받기와 먹기, 레벨 업, 저장 재접속, 월드 다섯 개의 인증서와 걸어 들어가는 포털, 잠긴 포털을 확인하고 데스크톱·휴대폰 화면을 `artifacts/fat-tycoon/`에 남긴다.
