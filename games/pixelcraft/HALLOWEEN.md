# 사진에서 구현한 할로윈 축제

- 메인 화면: 어두운 보라색 숲, 초승달, 호박, “할로윈이 왔어!”와 축제 입구.
- 월드: 자연 상태인 땅에 호박과 잭오랜턴을 추가하고, 호박 등불이 매달린 특별 나무를 배치한다.
- 마을: 기존 마을이 없는 지형에는 안전한 공간을 찾아 마을을 보완한다. 좁은 지형은 작은 마을을 사용한다. 음식 상자도 보완한다. 건축·채굴한 영역은 덮어쓰지 않으므로 공간이 없는 지형은 생략한다.
- 제작법: 아이템을 누르면 재료와 보유 수량, 실제 제작 버튼이 나온다.
- 미션: 호박 3개 모으기 → 잭오랜턴 3개 제작 → 3개 설치. 세계마다 한 번 다이아몬드 3개와 황금 사과 3개를 받는다.
- 기존 저장에서도 축제를 한 번 추가한다. 수확한 장식이나 비운 상자는 다시 채우지 않는다. 날짜에 따른 자동 종료는 없다.

흐린 글씨의 “할로윈 특별 나무”는 호박 등불 나무로 해석했다. 지형별 먹거리는 음식 상자로 구현했다. 사진의 정확한 문구가 확인되면 조정할 수 있다.

검증: `npm run test:pixelcraft`, `halloween-browser-check.mjs`, `portals-nether-browser-check.mjs`, `blocks-enchant-browser-check.mjs`, `village-chest-browser-check.mjs`. 브라우저 검사 URL은 `PIXELCRAFT_TEST_URL` 환경 변수로 지정한다.
