# 2D마인크레프트

게임 주소: `/play/pixelcraft` (기존 주소와 `pixelcraft.v1.slot*` 저장 키 유지). `public/play/pixelcraft/` 정적 파일을 iframe으로 실행한다.

## 숲의 비밀 업데이트

- 세계 가로를 640 → 1280칸으로 확장. 높이 160칸. 구버전 저장은 행과 상자·화로 인덱스를 옮겨 건축물·가방·좌표를 유지하며, 새 마을은 기존 640칸 바깥에만 추가한다.
- 마을 3곳, 농부·대장장이·상인의 재료 거래. 처음 위치 동쪽 약 65칸에 가까운 마을이 있다.
- 네더와 엔드 포탈 및 차원별 지형·건축·가방 저장. 가까이서 R 또는 화면의 ‘대화·포탈’ 버튼. 흑요석 4×6 테두리 안을 비우고 부싯돌과 부시를 든 채 R로 직접 네더 포탈을 활성화할 수도 있다.
- 이름과 스킨 4종 선택. 한 컴퓨터에서 2인 협동: 공유 가방과 선택 도구, 각자 체력. 1P A/D/W·스페이스·마우스, 2P 방향키·위쪽 점프, `/` 공격, `.` 정면 캐기, `,` 정면 놓기, L로 2P 관전 모드 켜기·끄기, B로 동료 곁 합류. 카메라는 가까운 두 사람을 함께 따라가며, 멀어지면 1P를 따라간다.
- 하루 1분·2분·10분 선택(기본 10분). 50일째 숲 세계에서 소환사 좀비 등장. 체력 540, 360에서 2단계, 180에서 3단계. 좀비 소환 → 더 많은 좀비와 마법 화살 → 스켈레톤 혼합 소환과 빠른 마법 화살. 소환수 최대 12마리. 평화로움에서도 이야기 보스는 등장한다.
- 보스전 체력 막대·넓은 시야. 처치 후 황금 포탈에서 학교로 돌아가는 이야기 엔딩. 엔딩 후 자유 탐험. 도전과제 10개.
- 기존 가방, 제작대, 화로, 물·용암, 침대, 자동 저장, 크리에이티브, 모바일 터치 조작 유지. 2P가 쓰러지면 1P 곁에서 회복한다.

## 파일과 확인 방법

- `data.mjs`, `core.mjs`: 블록·아이템·제작, 지형·빛·물·충돌 계산.
- `adventure-world.mjs`: 구버전 저장 이관, 마을·네더·엔드 지형, 포탈 프레임과 보스 단계.
- `adventure.mjs`: 이야기·거래·차원 저장·협동·보스·도전과제.
- `game.mjs`, `render.mjs`, `ui.mjs`, `textures.mjs`, `audio.mjs`: 게임 진행, 화면, 가방, 자체 픽셀 그림과 합성 소리.

```sh
node --test games/pixelcraft/core.test.mjs games/pixelcraft/adventure.test.mjs
node games/pixelcraft/browser-check.mjs artifacts/pixelcraft-adventure/baseline
node games/pixelcraft/adventure-browser-check.mjs
```

브라우저 검사는 `tools/node_modules/playwright`를 사용하고 전용 임시 HTTP 서버·새 브라우저 프로필에서 실행한다. 실제 사용자 저장은 변경하지 않는다. 50일 대기와 보스 체력 경계는 테스트 데이터로 진행한 뒤 실제 키보드 공격·포탈·엔딩을 확인한다.

## 로그인과 방어구

- 타이틀에서 공용 게임 계정으로 가입·로그인·로그아웃. `packages/net`의 `Account`를 사용해 기존 젤리 타워 계정과 함께 쓴다. 비밀번호 확인과 중복 닉네임 안내를 지원하며, 서버 코드는 변경하지 않는다.
- 세계 저장은 **브라우저 로컬 저장**이며 계정 ID로 세 칸씩 구분한다. 손님 저장 키는 그대로 유지한다. 계정에 로그인해도 다른 기기로 세계를 옮기지는 않는다. 비밀번호 복구는 제공하지 않는다.
- 공개 서버에 테스트 계정을 만들지 않는다. 테스트는 `?net=http://127.0.0.1:8787`로 지정한 로컬 서버에서만 수행한다. 다른 주소로는 계정 정보를 보내지 않으며, 로컬 서버 토큰은 공개 서버 토큰과 저장 키를 구분한다.
- 정적 게임이 사용하는 `net-client/index.mjs`, `social.mjs`는 공용 패키지 복사본이다. `node games/pixelcraft/sync-net.mjs`로 동기화하며 테스트에서 원본과 같은지 확인한다.
- 가죽·철·금·다이아몬드 방어구: 투구·흉갑·바지·신발 총 16종. 제작대에서 한 세트에 재료 24개(5/8/7/4)를 쓴다. 크리에이티브의 ‘도구·방어구’ 탭에서도 얻는다.
- 가방의 방어구 칸에 끌거나 집어 놓아 착용·해제한다. Shift+클릭은 1P 빈 부위에 빠르게 착용한다. 2P 방어구는 별도 칸에 넣는다. 부위가 맞지 않는 물건은 착용할 수 없다.
- 총 방어력 1당 전투·화염·용암 피해 4% 감소(최대 80%). 피해를 받으면 내구도가 닳고 0이면 파괴된다. 낙하·익사·굶주림은 방어하지 않는다. 착용 모습, 방어력 HUD, 내구도, 두 플레이어 장비가 저장된다.

```sh
node --test games/pixelcraft/*.test.mjs
# 별도 로컬 공용 로그인 서버가 8789에서 실행 중일 때 (services/net 지침 참고)
node games/pixelcraft/account-browser-check.mjs
# node games/pixelcraft/dev-server.mjs 3051 실행 중일 때
node games/pixelcraft/armor-browser-check.mjs
```

## 2026-10-23 · 블록 도감과 인챈트

- Java 26.1 등록 블록 1,168개를 고유 ID로 연결했다. 공기는 환경 블록이며, 나머지는 크리에이티브 도감(한글·영문 ID 검색, 9개 분류, 48개씩 페이지) 또는 `/give minecraft:cherry_planks 64`로 받는다. 기존 전용 블록도 유지한다. 새로운 픽셀 그림은 직접 생성하며 등록 데이터의 출처·MIT 표기는 BLOCK-DATA-SOURCES.txt에 있다. 모든 블록을 2D 타일로 표현하며 3D 상태, 레드스톤 회로와 자동화는 단순화했다. 전체 원작 조합법을 이식한 것은 아니다.
- 지형과 배경을 16비트로 확장하고 `u16:` RLE 형식으로 저장한다. 기존 8비트 저장과 640칸 세계를 계속 읽는다.
- 날카로움·효율·내구성·행운·섬세한 손길·보호·화염으로부터 보호·가벼운 착지·호흡·힘·무한·화염·밀치기·수선의 14종. 실제 공격·채굴·드롭·방어·수중 호흡·활·수리에 적용되며 가방/상자/드롭/저장에서도 유지된다. 행운은 원석 블록 자체가 떨어지는 광석을 복제하지 않는다.
- 야생: 제작대에서 책 1개 + 다이아몬드 2개 + 흑요석 4개로 마법 부여대 제작, 가까이서 우클릭 또는 인챈트 버튼. 부여 레벨 L마다 경험치 3L레벨 + 청금석 L개가 든다. 책장 3개마다 허용 레벨 +1(기본 1, 최대 5). 새 세계 물가는 사탕수수, 깊은 돌층은 청금석 광석을 생성한다. 기존 마을에서도 금 1개→청금석 4개, 가죽 1개→책 1개 거래를 제공한다.
- 크리에이티브는 부여대·재료 없이 인챈트 버튼으로 무료 부여. `/enchant sharpness 5`, `/xp add 30 levels` 명령어도 제공한다. 경험치를 얻을 때 수선 장비를 먼저 고친다.
- 검증: `npm run test:pixelcraft`, `node games/pixelcraft/blocks-enchant-browser-check.mjs` (기본 3055, PIXELCRAFT_TEST_URL / PIXELCRAFT_ARTIFACTS 지정 가능). 브라우저 검사는 새 손님 프로필의 로컬 저장만 쓴다.

### 인챈트 마무리 · 협동과 비용 안내

- 각 부여 항목에서 다음 레벨에 필요한 경험치·청금석과 부족한 책장 수를 확인한다.
- 2P가 착용한 방어구도 인챈트 창에서 직접 선택한다. 착용자 표시는 1P/2P로 구분한다.
- 2P의 공유 도구에도 날카로움·밀치기·효율이 적용된다. 2P가 주운 장비의 인챈트·내구도를 보존하고, 공유 경험치로 2P의 수선 방어구도 수리한다.
- 검증: `npm run test:pixelcraft` 51개 통과(공용 계정 검사 포함). `node games/pixelcraft/blocks-enchant-browser-check.mjs`에서 기존 부여·자원·저장 검사에 2P 전투·채굴·획득·수선·착용 장비 부여·재접속을 추가했다. PC와 휴대폰 화면 확인 결과는 `artifacts/pixelcraft-enchant-finish-20261023/`에 있다.

- 호스트가 물리·거래를 계산한다. 최초/차원 이동에는 gzip 압축한 전체 세계를 12KB씩 나눠 보내고, 이후 지형 차이와 플레이 상태를 보낸다. 송신을 60ms 이상 간격으로 직렬화해 공용 서버의 초당 30개·16KB 제한 안에 둔다. 손님 입력은 보통 10Hz, 눌렀다 떼는 입력은 별도로 전달한다.
- 검증: `npm run test:pixelcraft`, `node games/pixelcraft/online-browser-check.mjs`. 로컬 Worker는 AGENTS.md대로 마이그레이션 후 8793번, 게임은 `node games/pixelcraft/dev-server.mjs 3057`. 브라우저 검사 주소는 `PIXELCRAFT_TEST_URL`로 바꿀 수 있다. 실제 계정이나 운영 DB에 테스트 데이터를 만들지 않는다.


## 2026-10-24 · 새 블록 상호작용

- 블록을 겨냥하고 우클릭(휴대폰은 놓기/사용)한다. 새 나무·구리 문은 두 칸 높이로 놓이고 위아래 어느 쪽에서도 열고 닫는다. 다락문·울타리 문도 열면 통과하며 몸이 끼는 닫기는 막는다. 색깔 침대는 두 칸으로 놓고 잠자기·부활 위치를 지원한다.
- 통·셜커 상자·덫 상자·엔더 상자·호퍼·발사기·공급기·조각된 책장은 각각 27칸 보관함으로 사용한다. 보관물은 저장되고, 블록을 부수면 내용물을 떨어뜨린다. 호퍼 자동 운반, 발사체 발사, 엔더 상자 간 공유, 셜커 상자 아이템 안에 내용물 보관은 구현하지 않았다.
- 용광로는 철·금 광석(심층암 포함), 훈연기는 음식만 일반 화로의 두 배 속도로 굽는다. 새 나무 원목·판자는 연료로 쓴다(불에 타지 않는 네더 나무 제외). 제작기는 수동 제작대로 쓴다.
- 레버·버튼은 켜기/끄기를 전환하고 바로 붙은 상하좌우 문·램프를 작동한다. 버튼 시간 복귀, 감압판, 레드스톤 선·피스톤 회로는 구현하지 않았다. 램프는 직접 우클릭해도 켜고 끈다. 촛불·모닥불은 우클릭으로 끄고, 부싯돌과 부시로 다시 켠다. 실제 조명에도 반영된다.
- 케이크는 일곱 조각으로 나누어 먹는다. 종·소리 블록은 소리를 내며 소리 블록의 음높이를 바꾼다.
- 간단한 작업대 규칙: 장비를 든 채 모루를 우클릭하면 철괴 1개로 내구도를 모두 수리한다. 대장장이 작업대는 다이아몬드 1개로 철 장비를 다이아몬드 장비로 강화한다. 둘 다 인챈트를 유지한다. 숫돌은 인챈트를 지우고 경험치 3을 돌려준다. 크리에이티브는 수리·강화 재료를 쓰지 않는다. 원작의 수리 비용·형판·이름 변경은 구현하지 않았다.
- 온라인 패널 요청도 같은 블록 분류·거리 검사를 쓰며, 상태와 보관물은 기존 방장 저장·동기화 경로를 이용한다.

검증: `npm run test:pixelcraft`, `node games/pixelcraft/block-interactions-browser-check.mjs` (기본 서버 3063, `PIXELCRAFT_TEST_URL`/`PIXELCRAFT_ARTIFACTS` 지원). 새 프로필의 로컬 저장만 사용한다.
