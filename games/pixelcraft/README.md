# 픽셀크래프트 · 2D 마인크래프트

옆에서 보는 2D 마인크래프트. 빌드 없이 `public/play/pixelcraft/` 의 파일을 그대로 내보낸다.

- 사이트에서: `/play/pixelcraft` (`src/app/play/pixelcraft/page.tsx` 가 iframe 으로 감싼다)
- 이 게임만 바로 보기: `npm run pixelcraft:dev` 후 http://127.0.0.1:3047/play/pixelcraft/
- 시험: `npm run test:pixelcraft` (지형·빛·물·조합법·가방·캐기·충돌·저장 압축)
- 브라우저 확인: 테스트 서버를 켠 채 `node games/pixelcraft/browser-check.mjs` (`tools` 의 Playwright 필요)

## 파일

- `data.mjs` 블록 59종·아이템·조합법 50개·화로 굽기·연료·생물. 숫자 ID 는 저장 파일에 들어가므로 바꾸지 않는다.
- `core.mjs` 화면 없는 계산: 시드 지형(초원·숲·사막·눈 숲, 벌레 굴 동굴, 광석, 바다, 깊은 용암), 하늘빛·블록빛, 물·용암 흐름, 몸 충돌(한 칸 턱 오르기), 가방, 조합법, 캐는 시간, 저장 압축(RLE).
- `textures.mjs` 16x16 블록·아이템 그림을 코드로 그린다.
- `render.mjs` 하늘(해·달·별·구름·먼 산) → 뒷벽 → 블록 → 생물 → 물 → 부드러운 빛 → 금·선택 칸.
- `ui.mjs` 가방·제작대·화로·상자·크리에이티브 칸, "만들 수 있는 것" 목록, 핫바와 체력·배고픔.
- `game.mjs` 진행·입력·생물 AI·폭발·저장(localStorage 칸 3개, 30초마다 자동).
- `audio.mjs` 효과음과 잔잔한 배경 음악(Web Audio 합성).

## 규칙 메모

- 세계는 640x160 칸, 하루 10분. 밤(0.54~0.97)이나 빛 6 이하에서 적이 나온다. 평화로움은 적과 배고픔이 없다.
- 자연에서 자란 나무 줄기(`*_TRUNK`)와 잎은 지나갈 수 있고, 밑동을 베면 위쪽이 통째로 쓰러진다. 놓은 원목(`*_LOG`)은 단단하다.
- 곡괭이 등급(1 나무·금, 2 돌, 3 철, 4 다이아)이 모자라면 캐도 아무것도 안 나온다. 그때 안내 문구를 띄운다.
- 죽어도 가방은 그대로. 침대를 누르면 다시 태어날 곳이 되고, 밤에 자면 아침이 된다.
- 손에 횃불·잭오랜턴·용암 양동이를 들면 둘레가 밝아진다(그리기에서만, 몹 생성 빛에는 영향 없음).
