# DEEP DIG · 땅파기 게임 1인칭

인혁이의 손그림 기획을 바탕으로 만든 Babylon.js / WebGL 3D 채굴 게임입니다. `npm run deep-dig:build` 후 Next 개발 서버의 `/play/deep-dig`에서 플레이하거나, `npm run deep-dig:dev`로 단독 실행합니다. 원본은 `games/deep-dig/`, 배포 파일은 Vite가 생성하는 `public/play/deep-dig/`입니다. `npm run dev`와 전체 빌드에도 이 게임 빌드가 포함됩니다.

캐릭터 눈높이에서 바라보는 1인칭 3D 광산입니다. 중앙 조준점과 손에 든 삽, 3 × 3 입체 광맥, 광석 결정, 광차, 조명과 그림자로 구성되어 있습니다. 블록 또는 채굴 버튼을 **꾹 누르거나 Space를 누르고 있으면** 삽질할 때마다 금이 단계적으로 퍼집니다. 내구도가 모두 닳아야 블록이 부서져 광물이 들어옵니다. 짧은 클릭으로는 캐지지 않습니다. 버튼에 포커스가 있을 때는 Space 또는 Enter를 누르고 있어도 됩니다.

- WASD / 방향키: 화면 방향을 기준으로 캐릭터 이동. R 또는 하강 버튼: 한 블록 이상을 캔 뒤 다음 깊이로 이동.
- 가까운 미채굴 광물이 자동 선택됩니다. 먼 블록을 꾹 누르면 가까이 걸어간 후 채굴하며, 손을 떼면 자동 접근도 멈춥니다. 광산 가장자리 밖으로는 나가지 않습니다.
- 마우스 오른쪽 버튼을 누르고 드래그: 좌우·상하 둘러보기. 모바일은 **시점 조절** 영역을 드래그합니다. Q / E 또는 화면의 회전 버튼으로도 좌우 회전할 수 있습니다.
- Space / 채굴 버튼은 조준점의 블록을 선택해 채굴합니다. 블록을 직접 꾹 눌러 선택할 수도 있습니다.
- 누르기 해제, 터치 취소, 창 전환, 도감 열기: 채굴 중지. 이미 생긴 균열은 유지됩니다.
- 한 층을 모두 캔 뒤에도 누르고 있으면 자동 하강합니다. 배낭이 차면 멈추고, 광물을 판매한 뒤 이어갑니다.
- 왼쪽 아래 **화면 크게**: 게임 화면을 확대하고 지원 브라우저에서는 전체 화면으로 전환합니다. **원래 크기로** 또는 Esc로 돌아옵니다.
- 상단 **리셋**: 확인창에서 취소하거나, 돈·광물·도감·장비·균열·승리 기록을 지우고 1m부터 다시 시작합니다. 초기 상태도 자동 저장됩니다.
- 모바일은 화면의 방향 버튼을 꾹 눌러 이동하고, 3D 블록이나 채굴 버튼을 꾹 눌러 채굴합니다. 이동과 채굴을 두 손가락으로 함께 조작할 수 있습니다. 터치 취소·창 전환·도감·리셋창에서 이동 입력을 해제합니다.
- 캐릭터 위치는 현재 플레이 동안 유지되며, 새로고침·리셋 후에는 입구에서 시작합니다. 돈·장비·광물·균열 저장은 그대로 유지됩니다.

| 업그레이드 | 효과 |
| --- | --- |
| 삽 크기 | 선택 블록과 가까운 1 / 3 / 5 / 7 / 9칸에 동시에 피해 |
| 손의 속도 | 삽질 간격 420 → 365 → 310 → 255 → 200ms |
| 힘 | 한 번의 피해 20 → 28 → 39 → 55 → 77 |
| 배낭 | 보관량 20 → 40 → 60 → 80 → 100개 |

기본 돌의 내구도는 100이며 광물 등급마다 25씩 증가합니다. 기본 장비로 돌을 캐려면 5회(2.1초), 힘을 한 번 강화하면 4회(1.68초)가 걸립니다. 힘을 최대로 올려도 새 돌을 한 번에 캐지는 않습니다. 힘과 손의 속도는 독립적으로 작동합니다.

| 광물 | 최초 깊이 | 개당 판매가 |
| --- | --- | --- |
| 돌 | 1m | 10원 |
| 큰 돌 | 10m | 50원 |
| 석탄 | 50m | 100원 |
| 철 | 75m | 1,000원 |
| 구리 | 100m | 10,000원 |
| 은 | 150m | 1억 원 |
| 플래티넘 | 300m | 5억 원 |
| 다이아몬드 | 500m | 10억 원 |

손글씨의 최종 금액은 100억 원으로 해석했습니다. 목표는 누적 판매액 기준이어서 업그레이드에 쓴 돈도 인정합니다. 광물 위치는 깊이와 칸 번호로 결정됩니다.

진행 상황과 각 블록의 균열은 `deep-dig-v1` 저장 키에 version 2 형식으로 저장됩니다. 이전 2D 게임 저장 데이터의 돈·장비·깊이·도감을 보존하며 힘 Lv.1과 균열 0으로 자동 이관합니다. 소리는 기본 OFF입니다. 실행 중 외부 CDN이나 이미지 파일이 필요하지 않습니다.

검증: `npm run test:deep-dig`로 코어 테스트 10개를 실행합니다. 게임 빌드와 개발 서버 실행 후 `node games/deep-dig/browser-check.mjs`로 실제 WebGL 렌더링, 단계별 균열, 중지/재개, 저장 이관, 힘·속도, 판매·승리와 고해상도 모바일 터치, 캐릭터 이동과 이동 중지, 리셋, 1인칭 카메라 추적과 마우스·터치 시점 조작을 검사합니다. `DEEP_DIG_URL`로 서버 주소를 바꿀 수 있습니다. 브라우저 검증은 격리된 테스트 컨텍스트의 저장 데이터로 깊은 지층과 승리를 확인합니다. `window.render_game_to_text()`는 상태와 화면상의 블록 좌표를 조회하는 읽기 전용 진단 인터페이스입니다.
