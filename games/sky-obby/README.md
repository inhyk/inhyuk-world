# 하늘 점프맵 · SKY OBBY

구름 위에 떠 있는 Babylon.js / WebGL 3D 점프맵입니다. `npm run sky-obby:build` 후 Next 개발 서버의 `/play/sky-obby`에서 플레이하거나, `npm run sky-obby:dev`로 단독 실행합니다. 원본은 `games/sky-obby/`, 배포 파일은 Vite가 생성하는 `public/play/sky-obby/`입니다.

> 사이트에는 예전부터 `jump-map` 슬러그로 등록된 다른 게임(지오메트리 대시 스타일 "점프맵")이 있어서, 이 게임은 `sky-obby`라는 이름을 씁니다.

## 조작

- **WASD / 방향키**: 카메라 방향 기준으로 달리기
- **Space**: 점프 (발판 끝에서 살짝 늦게 눌러도 되는 여유 시간과, 착지 직전에 미리 눌러 둔 입력을 받아 줌)
- **마우스 드래그**: 시점 회전, **휠**: 확대/축소
- **모바일**: 왼쪽 아래 조이스틱으로 이동, 오른쪽 아래 버튼으로 점프, 화면 드래그로 시점 회전
- **↺ 처음부터**: 확인창을 거쳐 STAGE 1부터 다시 시작 (최고 기록은 유지)
- **🗑 기록 리셋**: 확인창을 거쳐 최고 기록·현재 기록·넘어짐·체크포인트를 모두 지우고 STAGE 1부터 시작 (소리 설정은 유지)

## 스테이지

1. **첫 점프**: 간격이 조금씩 벌어지는 블록
2. **용암 징검다리**: 용암 위 지그재그 발판
3. **움직이는 발판**: 좌우로 움직이는 발판 두 개와 위아래로 움직이는 발판
4. **회전 막대 다리**: 좁은 다리 위에서 돌아가는 빨간 막대를 뛰어넘기
5. **사라지는 블록**: 밟고 0.7초 뒤 사라지고 2.7초 뒤 돌아오는 블록
6. **하늘 점프대**: 초록 점프대로 5.5m 위 발판까지 튕겨 오르기
7. **구름 나선 계단**: 기둥을 감싸고 1.5바퀴 올라가는 13개의 계단
8. **쌍둥이 회전 막대**: 서로 반대로 도는 막대 두 개
9. **하늘 삼단 콤보**: 좁은 다리, 움직이는 발판, 사라지는 블록, 점프대
10. **미끄러운 얼음길**: 얼음 위에서는 잘 멈추지 않아 미리 방향을 잡아야 하는 길
11. **컨베이어 벨트**: 뒤로 미는 벨트와 옆으로 미는 벨트
12. **앞뒤로 움직이는 발판**: 서로 반대로 앞뒤로 움직이는 발판 두 개
13. **용암 미로**: 바닥 곳곳의 용암 칸을 피해 걷거나 뛰어넘기
14. **점프대 릴레이**: 점프대 → 발판 → 점프대로 이어 오르기
15. **구름 관문**: 회전 막대 다리, 얼음, 움직이는 발판, 사라지는 블록, 점프대

### 16~100 스테이지 (생성 코스)

`stages.mjs`가 스테이지마다 고정된 시드로 코스를 만들기 때문에 언제나 같은 코스가 나옵니다. 스테이지마다 대표 장애물 하나에 다른 장애물을 섞습니다. 16~40은 2개, 41~75는 3개, 76~100은 4개를 씁니다.

- **장애물 14종**: 징검다리 블록, 용암 징검다리, 흔들 발판, 앞뒤 발판, 엘리베이터 발판, 회전 막대 다리, 사라지는 블록, 점프대, 얼음길, 컨베이어 벨트, 나선 계단, 용암 미로, 쌍둥이 막대, 좁은 다리
- **난이도**: 16에서 100으로 갈수록 발판 크기, 간격, 장치 속도, 막대 개수, 미로 길이가 어려워집니다.
- **하늘 테마** (10스테이지마다): 구름 들판, 새벽 하늘, 노을 하늘, 별빛 밤하늘, 오로라 빙하, 화산 하늘, 사탕 구름, 폭풍 구름, 우주 정거장, 무지개 정상
- **안전 규칙**: 움직이는 장치 앞에는 멈춰 설 고정 발판을 둡니다. 사라지는 블록 뒤에도 쉬는 발판을 둡니다. 회전 막대가 두 개면 사이에 쉼터를 둡니다.

코스 전체 길이는 약 6.2km, 트로피 높이는 약 385m입니다.

## 규칙

- 용암이나 빨간 막대에 닿거나 아래로 떨어지면 넘어짐이 1 늘고 마지막 체크포인트에서 다시 시작합니다.
- 떨어짐 판정 높이는 코스를 따라 올라가서, 높은 곳에서 떨어져도 오래 기다리지 않습니다.
- 체크포인트(깃발 발판)에 올라서면 깃발이 초록색으로 바뀌고 진행도가 저장됩니다.
- 트로피 발판에 착지하면 클리어이며 기록과 최고 기록이 표시됩니다.

## 물리 값

- 이동 속도 8m/s, 중력 32m/s², 점프 초속 12.5m/s (최고 약 2.4m), 점프대 초속 21m/s (최고 약 6.9m)
- 얼음 위 가감속 10m/s² (일반 바닥 70m/s²), 컨베이어 벨트는 초속 3~4m로 밀어냄
- 캐릭터 충돌 상자 0.8 × 1.8 × 0.8m, 1/120초 단위로 나눠 계산

## 저장과 테스트

- 진행 상황(체크포인트·기록·넘어짐·최고 기록·소리)은 `sky-obby-v1` 키로 localStorage에 저장됩니다.
- `npm run test:sky-obby`: 물리·저장 단위 테스트와 함께, 봇이 실제 입력으로 100개 스테이지 전 구간을 건너는지 확인합니다. 회전 막대 구간은 기다리는 시간을 바꿔 가며 통과 타이밍을 찾고, 용암 미로는 생성기가 만든 안전한 길을 따라 걷습니다.
- 화면은 플레이어 근처 구간(뒤 60m, 앞 190m)의 오브젝트만 켜서 그리고, 스테이지 표지판 글자는 가까워질 때 만듭니다.
- `node games/sky-obby/browser-check.mjs`: 개발 서버(기본 `http://localhost:3000`, `SKY_OBBY_URL`로 변경)에서 실제 브라우저로 플레이를 확인하고 `public/images/games/sky-obby-*.png` 스크린샷을 저장합니다.
