# METTATON EX · GLAMOUR / LIVE

언더테일 메타톤 EX를 주인공으로 한 비공식 팬 게임. 캐릭터 원작은 Toby Fox이며, 코드로 그린 픽셀 벡터 그래픽과 실시간 합성 음악은 이 게임을 위해 제작했습니다. 외부 이미지, 폰트, 음악 다운로드 없이 실행됩니다.

루트에서 `npm run dev` 후 **http://localhost:3000/play/mettaton** 에서 플레이합니다. 독립 실행 파일은 `public/play/mettaton/`에 있으며 정적 서버에서도 실행할 수 있습니다.

- 방향키 / WASD: 이동, Shift: 정밀 이동
- Z / Space / Enter: 선택, 타이밍 공격, 노란 영혼 연속 발사
- X / Esc: 돌아가기 및 일시정지, M: 음소거
- 모바일: 터치 방향 패드, 정밀 이동, 발사 버튼
- 공격으로 보스 HP를 소진하거나 시청률 목표를 모은 뒤 자비로 승리 (EX 10,000 / NEO 18,000)
- 파란 탄막은 정지, 주황 탄막은 실제 이동 중 안전
- 포즈: 시청률 +950, 선언: +300 및 다음 라운드 무피격 +850, 춤: HP +6 및 시청률 +400
- 파르페 3개: HP +24, 무피격 라운드: 시청률 +700
- 리허설 / 라이브 / 앙코르 세 난이도, 난이도별 로컬 최고 기록
- 창 전환 시 메뉴 없이 잠시 멈추고 복귀 시 자동 재개, 소리 설정 저장, OS의 동작 줄이기 설정 반영

`npm run test:mettaton`로 전투 로직을 검증합니다. `window.render_game_to_text()`는 브라우저에서 현재 전투 상태를 읽는 자동화용 인터페이스입니다.

## 난이도와 NEO 해금

| 모드 | 플레이어 HP | 피격 피해 | 탄막 속도 | 발사 빈도 | 기본 회피 시간 | 보스 HP |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 리허설 | 64 | 2 | 60% | 65% | 6초 | 6,600 |
| 라이브 | 40 | 4 | 100% | 100% | 9초 | 9,000 |
| 앙코르 | 32 | 6 | 148% | 160% | 12초 | 12,000 |
| 메타톤 NEO | 36 | 7 | 전용 패턴 | 전용 패턴 | 12초 | 16,000 |

EX 난이도는 한 번에 나오는 탄막 수, 안전한 통로 수, 레이저 예고 시간, 피격 후 무적 시간과 타이밍 공격 속도도 다릅니다. 피날레 패턴은 기본 회피 시간보다 2초 깁니다.

앙코르 오른쪽의 **NEO** 버튼은 처음에는 잠겨 있습니다. **EX 앙코르 승리**로만 열리며 공격·자비 결말 모두 인정됩니다. 리허설·라이브 승리와 앙코르 패배로는 열리지 않습니다. 승리 화면에서 바로 NEO에 도전할 수 있고 해금은 같은 브라우저의 로컬 저장소에 유지됩니다. 이전 버전의 앙코르 승리 기록도 인정합니다.

NEO는 별도로 그린 에너지 날개와 암 캐논, 네오 블래스터·칼날 날개·코어 과부하·파워 오브 네오의 4가지 전용 패턴을 사용합니다. 모든 패턴에서 노란 영혼으로 코어를 쏠 수 있습니다.

`node games/mettaton/browser-check.mjs --neo`는 브라우저의 잠금·해금·저장·NEO 전투를 검증합니다. 테스트 브라우저의 요청에만 보스 HP를 낮춘 응답을 제공해 승리 화면을 확인하며, 게임 파일에는 치트나 테스트 전용 조작 기능을 넣지 않습니다.
