# 그린 체스

`public/play/chess`의 정적 게임. `/play/chess`에서 실행합니다. chess.com 같은 체스 사이트의 기능을 그린 체스만의 이름, 그림, 캐릭터로 만들었습니다(다른 회사의 이름, 로고, 말 그림, 화면은 쓰지 않음).

## 화면

- 홈: 레이팅 카드, 바로 가기, 숲속 캐릭터 목록
- 플레이: 온라인, 컴퓨터, 같은 기기 세 가지
- 게임 리뷰, 퍼즐, 퍼즐 러시

## 온라인 대전

공용 서버(`services/net`)의 방과 계정을 씁니다. 게임 이름은 `green-chess`입니다.

- **게임 찾기**: 로그인 필요. 10분 랭크전이고 온라인 점수가 바뀝니다. 상대 이름은 서버가 준 `opponent.nickname`을 씁니다. 판이 끝나면 `room.report(n, won)`으로 서버가 온라인 승리를 셉니다.
- **친구 초대**: 로그인 필요. 접속 중인 친구에게 10분 친선전 초대를 보냅니다. 친구 추가, 수락, 거절도 같은 칸에서 합니다.
- **방 코드**: 로그인 없이 6자리 코드로 들어옵니다. 친선전이고 방장이 시간을 고릅니다.
- 사람이 쓴 글은 보내지 않습니다. 빠른 인사말 8개를 번호(`k`)로만 보내서 채팅 거르기, 차단, 신고 화면이 필요 없습니다.
- 메시지: `hello{r}`, `start{n,you,time}`(방장만), `move{n,ply,m(UCI),ms}`, `resign`, `draw`, `draw-yes`, `draw-no`, `timeout`, `flag`, `rematch`, `say{k}`. 받은 메시지는 `parseMessage`로 확인합니다.
- 시계는 각자 자기 시간을 재고, 수를 둘 때 남은 시간을 같이 보냅니다. 내 시간이 0이 되면 `timeout`, 상대 시간이 3초 넘게 지나도 소식이 없으면 `flag`로 이깁니다. 상대가 방을 나가면 30초 뒤 이깁니다.
- 내 컴퓨터 서버로 시험: 주소 뒤에 `?net=http://127.0.0.1:8787`(내 컴퓨터 주소만 받음). 서버 클라이언트는 `games/chess/sync-net.mjs`가 `packages/net`에서 `public/play/chess/net-client/`로 복사합니다(빌드할 때 자동).

## 컴퓨터 캐릭터 7명 (`bots.mjs`)

새싹이 250, 도토리 다람 500, 호박 기사 800, 부엉 박사 1100, 바위 거북 1400, 번개 여우 1700, 숲의 용 2000. 약한 캐릭터는 점수에 흔들림(`noise`)을 섞고 가끔 아무 수(`blunder`)나 둡니다. 얼굴 SVG와 대사는 직접 만들었습니다.

수 읽기는 `fast-engine.mjs`(0x88 보드, 알파베타, 잡기 끝까지 읽기, 체크 연장, 반복 위치 피하기)가 합니다. perft 값으로 규칙을 확인합니다. 고른 수는 chess.js로 한 번 더 확인합니다. 힌트도 이 엔진을 씁니다. 게임 리뷰는 예전 `engine.mjs`를 그대로 씁니다.

## 레이팅 점수 (`rating.mjs`)

- 엘로 방식. 처음 800점, 처음 20판은 K=40, 그다음 K=20.
- 컴퓨터 대전, 온라인(게임 찾기만), 퍼즐 점수가 따로 있고, 퍼즐 러시는 모드별 최고 기록만 남깁니다.
- 무르기나 힌트를 쓴 판, 2수가 안 된 판, 친선전은 점수가 바뀌지 않습니다.
- 퍼즐은 처음 보는 Lichess 퍼즐만 셉니다. 힌트 없이 한 번에 풀면 이김, 틀리거나 힌트, 정답 보기를 쓰면 짐(상대 점수는 퍼즐 점수).
- 이 기기(브라우저 `localStorage`)에만 저장합니다. 서버가 확인하지 않는 값이라 마음먹으면 속일 수 있습니다.

## 퍼즐 러시 (`rush.mjs`, `rush-ui.mjs`)

3분, 5분, 서바이벌(시간 없음). k번째 퍼즐 목표 점수는 `550 + 60k`(10개마다 40 더)이고, 점수에 가까운 퍼즐을 고릅니다(`indexForRating`). 틀리면 정답을 보여 주고 바로 다음 퍼즐, ✕ 3개면 끝납니다. 다음 퍼즐은 미리 받아 둡니다.

## 퍼즐

- 자체 제작 전술 퍼즐 10개 + 별도 Lichess CC0 공개 퍼즐 100,000개. 데이터 원본의 FEN은 상대 수 직전이므로 첫 수를 재생해 플레이할 차례의 보드로 바꿉니다. UCI 정답 수순은 chess.js로 검증합니다.
- 1,000개 묶음 100개, 점수 낮은 것부터 높은 것 순서입니다. `puzzle-bank.mjs`가 필요한 묶음만 내려받고, 퍼즐 화면과 퍼즐 러시가 같이 씁니다.
- 내 점수 퍼즐, 오늘의 퍼즐, 난이도별 목록, 개별 Lichess 출처 링크, 기기 내 해결 표시.
- 공개 퍼즐을 다시 가져오려면 `curl -L https://database.lichess.org/lichess_db_puzzle.csv.zst -o /tmp/lichess_db_puzzle.csv.zst` 후 `npm run chess:puzzles:import -- /tmp/lichess_db_puzzle.csv.zst`를 실행합니다. 시스템에 zstd가 필요합니다. 원본: https://database.lichess.org/#puzzles (CC0).

## 시험

```bash
npm run test:chess
```

`platform.test.mjs`(엔진 perft, 캐릭터, 레이팅, 러시, 퍼즐 고르기), `online.test.mjs`(메시지 확인, 가짜 방으로 시작, 수, 기권, 무승부, 한 판 더), `core.test.mjs`, `puzzles.test.mjs`.
