# 구름 점프 · 2D 점프맵

Canvas 2D로 만든 횡스크롤 점프맵. `/play/jump-map-2d`에서 실행합니다. 빌드 없이 제공하는 원본은 `public/play/jump-map-2d/`에 있습니다.

- 방향키 또는 A/D: 이동. Space, W 또는 ↑: 점프.
- R: 마지막 체크포인트로 돌아가기. P 또는 Esc: 일시정지.
- 모바일: 왼쪽 이동 버튼과 오른쪽 점프 버튼.
- 10개 코스, 별 50개, 움직이는 발판, 사라지는 발판, 점프대, 얼음 발판.
- 체크포인트, 별, 시간, 넘어짐, 최고 기록은 `cloud-jump-2d-v1`로 자동 저장. 다른 게임 저장과 분리됩니다.
- 테스트: `node --test games/jump-map-2d/core.test.mjs`. 실제 이동 입력으로 전 코스를 완주하고 별 50개를 수집하는지 검증합니다.

기존 3D 하늘 점프맵은 `/play/sky-obby`에서 계속 플레이할 수 있습니다.
