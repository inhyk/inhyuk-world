# 모아몬 탐험대

마을을 걸으며 몬스터를 찾고, 방울을 던져 잡고, 키워서 도장에 도전하는 3D 수집 모험 게임입니다. 걸어 다니며 몬스터를 모으는 게임의 재미를 우리만의 몬스터 34마리와 마을, 음악으로 새로 만들었습니다. 그림 파일과 소리 파일 없이 모두 코드로 만듭니다.

## 실행

- 테스트 서버: 저장소 루트에서 `npm run moamon:dev` → `http://127.0.0.1:5202/`
- 빌드: `npm run moamon:build` → `public/play/moamon` (커밋하지 않음). 사이트 주소는 `/play/moamon`
- 규칙 테스트: `npm run test:moamon`

## 할 수 있는 일

- 끝없이 이어지는 마을 걷기: 공원, 숲, 호수, 주택가, 상점가, 광장, 도장
- 모아몬 34마리 (풀, 불, 물, 번개, 돌, 바람, 달), 진화 가족 14개, 전설 3마리, 반짝이
- 잡기: 방울을 위로 밀어 던지기. 고리가 작을 때 맞히면 좋아요, 멋져요, 완벽해요
- 방울 3종류, 달콤열매(더 잘 잡힘), 황금열매(사탕 2배), 향기풍선(5분 동안 많이 모임)
- 별샘: 90초마다 돌려서 방울, 열매, 알 받기
- 알: 걸으면 깨어남 (250m, 600m, 1200m)
- 키우기: 별가루와 사탕으로 강하게 하기, 사탕으로 진화, 단짝과 300m 걸으면 사탕
- 도장: 3 대 3 싸움. 화면을 눌러 공격, 기운이 차면 큰 기술, 느낌표가 뜨면 피하기
- 낮, 저녁, 밤과 날씨(맑음, 흐림, 바람, 비)에 따라 나오는 몬스터가 달라짐
- 오늘의 할 일 3개, 도감, 상점, 탐험가 레벨 50까지

## 조작

- 걷기: WASD 또는 방향키, 땅 누르기, 손가락 스틱(터치 기기)
- 둘러보기: 화면 끌기, 휠 또는 두 손가락으로 크기 조절
- 싸움: 화면 누르기 또는 Space(공격), Q(큰 기술), F(피하기)
- Esc: 메뉴 닫기

## 파일

- `core.mjs`: 화면과 상관없는 규칙 (몬스터 표, 잡기 확률, 키우기, 알, 할 일, 저장). `core.test.mjs` 로 검사
- `src/monsters.js`: 몬스터 3D 모양과 도감 그림
- `src/world.js`: 마을, 하늘, 날씨, 탐험가, 별샘, 도장
- `src/stage.js`, `src/encounter.js`, `src/battle.js`: 잡기 화면과 싸움 화면
- `src/ui.js`, `style.css`: 버튼과 메뉴
- `src/audio.js`: 효과음과 음악
- `main.js`: 전체를 이어 주는 곳

## 살펴보기용 주소 옵션

- `?mood=day|dusk|night`, `?weather=sunny|cloudy|windy|rain`: 시간과 날씨를 정해서 보기
- `?gallery=1&row=0..3`: 몬스터를 줄 세워 보기
