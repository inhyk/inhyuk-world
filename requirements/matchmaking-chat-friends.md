# 코드 없는 온라인 대전: 랜덤 매칭, 친구, 채팅

정리일: 2026-10-05. 처음 적용할 게임은 젤리 타워(`games/puyo-puyo`)입니다.

## 원래 요청

> 코드를 이용해서 방을 들어가야해..? 코드를 아예 사용하지 않는 편리한 방법을 원해

> 친구등록과 출시, 출시는 아직 고려하지마. 친구등록은 아는 사람을 친구 추가할 수 있게 해주고 닉네임 검색등으로도 친구 추가하게 해줘.

## 목표

젤리 타워에서 방 코드를 입력하지 않고 온라인 대전을 합니다. 모르는 사람과는 랜덤 매칭으로, 아는 사람과는 친구 목록에서 초대해 붙습니다. 친구와는 게임 밖에서도 1:1로 대화합니다.

## 범위

### 포함

1. **서버 계정**
   - 닉네임과 비밀번호로 만듭니다. 닉네임은 전체에서 하나뿐입니다.
   - 어느 기기(웹, 아이폰, 안드로이드)에서 로그인해도 같은 계정과 친구 목록이 보입니다.
   - 이메일은 받지 않습니다. 비밀번호를 잊으면 복구할 수 없습니다.
2. **랜덤 매칭**: "게임 찾기" 버튼 하나로 먼저 기다리던 사람과 바로 붙습니다.
3. **친구 요청**
   - 보내는 방법: 닉네임 검색, 또는 랜덤 매칭 결과 화면의 "친구 요청" 버튼
   - 상대가 수락해야 서로 친구가 됩니다.
4. **친구 초대**: 친구 목록에서 접속 중인 친구를 눌러 초대하고, 친구가 수락하면 같은 판에 들어갑니다.
5. **채팅**
   - 대전 중 자유 채팅
   - 친구 1:1 대화. 상대가 접속해 있지 않아도 남아야 하므로 서버에 저장합니다.
6. **안전 장치**
   - 욕설, 전화번호, 링크를 자동으로 가립니다.
   - 차단: 차단한 사람과는 매칭, 친구 요청, 메시지가 모두 막힙니다.
   - 신고: 신고하면 그 대화 기록을 저장합니다.
7. **관리 페이지**
   - Cloudflare Access 이메일 인증(일회용 코드)으로 들어갑니다. 관리자 이메일은 `kubony@gmail.com`입니다.
   - 신고를 확인하고 계정을 정지합니다.

### 대상

젤리 타워에 먼저 넣습니다. 서버(`services/net`)와 클라이언트(`@inhyuk/net`)의 공용 기능으로 만들어, 다른 게임은 나중에 같은 부품을 씁니다.

### 제외

- 스토어 출시와 심사 대응
- 초대 링크, QR 코드
- 레벨이나 레이팅 기반 매칭
- 비밀번호 복구
- 방 코드 입력 화면 (숨김)

## 제약 조건

- 서버는 Cloudflare 계정 하나(`https://net.seonn.workers.dev`)에 둡니다. 실시간 방은 Worker와 Durable Object로, 계정, 친구 관계, 1:1 대화, 신고, 차단은 D1 DB에 저장합니다.
- 서버는 비밀번호 원문을 저장하지 않고 해시만 저장합니다.
- `AGENTS.md`의 "멀티플레이" 규칙(모르는 사람 매칭 금지, 자유 채팅 금지)을 이 문서의 결정에 맞게 고칩니다.

## 성공 기준

- 로그인한 기기 두 대가 각각 "게임 찾기"를 누르면 코드 입력 없이 같은 판에 들어갑니다.
- 친구 맺기와 초대
  - A가 닉네임으로 B를 검색해 친구 요청을 보내고 B가 수락하면, 양쪽 친구 목록에 서로 보입니다.
  - A가 접속 중인 B를 초대하고 B가 수락하면 같은 판이 시작됩니다.
- B가 접속해 있지 않을 때 A가 보낸 1:1 메시지를 B가 다음 로그인 때 받습니다.
- 욕설, 전화번호, 링크는 상대 화면에서 가려집니다.
- 차단, 신고, 정지
  - 차단한 상대와는 다시 매칭되지 않습니다.
  - 신고는 대화 기록과 함께 관리 페이지에 나타납니다.
  - 정지된 계정은 로그인과 매칭이 거부됩니다.
- 계정
  - 이미 있는 닉네임으로 가입하면 거절됩니다.
  - 다른 기기에서 같은 닉네임과 비밀번호로 로그인하면 같은 친구 목록이 보입니다.

## 결정 사항

| 항목 | 원래 | 결정 |
|---|---|---|
| 같이 할 사람 | 불명확 | 모르는 사람(랜덤 매칭)과 아는 사람(친구) 모두 |
| 랜덤 매칭 기준 | 불명확 | 먼저 기다린 사람과 바로 |
| 닉네임 | 기기 안에서만 겹치지 않음 | 전체에서 하나뿐 |
| 계정 | 기기 안 계정과 기록 코드 | 서버의 닉네임+비밀번호 계정, 복구 수단 없음 |
| 친구 추가 방법 | 불명확 | 닉네임 검색, 판이 끝난 뒤 요청 |
| 친구 성사 | 불명확 | 상대가 수락해야 함 |
| 채팅 | 불명확 | 대전 중 자유 채팅과 친구 1:1 대화(서버 저장) |
| 채팅 안전 | 불명확 | 필터, 차단, 신고 |
| 관리 페이지 접근 | 불명확 | Cloudflare Access 이메일 인증, `kubony@gmail.com` |
| 출시 | 불명확 | 이번 범위에서 제외 |

## 확인이 필요한 것

- **기존 기기 계정 옮기기** (제안, 확정 아님)
  - 젤리 타워에는 기기 안에만 있는 계정(`games/puyo-puyo/profile.mjs`)과 기록 코드(`JELLY1.`)가 있습니다.
  - 앱을 처음 열 때 이 계정을 같은 닉네임과 비밀번호로 서버에 올립니다.
  - 그 닉네임이 이미 서버에 있으면 새 닉네임을 고르게 합니다.
